## 2. 新七品の材料・工程

材料は各×1のゲーム内一食単位。水・少量調味は内包。

| 料理 | 材料 | 工程案 |
|---|---|---|
| 牛丼 | 米、肉、玉ねぎ | 米を鍋で炊く＋肉・玉ねぎを切りフライパンで煮る→提供容器で合流 |
| 親子丼 | 米、肉、玉ねぎ、卵 | 米を鍋で炊く＋肉・玉ねぎを切り卵とフライパンで煮る→提供容器で合流 |
| ミートオムライス | 米、トマト、卵、肉 | トマトを切り米と鍋で炊く＋肉を切って卵とフライパンで加熱→提供容器で合流 |
| 野菜お好み焼き | 小麦粉、卵、葉野菜 | 本体から外したジャーに小麦粉・卵を揃え、戻して混合＋葉野菜を切る→フライパンで合流し焼く |
| 肉お好み焼き | 小麦粉、卵、葉野菜、肉 | 小麦粉・卵を混ぜる＋葉野菜・肉を切る→フライパンで合流し焼く |
| えび天 | えび、小麦粉、卵 | 小麦粉・卵を混ぜる→えびへ混合衣を重ねる→かごで揚げ、上げて提供 |
| ミートソースパスタ | パスタ麺、肉、トマト、玉ねぎ | 麺を茹でる＋肉をミキサー加工し熱源外のフライパンへ→トマトをミキサー加工し、切った玉ねぎと同じフライパンへ揃える→加熱→麺と提供容器で合流 |

- 丼具フライパン化は今回の追加提案。旧具鍋案からの変更をラーメン変更に自動追従した確定事項としない。6-1のオムレツとフライパンが競合するため台数・注文比率は要検証。
- ミートオムライスはトマトライス＋肉入り卵の簡略版。炊いた米を炒め直す工程や裸運搬は不要。旧3材料ではなくトマト込み4材料。
- 生地／衣の粉＋卵はゲーム上の共用中間素材。現実の厳密な配合まで同じとする主張ではない。ジャーへ事前投入してから本体へ戻し、高速追加入力を要求しない。混合後も二材料スロット分。
- 6-6は肉とトマトを別々に混ぜる二回の処理。ジャーに両方入れて一度に混ぜる工程ではない。熱源外のフライパンで素材を揃え、肉だけ先にハンバーグとして完成する前の高速投入を要求しない。
- 完成物は器具から提供容器へ全量移す。工程秒数・料理点・実測難易度は未確定。
