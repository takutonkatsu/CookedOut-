## 1. ラーメンの調理器具変更への評価

推奨案：麺は鍋で茹で、具と内包スープはフライパンで煮て、提供容器で合流する。肉ラーメンは中華麺・肉各×1、卵野菜ラーメンは中華麺・卵・葉野菜各×1で材料不変。肉／葉野菜の切断も維持する。

一食に必要な鍋工程は二つから一つへ減り、代わりにフライパン工程が一つ増える。二枝並行と合流は残り、待ち時間が短くなるとまでは断定しない。既存のフライパンを使い、専用の深鍋・汁容器・注ぐ操作は追加しない。水・スープの基本調味は内包し、具入りスープ全量を提供容器へ移す。

4-3では肉玉ねぎオムレツ、4-4ではラーメン二品と肉焼きそばがフライパンを共用する。4-4の中華麺自体は、ラーメンなら鍋／焼きそばならフライパンの区別を維持する。具は煮る／炒める見た目と工程アイコンを区別する。フライパン一台へ負荷が集中しない台数・注文比率の検証が必要で、鍋数の減少を全体難易度の低下と同一視しない。

将来の海鮮ラーメンも同系統の工程に揃える候補。ただしカレーやスープ全般をフライパンへ移す変更ではない。採用待ちのため既存ラーメンの二鍋工程を確定変更しない。

## 3. 新六品の材料・工程

| 料理 | 材料（各×1） | 工程 |
|---|---|---|
| 唐揚げ | 肉、小麦粉 | 肉を切る→小麦粉を重ねる→かごで揚げる→かごを上げて提供 |
| スパイス唐揚げ | 肉、小麦粉、スパイス | 肉を切る→小麦粉・スパイスを重ねる→揚げて提供 |
| とんかつ | 肉、卵、パン粉 | 切らない肉に卵・パン粉を重ねる→揚げて提供 |
| えびフライ | えび、卵、パン粉 | 切らないえびに卵・パン粉を重ねる→揚げて提供 |
| エッグサラダ | 葉野菜、卵 | 葉野菜を切る＋卵を鍋で加熱→提供容器で合流 |
| 玉ねぎソース唐揚げ | 肉、小麦粉、玉ねぎ | 肉を切って粉衣を付けて揚げる＋玉ねぎを切る→提供容器で合流。刻み玉ねぎに少量のたれを内包する仕上げ案 |

玉ねぎソースは別途煮詰めたソースやミキサー加工を要求する案ではない。刻み玉ねぎ＋内包たれの見た目・名称の納得感は相談対象。現実の肉・卵の個数を表すのでなく、ゲームの一食用単位で数える。

粉衣と卵＋パン粉衣は既存候補の簡略化を維持し、フライ用にさらに小麦粉を要求しない。成形台・衣専用台は追加せず、中間素材を組み立てる既存の例外を使う。完成した揚げ物はかごごとか提供容器で扱い、かごは持ち運び可能・洗浄不要。
