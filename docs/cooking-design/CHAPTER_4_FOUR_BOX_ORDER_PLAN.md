## 2. 第4章の新八品の数量・工程

| 料理 | 材料（各×1） | 工程 |
|---|---|---|
| 基本オムライス | 米、トマト、卵 | トマトを切り米と鍋で炊く＋卵をフライパンで焼く→提供容器で合流 |
| チーズオムライス | 米、トマト、卵、チーズ | 同じトマトライスと卵を作る→提供容器でチーズも重ねる |
| トマトハンバーグ | 肉、トマト | 肉をミキサー加工してフライパンで焼く＋トマトを切る→提供容器で合流。ソースではなく切ったトマト添えという未承認案 |
| 肉ラーメン | 中華麺、肉、玉ねぎ | 麺を鍋で茹でる＋肉・玉ねぎを切って別鍋で煮る→提供容器で合流 |
| 肉玉ねぎオムレツ | 卵、肉、玉ねぎ | 肉・玉ねぎを切る→卵と同じフライパンで加熱→提供 |
| 卵野菜ラーメン | 中華麺、卵、葉野菜 | 麺を鍋で茹でる＋葉野菜を切り卵と別鍋で煮る→提供容器で合流 |
| 魚のサラダ寿司 | 米、魚、葉野菜 | 米を鍋で炊く＋魚・葉野菜を切る→提供容器で合流。最終名称・形は保留 |
| えび焼きそば | 焼きそば麺、えび、葉野菜 | 葉野菜を切る→麺・えびとフライパンでまとめて加熱→提供 |

水・少量調味は内包。加熱物は裸で持たず、調理器具から提供容器へ一食分を移す。米＋トマトは熱源から外した鍋で揃えてから加熱する手順で、白米の完成前に急いで追加する操作を要求しない。手順の表示と作業面は要検証。

## 4. 前案との差と保留

- A案により旧4-1はトマト追加で5箱になるため、肉そぼろを外して4箱にした。
- 肉玉ねぎオムレツを4-5→4-3へ移すと、肉ラーメンと肉・玉ねぎを共用し、新八品を維持できる。一方、一品だけで新ラーメンを導入する余裕は減る。
- 魚のサラダ寿司は4-5のまま、無関係な肉・卵・玉ねぎを外して3箱にする。
- えび焼きそばを4-4→4-6へ移す。えび野菜パスタと共用し、二種類の麺を比較する4箱面。旧4-6の「新料理なし」「自章の新二系統を総合」の狙いを変更する提案。第1・2章にも章末の新料理はあるが、今回も無条件で軽いとはしない。
- オムライス基本二品、ラーメン基本二品は本章で各一面ずつの登場となる。基本二品を早期に習得する条件は4-1／4-4で満たすが、章内の基本料理反復は薄い。通常営業・Sステージ・後続本編の復習計画は別途必要で、通常を必ず遊ぶ前提にはしない。
- 肉そぼろの4-1復習を外すため、現行後続提案では次回は5-5。第5〜8章も本編4箱優先で再検討する際に復習機会を守る。後続の全構成を今回確定しない。
- 章末を新料理なしへ戻したい場合は、えび焼きそばを後章へ送る等の別案を比較する。今回の八品維持・全6面4箱と同時に章末条件まで満たしたとはしない。
