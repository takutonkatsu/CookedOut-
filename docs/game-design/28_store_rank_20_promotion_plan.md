# COOKED OUT! 店ランク20・三条件昇格案 v0.1

- 作成日: 2026-09-12
- 状態: 再検討済み。ランク20案は維持候補だが、偶数ランクごとの三条件方式は後続の「店の評判＋出張ランク上限」案により上書き
- 上書き対象候補: 店ランク1〜10、XPのみの昇格、一部設備Lvだけに指定出張クリアを要求する現行方式

## 1. 解決する問題

店ランクをXPだけで上げ、新料理を出張営業だけで解放すると、次の不整合が起こる。

- 通常営業だけで最高店ランクへ到達したのに、料理がほとんど解放されていない
- シーズン競技の直前に、出張営業を第1章から一気に全クリする必要が生じる
- 店ランクが高いことと、ゲーム全体を経験していることが一致しない
- 後半の通常営業Tierで想定する料理文法を未習得のままになる

店ランクを、単なる累計プレイ時間ではなく「出張で料理を学び、本店で使いこなした総合進行」として再定義する。

## 2. 基本構造

店ランクは1〜20とする案を推奨する。

- 全ランクに累計XP条件を持たせる
- 奇数ランクはXPだけで上がる中間ランク
- 偶数ランクはXP、指定出張到達、通常営業実績をすべて満たす昇格ランク
- ランク1から開始する
- 昇格条件が未達でも超過XPを蓄積し、無駄にしない
- 条件達成時、蓄積XPで到達可能なランクまで自動反映する
- 当面は固有名称を付けず、数字で表示する

偶数ランクでは、三つの条件を単純なアイコンで示す。

```text
経験: XP閾値
出張: 指定ステージクリア
本店: 通常営業実績
```

昇格券、専用通貨、手動受取は追加しない。

## 3. 20段階を推奨する理由

- 10段階では、出張9章、設備Lv5段階、通常営業Tier5段階を配置する余白が少ない
- 20段階なら、大きな昇格の間にXPだけの中間成長を置ける
- 奇数ランクにはコイン、外見、購入上限等の小さな報酬を置ける
- 偶数ランクへ章進行、設備Lv上限、通常営業Tierの節目を配置できる

30〜50段階まで増やすと一段の意味が薄くなる。発売後の追加成長は、店ランクを延長するよりシーズン記録や別の累計レベルで扱う。

## 5. 生スコア以外の通常営業条件

### 5.1 メニューの幅

- 現在Tierで異なる2〜3メニューに成功する
- 鍋中心とフライパン中心の両方へ成功する
- 異なる工程系統を含むメニューへ成功する

最も分かりやすく、簡単なメニューだけの周回を防げるため、主要条件に向く。

### 5.2 注文達成率

```text
注文達成率 = 完了注文数 ÷ 完了または失効した注文数
```

70%、75%、80%等を段階的に要求できる。スコアではなく、安定して注文へ応えた割合を評価する。

### 5.3 配送方法の習得

- 一回の成功営業で自前配達と配送代行を各1件使う
- 自前配達と配送代行を累計各3件成功させる

複雑な比率条件は避け、絵だけで進捗が分かる条件にする。

### 5.4 安全性と立て直し

- 失注2件以内で営業成功
- 火災から復旧したうえで星1
- 誤料理を廃棄し、正しい注文を完成する

完全無失敗は初心者を詰まらせるため、任意バッジに限定する。必須昇格では失敗と復旧を許す。

### 5.5 安定性

- 現在Tierで2営業成功
- 異なるメニューで3営業成功
- 注文達成率70%以上を2回達成

連勝条件にはしない。失敗で進捗をリセットしない。

### 5.6 設備活用

- 可搬設備を一度移動して営業成功
- 保存した配置プリセットで営業成功

特定配置を必須にすると自由を損なうため、初回チュートリアルまたは任意バッジ向けとする。

### 5.7 特別注文

将来、任意の特別注文を入れる場合は累計達成条件にできる。ただしランダム出現のままでは昇格を止めるため、出現保証がない限り必須にしない。

## 6. 必須条件の推奨配分

主に使う:

1. 複数メニューでの成功
2. 注文達成率
3. 自前配達と配送代行の両方

少数だけ使う:

- 許容失注数以内の成功
- 連続ではない複数回成功
- 最終ランクで複数メニューの星2

必須にしない:

- 完全無失敗
- 指定された固定配置
- ランダムな特別注文
- ランキング順位
- 広告視聴、課金、連続ログイン

## 7. 昇格待ちの不満を防ぐ

### 7.1 次の条件を早く表示する

XPが上限へ達した後ではなく、常に次の偶数ランクの三条件を表示する。

```text
次: 店ランク8
✓ 経験 3,800 / 3,800
✓ 本店 Tier 2で注文達成率70%
○ 出張 4-6をクリア
```

出張条件を押すと該当ステージ、通常条件を押すと適合するおすすめメニューとTierへ直接移動する。

### 7.2 超過XPを保存する

昇格条件で止まっている間もXPを蓄積する。出張または通常条件を達成した瞬間、蓄積XPで到達可能な中間ランクまで自動反映する。

### 7.3 過去の達成を数える

条件が表示される前に指定出張や通常実績を達成していた場合も有効にする。各条件を安定した実績IDで保存し、再達成を要求しない。

### 7.4 二重の壁を作らない

昇格条件に指定する出張ステージは、そのランクへ近づく頃には通常の章進行で到達可能にする。店ランク壁と大きな星稼ぎを同時に要求しない。

## 8. 各モードとの関係

### 出張営業

- 通常どおり直前ステージ星1と章進行星で次面を解放する
- 普通の出張ステージ解放に店ランクを要求しない
- 本店設備Lvと配置は持ち込まない
- 店ランクで止まっていても出張キャンペーンは先へ進められる

### 店ランク

- 主要な偶数ランクでは出張と通常営業の両方を経験する
- 出張で新料理を学び、通常営業で使いこなす流れを作る
- 店ランクと料理解放が大きく乖離しない

### シーズン競技

- 店ランク20と最終大型出張9-4星1を条件にする
- 全章、主要料理、設備種類、Tier 5を経験した統合エンドコンテンツとする

## 9. 設備Lv・通常営業Tierとの対応案

| 機能 | 解放節目 |
|---|---:|
| 通常営業 | 1-8後。初回成功がランク2条件 |
| 設備Lv2上限・Tier 2 | ランク4 |
| 設備Lv3上限・Tier 3 | ランク8 |
| 設備Lv4上限・Tier 4 | ランク12 |
| 設備Lv5上限・Tier 5 | ランク16 |
| ランク20プロフィール装飾 | ランク20 |
| シーズン競技 | ランク20＋9-4星1 |

基本機能をランク20まで引っ張らず、最高ランクは習得完了ではなく熟練の証にする。

## 10. 推奨結論

1. 店ランクを10から20へ増やす。
2. 全ランクへXP条件を置く。
3. 偶数ランクへ出張到達と通常営業実績を追加する。
4. 超過XPを保存し、過去達成も遡及反映する。
5. 出張条件を章ごとに段階配置し、ランク20で9-3まで到達済みにする。
6. 通常条件は、生スコアだけでなくメニュー幅、注文達成率、二配送方法を中心にする。
7. 完全無失敗、ランキング、ランダム、広告、課金は必須条件にしない。
8. 出張ステージ自体は店ランクに関係なく進められる。
9. シーズン競技は店ランク20＋9-4星1で解放する。
