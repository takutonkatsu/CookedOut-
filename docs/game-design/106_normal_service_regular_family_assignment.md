## 1. 既定の章ゲートに合わせる案

## 2. 通常営業では各系統の基本2品だけを出す

ユーザーの意向により、定番・選択する追加系統とも料理統合台帳の「基本二品」を使い、三品目は習得後も通常営業へ出さない初期方針とする。サラダならグリーンサラダ・トマトサラダのみで、後からエッグサラダを習得しても通常営業の候補に加えない。

その系統を通常営業で使える時点で基本2品が習得済みとなることを進行条件として整合させる。本店解放の1-6時点で全20系統の基本2品を解放する意味ではない。定番は対応章の既定ゲートによって基本2品の習得を保証する。追加系統は次案107で基本2品習得を候補条件とする。

個別派生の習得は既定の共通進行に従い、招待先の説明閲覧だけでは解放しない。料理側台帳の初出面と個人の正式な解放記録を区別する。

Lv1〜4は1系統2品、Lv5〜20は定番2品＋追加系統2品の合計4品が注文候補となる。表示中の注文票枚数や一営業の注文総数とは別。図鑑・出張・練習・シーズンの料理候補を一律2品へ減らす変更ではない。

## 3. 出張先行でも通常営業は飛ばさない

通常営業が序盤のまま出張を先へ進めても、定番のLv順と昇格条件は変えない。後半系統を習得したことを理由にLv1の定番をピザ等へ置き換えたり、通常営業Lvを自動で飛ばしたりしない。

Lv5以降に本人が選ぶ追加系統は、既定どおり解放済み・原料供給枠・設備・作業面の適合を条件とする。この表はその自由選択枠を固定する変更ではない。先行習得した難しい系統の推薦順位や低Lvへの負荷上限は別途検証する。

## 4. 高Lvほど必ず複雑な料理にする必要はない

Lv13のフライドポテトなど、料理単体は前Lvより簡単でもよい。営業の難しさは選択するもう一系統、注文の重なり、動線、配達判断とともに設計する。ただし簡単な料理の低基本点によって星・評判が不当に取りにくくならないよう、注文負荷・基本点・基準点の実測が必要。

この割当だけで難度曲線・経済・解放整合が検証済みとは扱わない。料理を難しくするためだけに確定した材料・工程を勝手に増やさない。
