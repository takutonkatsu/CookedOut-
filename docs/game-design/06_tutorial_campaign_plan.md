## 1. 目的

チュートリアルは説明文を読む場ではなく、短い営業を通じて一つずつ操作と判断を覚える章とする。

- 一つのステージで新しい主題を原則一つだけ導入する
- 新操作、新料理、新厨房ギミックを同時に複数追加しない
- 全ステージで最低一皿の料理完成と提供を必須にし、操作だけの独立訓練でクリアさせない
- 新しく教える機能は料理を完成・提供する経路に組み込み、その機能を使わなければ物理的またはルール上クリアできない配置にする
- 最初の実行だけはタイマーを停止または十分に延長し、成功後に通常の営業へ移る
- 長い会話、NPC説明、文章中心の画面を使わない
- 矢印、対象輪郭、手元アイコン、短いアニメーション、効果音、振動で伝える
- 一度学んだ操作は次のステージで説明を消し、実際の仕事として再利用させる
- 全ステージは後から自由に再プレイできる
- チュートリアル中は強制広告を表示しない

## 2. 一ステージの基本構造

1. 3〜5秒のカメラ移動で、新設備または新ギミックを見せる
2. 最初の一工程をアイコンと輪郭で誘導する
3. 正解操作まで注文タイマーを停止または大幅緩和する
4. 一回成功したら誘導表示を縮小する
5. 短い通常営業へ移行する
6. 星0〜3と、今回覚えた内容を絵で振り返る

誘導に従わなくても、危険でない範囲では自由に触れる。誤操作のたびに全画面説明を出さず、対象輪郭の点滅や短いアイコンで戻す。

### 3.1 1-1

- ダッシュと投げはまだ有効化しない
- 最初のレタス一件は注文タイマーを止める
- 10×8グリッドの中央へ3×2セルの作業島を置き、空間が広く見えすぎないようにする
- 作業島の周囲を一周でき、対象へ近づく、回り込む、置くという基本を自然に使わせる
- 初回注文完了後だけ、短い営業タイマーと二件目を開始する

### 3.2 1-2

- 最初の一鍋は食材を順番に輪郭表示し、投入完了まで注文タイマーを止める
- 鍋の加熱中に次の食材を切らせ、待ち時間を別作業へ使う感覚を教える
- 完成音、進捗円、湯気を同時に見せ、鍋を火から外すまでを一連の操作にする
- 誤料理は強制的に作らせず、発生した場合にゴミ箱を誘導する
- 注文失効は一回だけ安全な実演を許可し、永久ペナルティに見せない

### 3.3 1-3

- ソロでも投げが必要になるよう、低い壁の向こうに置き台を設ける
- 必要食材を投げて鍋へ投入した実績が揃うまで完成料理をバイクへ積めず、徒歩投入による学習工程の省略を許可しない
- 投げられる食材は対応する鍋へ直接投入でき、無効な器具には入らない
- 仲間による直接キャッチはマルチ初回ガイドで追加説明する
- 皿は投げられないことを、禁止アイコンで一度だけ示す
- 厨房練習後に同じステージ内の極短い直線路へ移り、バイクの乗降、四ボタン操作、積載、自前配達を一度ずつ行う
- バイク練習中は注文タイマーを停止し、交通、分岐、事故ペナルティをまだ出さない
- 星1獲得後にマルチロビーと初心者用出張営業群を解放する

### 3.4 1-4〜1-6

- 1-4で初めてダッシュを有効化する。再使用待ちは設けず、押すたびに短いダッシュを開始・継続できる
- 最初のサラダは提供口と調理区画の間にある逆走コンベアを越えなければ提供できず、通常歩行では進めないが連打ダッシュなら完成料理を運べる構成にする
- ダッシュ中も持ち物を落とさない。仲間や壁へぶつかると短く減速するが、硬直罰は小さくする
- 1-5では火災を強制せず、フライパンと焦げ予告の見分けを優先する
- 1-5で焦げた場合はフライパンを熱源からゴミ箱へ運び、中身だけを捨てて空のフライパンを熱源へ戻す復旧操作を行う
- 1-6冒頭だけ、失敗扱いにならない小さな誘導火災を発生させる
- 消火器は固定位置へ戻り、紛失しない
- 火災を消した後に通常営業を始め、復旧作業が罰だけに感じないようにする

### 3.5 1-7

- 皿洗いは現地提供型だけに登場する特殊ループだと明示する
- 洗浄中にアクションを離すと停止し、再開できることを一度体験させる
- 皿は投げられない。配達容器との違いを絵で見せる

### 3.6 1-8

- 一件目は配達代行、二件目は1-3で学んだ自前配達を指定する
- 三件目からプレイヤーが好きな経路を選ぶ
- 得点差だけで優劣を決めず、厨房へ残る時間と配達ボーナスの違いを結果画面で図示する
- 動的厨房は一種類だけ使い、変化前に床色、音、振動で予告する
- 初回変化は料理を失わない安全なタイミングで起こす
- 二回目以降は注文中に変化し、準備の必要性を教える
- 既習レシピだけを使い、新料理は追加しない

## 4. 1-3後に解放するマルチ

- ロビー、フレンド招待、準備完了、初心者用出張営業を解放する
- 初心者用ステージはサラダ、野菜スープ、投げ、自前配達までの既習要素だけで構成する
- ダッシュ、フライパン、火災、皿洗い、配達代行、動的厨房を必須にするステージは、対応チュートリアル完了前には一覧で未習得表示する
- ホスト解放済みステージへは、未習得要素があるゲストも参加できる
- 未習得要素はロビーでアイコン表示するが、開始前の強制実地ガイドは設けない。任意の操作・ギミック一覧はヘルプから確認できる
- 本店通常営業はまだ解放せず、1-8を星1以上で完了した時に解放する

## 5. 機能ごとの初回ガイド

第1章に入れると長くなりすぎる管理・オンライン機能は、初回アクセス時に30〜90秒で説明する。

| 発生条件 | 教える内容 | 方式 |
|---|---|---|
| 初めて本店へ戻る | コイン、厨房設備レベル、次の解放条件 | 強化できる一設備を点滅させ、初回だけ割引または無料で実行 |
| 初めて設備配置を開く | グリッドへの設置、回転、確定、通路封鎖不可 | 小さな練習配置。営業結果へ影響しない |
| 初めてマルチロビーへ入る | 招待、準備完了、ホスト選択、途中参加なし | 三画面以内のアイコン説明 |
| 初めてマルチ営業を始める | 仲間への投げ渡し、顔アイコン、切断復帰 | ロビーから任意閲覧できる操作カード。強制ガイドは出さない |
| 初めてデイリーを開く | 達成条件、更新時刻、受取 | 対象一件だけ強調 |
| 初めてランキングを開く | 人数別、対象ステージ、不正記録除外 | ランキング実装時に追加 |
| 初めて外見を変更する | 性能差なし、共通衣装とキャラクター部品 | 無料外見一つで試す |
| 初めて任意広告を見る | 任意視聴、報酬内容、閉じても不利益なし | 広告SDK実装後に追加 |

## 6. 後続章での新要素

新しい厨房ギミックは、毎回チュートリアル章へ戻さず、該当ステージ冒頭の短い安全実演で教える。

- 移動カウンター: 最初の一往復を注文開始前に見せる
- 回転厨房: 回転方向と停止位置を床矢印で予告する
- 落下床: 消える順番を点滅で見せる
- 滑る床: 安全な短い直線で一度滑らせる
- リフト: 到着予告、積載枠、出発時刻を最初の一便だけ強調する
- 背景移動厨房: 床は動かないことを操作開始前に一度示す
- 新料理: 完成画像、材料、工程アイコンを営業前カードで示し、最初の注文だけ猶予を延ばす

## 7. 表示と入力

- 文字は補助に留め、材料、操作、方向、禁止をピクトグラムで表す
- 対象輪郭は次に触る物だけを強調し、画面全体を点滅させない
- 仮想ボタンを初めて使う時だけ拡大パルスを出す
- 成功時は短い音、拡大、振動を組み合わせる
- 失敗時は赤色だけに依存せず、形、音、振動、煙等を併用する
- チュートリアル表示は設定から再表示できる
- 操作を一定時間検出できない場合だけ、次の手順を再表示する

## 8. 計測

ステージごとに以下を匿名イベントとして計測する。

- 最初の正解操作までの時間
- 誤対象の選択回数
- 同じ手順を三回以上失敗した割合
- 誘導表示の再表示回数
- 注文別の完成・失効・誤料理数
- 初回クリア率とリトライ率
- 各ステージの離脱位置
- 第1章完了までの総時間
- 完了後、通常営業またはマルチへ進んだ割合

## 9. 受入目標

数値は初期仮説であり、テスト結果から調整する。

- 各ステージの初回星1到達率80%以上
- 1-1のガイド注文完了率95%以上
- 同一操作で三回以上詰まるプレイヤー10%未満
- 1-3完了までの中央値10分以内
- 第1章全体の中央値25分以内
- 第1章完了直後、主要操作を説明なしで再現できる割合80%以上
- 「説明が長い」と感じる割合20%未満
