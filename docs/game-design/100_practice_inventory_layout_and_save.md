# COOKED OUT! 練習厨房の設備台数・編集・保存案 v0.1

- 作成日: 2026-09-14
- 状態: 2026-09-14、ユーザー承認で公開方針を採用。本人所有台数内・推奨は必要分・準備で原料箱等を並替え・系統ごと前回配置一つ・開始時保存・開始せず離れる時の保存確認・練習中移動の自動上書きなし・推奨復帰との分離が対象。保存の技術方式等の未公開細部は未確定。実装・実データ変更なし
- 既定: 練習は本人設備Lv、必要原料箱・設備の推奨配置を自動生成し編集可能、本店と独立、1キャラ、報酬なし。図鑑からの個別料理反復入口も採用済み

## 1. 台数も本人の所有範囲を使う案

設備Lvだけでなく、追加配置できる設備の種類と台数も本人の所有範囲内とすることを推奨する。練習専用の設備購入は不要。本店に配置済みの設備も練習で使用でき、本店から取り外したり在庫を消費したりしない。例えば鍋3台所有なら、練習でも合計3台まで配置できる。

推奨配置には選択内容の練習に必要な台数を置き、所有全台を自動で並べない。追加したい時だけ未配置の所有設備から足す。原料箱は設備購入台数と分け、必要な原料をゲーム側が供給する。

所有範囲で必要な調理・後片付けが成立するかを事前検証し、不足があるならその内容を示す。未所有設備の自動購入や、同じ器具の複製で突破させない。初回未同期時の基本練習セットは96の例外として維持し、本人の所有が取得できたかのようには表示しない。

## 2. 準備編集と練習中移動を分ける

準備では練習用の設置可能枠の中で、設備・原料箱を並べ替えられる案。固定会場をひとつ用意し、その中の配置を変える。本店や出張盤面の編集権限は変更しない。

練習中は既定の可搬／固定ルールを適用する。まな板やコンロ等は動かせるが、原料箱・水場等をプレイ中に持ち運べるようにはしない。建物外形・水場・提供口まで自由に作り替える建築モードは初期範囲に含めない。枠と通路の具体設計は別途。

## 3. 系統ごとに前回の準備配置を一つ保持する案

保存スロットを多数管理させず、一系統につき一つの前回配置を端末へ保持する。最初は推奨配置を出し、次回は同じ系統の保存済み配置を読み込む。図鑑から個別料理を選んで入る時も、その所属系統の配置を土台にする。60品別々の保存枠にはしない。

練習開始時に有効な準備配置を自動保存する。練習中に移動した結果は自動上書きしない。準備を編集した後に開始せず離れる時だけ、保存するか変更を破棄するかを確認する。編集を続けるために確認を閉じることもできる。無効配置は上書き保存せず不足を示す案。

本店・シーズンの配置と別保存で、共有URLの対象にも加えない。初期案は端末内保存で、機種変更時に練習配置まで復元する保証はアカウント・セーブ検討時に別途決める。本人設備Lvは保存配置の過去Lvへ固定せず、次の練習開始時に現在の確定した種類Lvを参照する。

## 4. 二種類の戻し方

- 練習中の「やり直す」：その練習を開始した時の配置と初期状態へ戻す。配置を工夫した分まで消さない
- 準備画面の「推奨配置に戻す」：自分の編集を初期推奨へ置き換える。変更前に確認し、保存は通常の準備保存ルールに従う

料理変更・追加習得で必要な原料や設備が変わった場合は、保存配置の使える部分を維持し、不足分だけ準備させる。適合するかの確認なしに古い配置で開始させない。初回推奨生成の再利用を含む補完アルゴリズムは未決定。

## 5. この方式の狙いと未決範囲

本人の能力・台数で練習するため、本番への持ち帰りが分かりやすい。一方、まだ買っていない設備を大量に試す自由な実験場にはならない。まず習得と配置の工夫を支える範囲に絞る。

所有不足時の具体セット、編集可能枠、系統内の個別レシピ間の必要品差分、保存のクラウド対応、障害時のキャッシュ整合は未確定。課金・設備販売・クラウド保存をこの案だけで実装しない。
