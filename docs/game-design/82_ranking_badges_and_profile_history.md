# COOKED OUT! ランキングバッジと実績の見せ方 v0.2

- 作成日: 2026-09-13
- 状態: 2026-09-14、公開した最大3枠・自由な付替えと並替え・プロフィールと協力ロビーで最大3個・小型ランキング行で先頭1個の表示も採用。具体造形・未公開細部は未確定、未実装
- 確定前提: シーズンはソロ専用。順位コインは控えめとし、主な報酬はランキングバッジ等の名誉。正当な過去実績はシーズン切替で消さず、性能差や購入による順位実績獲得は設けない

## 1. 好きなバッジを複数選んで表示する

一枠だけの旧案を撤回し、最大3枠を採用する。0〜3個を自由に選び、空き枠を埋める義務はない。付替え・並替えは自由で、先頭のバッジを小さい表示の代表にする。装着費用は設けない既定を維持する。

選択したバッジをプロフィール、出張営業の協力ロビー、個人ランキングの本人名の横へ小さく表示する方針は採用。プロフィール・ロビーは最大3個、狭いランキング行は先頭の1個だけを表示し、プロフィールを開くと残りも見られる構成を推奨する。シーズンはソロ専用だが、実績を友達との出張営業で見せられる。厨房プレイ中のキャラクター頭上や注文票には出さず、調理の視認性を優先する。

出張常設のチーム順位行へ個人の選択バッジを代表として付けない。チーム順位と個人の過去シーズン実績を混同させず、各メンバーのプロフィールで確認できる範囲とする。ランキングの現在順位表示はバッジで置き換えない。

## 2. 小さくても区分が分かり、詳細で実績を確認できる（公開方針を採用）

シーズンバッジは共通の基本形を使い、上位50／25／10／3／1%に応じた輪郭や飾りの違いを付ける。色だけで区別しない。アイコンの中へ年月・細かな順位・数字をすべて詰め込まない。

タップした詳細に「対象シーズンの年月」「最終順位／順位対象者数」「報酬区分」を載せる案。たとえば同じ上位1%バッジでも、何月の何位だったかを確認できる。過去シーズンのバッジであると分かる表現にし、現在のランキングの1位と誤認させない。

参加人数と同点で区分の実際の受賞割合が変わる場合も、最終確定時の事実を保存する。上位割合から後で順位を推定し直さない。1位専用の追加コイン枠を作らなくても、実順位は記念として残る。

## 3. 一時的な装飾ではなく、積み上がるコレクションにする（公開方針を採用）

月ごとに確定したシーズン実績とバッジを残し、次の月に低順位でも過去のバッジを下位版へ置き換えない。獲得後は自由に付け替えられ、期限や装着費用を設けない。新しいバッジ獲得時も、本人が選んだ表示中バッジを勝手に変更しない。

本人の履歴から各月の最終合計・4厨房の自己ベストを確認できるようにする。未挑戦は未挑戦として区別し、0点分を合計に使う既定を維持する。他人へ全履歴・個別厨房記録をどこまで公開するかは別途とし、まず装着バッジの実績詳細だけを共有範囲とする案。

第9章制覇バッジも同じ表示枠に選べるようにし、「シーズン順位の強さ」と「出張営業を遊び切った達成」のどちらを見せるか本人が選ぶ。第9章バッジ自体の星3による上位デザイン化の既定は変更しない。未解放第9章のバッジを本人の未獲得一覧へ先行表示して章をネタバレする仕様にはしない。
