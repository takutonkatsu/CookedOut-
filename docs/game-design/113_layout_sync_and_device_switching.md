# COOKED OUT! 配置保存・同期と端末切替案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、ユーザー指定の「同じアカウントで2端末同時ログイン不可」に修正して、その他の公開方針を採用。本店／シーズンの共通保存、練習配置の端末別保存、未同期配置の端末内保持、同期状態表示を採用。競合確認は同時オンライン編集ではなく、端末切替後の古い下書き復帰等への保護として残す。実装・認証サービス選定は行わない
- 既定: 確定済み進捗と資産は自動保存。本店・シーズンの保存配置はアカウントで復元。音量・操作設定は端末別。同時正式営業不可。結果同期待ち中は次の報酬営業と設備購入・強化を停止する。既定を再審議しない

## 1. 本番の配置は共有し、練習の配置は端末ごとにする

本店の保存枠・シーズン各課題の保存配置は既定どおりアカウント共通にする。機種変更後は同期済みの配置を復元できる設計とする。配置の明示保存と、進捗・資産の自動保存は区別する。

未決だった練習厨房の前回配置は、初期は端末ごとに保持する案。新端末では推奨配置から始め、必要なら編集する。同じ端末では既定の系統ごとの前回配置を保持する。練習で使う確定済み所有設備・種類Lv・習得料理はアカウント共通であり、練習配置をローカルにすることで性能や料理解放を初期化しない。

練習配置も引き継ぎたい人には不便があるが、オフライン練習同士の配置競合を初期に管理させずに済む。音量・ボタン配置等も既定どおり端末別で、機種変更時に自動上書きしない。

## 2. 同じ保存枠を別端末で変更していたら、無断上書きしない

同じアカウントの同時ログインを禁止するため、二端末が同時にオンライン編集する使い方は認めない。端末Aの未同期下書きが残ったまま端末を切り替え、後日Aへ戻った時など、古い配置が遅れて届く場合だけ競合確認を行う。最終送信時刻だけでAの古い状態を無条件採用したり、二つの盤面を自動合成したりしない。有効でない旧ログイン状態のまま保存は受け付けず、再ログイン後に確認する。

最新版と今回編集した配置をプレビューで比較し、「最新版を使う」「今回の配置で上書き」を本人が選ぶ案。上書きは明示確認し、現在の所持台数・配置制約を再確認する。本店で別枠に残したい場合は既定の保存枠選択を使い、枠数を無制限に増やさない。選択するまで編集内容は破棄しない。

競合を検出して比較・選択する仕組みは配置だけを対象とする。コイン・評判・解放・設備Lv等について利用者に新旧セーブを選ばせたり、都合のよい値を合算したりしない。これらはサーバーで確定した取引・結果に従う。

## 3. 通信待ちでも無料の配置編集はできる

未同期営業結果がある時や通信不可時も、保存済み情報を使って無料の配置編集を行える案。編集結果は端末内へ一時保持し、サーバーへ届いていない間は「端末に保存・同期待ち」等の短い状態を示す。クラウド保存完了とは表示しない。

再接続後、元の保存枠が変わっていなければ同期し、他端末が同じ枠を変更していれば第2項の確認を行う。結果同期待ちで設備購入・強化を止める既定は維持し、未確定の報酬や未所有設備を利用可能にしない。編集できることを、正式営業のオフライン開始許可とは扱わない。

端末内保持は追加の正式な配置プリセット枠ではなく、未同期編集の復旧用とする。クラッシュ耐性・容量・保持期限・複数枠を編集した場合の管理は実装設計と障害試験で詰める。

## 4. データ引継ぎ前に、連携と同期の状態を確認できる

設定のアカウント欄に「連携済みか」と「同期が完了しているか」を短く示す案。機種変更前に確認できるようにし、営業結果・配置等が未同期なら完了したように見せない。毎起動の確認画面や、無料プレイに新しい連携必須条件は加えない。

端末内にしかない未同期結果・配置は、新端末でログインしただけでは届かない。旧端末での同期完了を案内する。旧端末を紛失した場合の完全復元は約束せず、サーバーで確認できる情報に基づく復旧手順を別途定める。アカウント切替・削除時の具体処理は今回一括確定しない。

## 5. 範囲外・検証

認証先、バックアップ技術、実際のオフライン永続化保証、切替・連携解除・削除、購入権復元、問い合わせ本人確認、排他期限の具体値。二端末同時保存・古い配置の遅延到着・アプリ終了・結果同期との競合を検証する必要がある。提案のみで安全性を検証済みとは扱わない。
