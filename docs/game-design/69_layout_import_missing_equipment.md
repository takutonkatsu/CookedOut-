## 1. 不足があっても、所持分だけ取り込める

| 状態 | 推奨する扱い |
|---|---|
| 同じ設備を必要台数所有 | 自分の種類Lvで配置。相手のLvは引き継がない |
| 種類は所有、台数不足 | 所持分を配置し、残りの位置は空白。所持分をどの位置に置くか編集できる |
| 種類が未所有・未解放 | 位置は空白。自動購入・自動解放しない |
| コピー元で使わない所有設備 | 自分の未配置一覧へ戻す。削除しない |

例：コピー元にミキサー3台、自分は1台なら1台を配置し、残り2台の位置は空白にする。最初の割当は一貫した座標順等を後で決め、最適位置だと保証しない。空白は設備がないという意味で、下地の作業台・床を削除する意味ではない。不足用の輪郭・幽霊設備・盤面上の鍵を追加しない。

プレビュー・編集・保存は自分の所持分で成立する配置を扱う。保存対象は実際に配置した設備だけとし、別の「将来の設計図」機能は追加しない。外部の共有URLをタップしてプレビューを開き、そこから編集・保存する。ゲーム内にURL入力・貼付け用の「リンクから取り込む」ボタンは設けない。プレビューで取り込みを確定する操作は残し、リンクを開くだけで上書きしない。

未知の設備ID、不正座標、非対応テンプレート・版は、単なる未所有と区別し、安全に読み込めない配置として理由を示して中止する。必要なら更新を案内し、現在配置を破壊しない。

## 2. 保存・営業開始の扱い

### 2-A. 読み込みだけでは本店を変更しない

プレビュー→取り込み編集→保存の順。保存は既存3枠から明示選択し、上書き時のみ確認。取消なら従来配置を保持。共有機能専用の追加保存枠を設けない。コピーで余った所持設備は保存確定までは編集上の仮在庫として扱う。

### 2-B. 不完全配置を保存できるが、開始条件は別

不足があっても実物部分だけ保存できる。選択中の献立に必要な設備・容器供給と、既存の通路・到達可能性等の開始条件を満たす時だけ営業開始可。コピー元と完全一致する必要はなく、使わないミキサー等が不足していても開始を止めない。推奨Lv未満だけを理由に開始不可にしない既定を維持する。

不足時は設備の絵と短い理由で示し、該当設備の準備へ進める入口を設ける。自動購入や献立変更はしない。

### 2-C. コピーのたびに解説を挟まない

本店準備の保存配置一覧に共有ボタンを置く。受取りは外部の共有URLタップから行い、ゲーム内にリンク入力の入口を置かない。正常ならプレビューから進める。不足・互換性・上書きなど判断が必要な時だけ短く説明する。営業中にリンクを開いても盤面へ即時反映せず、営業後に確認する。

## 保留

- 同種設備の初期割当順、付属器具を含むシリアライズ、固定要素との厳密な照合
- 保存前のアプリ終了時の編集中データ保全、共有リンク寿命、サーバー方式
- UI実装・新規アセット・ステージ構成変更は行わない
