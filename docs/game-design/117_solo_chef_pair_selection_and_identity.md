# COOKED OUT! ソロ出張の料理人ペア選択と識別案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、公開4点をユーザー承認で採用。本人用キャラ＋相棒、準備画面の二つの顔から変更・前回保持、色＋形で識別し操作中を強調、開始・リトライは1人目から。初期配布・具体アート・寸法等は未決。キャラクター・UIは未実装
- 既定: 通常営業・シーズン・練習は1キャラ、ソロ出張は2キャラ切替、マルチは一人1キャラ。全動物は能力・当たり判定共通。56の切替・配送中停止・非操作作業継続・帰還時の選択維持は変更しない

## 1. 本人用の料理人と、ソロ出張用の相棒

1人目は通常営業・マルチ・シーズン等で本人が使う選択キャラと共通にし、2人目はソロ出張専用の相棒として選択を保持する案。相棒も同じアカウントの利用可能な動物・衣装から選び、別のプレイヤー登録や専用育成を要求しない。

同じ動物・同じ衣装の組合せも許可し、選べる動物が一種類でも2人で遊べる。初回は利用可能な外見から既定の組合せを設定し、選択操作をしなくても開始できる。初期配布の動物種類・頭数・入手経路はこの案で確定しない。

「本人」「相棒」は選択枠の区別であり、仕事内容・調理速度・得点・配送担当を固定する職種ではない。プレイ中は既定どおりどちらでも調理・配達ができる。相棒に別名・別バッジ・別経験値を設定する機能は初期必須にしない。

## 2. 準備画面の二つの顔から変更できる

ソロ出張の準備画面へ二つの顔をまとめて表示し、各顔を押すとその枠の動物・衣装を選べる案。前回選択を保持し、営業ごとに選び直したり、専用の選択画面を強制表示したりしない。

1人目の変更は本人用の共通外見へ反映し、2人目だけの変更は本店等で使う本人の外見を変えない。本人枠を他モードで変更した場合も、次のソロ出張準備で更新する。同期や画面反映の具体実装は別途設計する。

衣装の新しい購入・貸出導線は追加せず、利用可能なものの選択だけを扱う。営業開始後は外見を変更できない。料理・ステージ確認と同じ準備画面で扱い、出張盤面・ギミックは開始前に見せない。

## 3. 色と形で二人を区別し、操作中だけ強調する

二つの選択枠に色＋簡単な形の識別マークを割り当て、準備画面の顔、足元、配送状況の顔で対応を一致させる案。同キャラ同衣装でも区別できるようにし、衣装や毛色を強制変更しない。

現在操作中の料理人は、既定の輪郭・足元マーカー・顔アイコンで強調する。切替によって強調だけを移し、二人の識別色と形そのものは入れ替えない。具体寸法・色・形・表示位置は実機検証する。

切替は既定の専用入力のままとし、顔を押す新操作・分割画面・常時ライブ小窓・指示メニューはこの案では増やさない。長い名前や相棒用バッジを厨房の頭上へ常時表示しない。

## 4. 開始とリトライは1人目から揃える

毎回、1人目を操作対象として開始する案。前の営業で最後に触ったキャラを引き継がず、リトライも同じ初期条件にする。各面の二つの初期配置枠と料理人の対応は固定し、ランダムで左右を入れ替えない。

外見の選択は初期配置枠の場所を変更せず、開始前に好きな位置へ置ける機能や事前盤面表示にはしない。具体スポーン座標はステージ側で設計する。

営業中、非操作側の作業完了・帰還だけで操作対象を自動変更しない56の既定を維持する。初期選択の統一と、営業途中に選択を奪わないことを区別する。

## 5. 未決・範囲外

初期キャラ配布内容・入手方法、選択画面のアート・実寸、識別色・形、切替ボタンの最終位置、初期配置座標。相棒の独自性能や雇用・給料・育成システムは追加しない。料理・ステージ配置・切替操作の実装変更をこの提案だけで行わない。
