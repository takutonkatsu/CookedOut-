# COOKED OUT! 通常営業前・設備ショップ・配置編集UI仕様 v0.1

- 更新日: 2026-09-11
- 状態: 情報構造と遷移を決定。画面寸法はiPhone実機で調整
- 前提: 本店厨房は12×9固定、配置プリセット3枠、献立候補3セット

## 1. 営業開始までの最短導線

```text
本店ホーム
  → 通常営業
  → 献立候補を一つ選ぶ
  → 設備確認・配置
  → 営業開始
```

前回と同じ献立・有効な配置なら、「前回の条件でもう一度」から確認画面を一枚省略できる。初回、新設備解放後、必須設備不足時は省略しない。

## 2. 献立選択画面

横持ち画面の中央に3枚の候補カードを並べる。

```text
┌ 戻る ───── 通常営業 ───── コイン・店ランク ┐
│                                                │
│  [候補1]       [候補2]       [候補3]          │
│  完成品         完成品         完成品            │
│  必要工程       必要工程       必要工程          │
│  難度・報酬     難度・報酬     難度・報酬        │
│                                                │
│             [この献立を選ぶ]                    │
└──────────────────────────────────────────────┘
```

各カードに表示するのは、完成料理1〜3個、主要工程アイコン、難度Tier、目標時間、報酬目安である。材料の完全一覧と設備不足は選択後に表示し、三枚を細かい文字で埋めない。

## 3. 設備確認・配置画面

左約70%を12×9厨房、右約30%を情報パネルにする。下端はドラッグ操作とホームインジケータの余白を取る。

```text
┌ 戻る ─ 献立名 ─ プリセットA/B/C ─ 元に戻す ┐
│                               │ 必須設備       │
│       12×9厨房プレビュー       │ 推奨設備       │
│       ソケットと動線表示       │ 配送方式       │
│                               │ 警告・不足     │
│                               │                │
├ 設備トレイ：まな板 鍋 フライパン … ────────┤
│ [推奨配置] [保存]              [営業開始]      │
└──────────────────────────────────────────────┘
```

- タップで設備を選び、有効ソケットを強調する
- ソケットをタップして配置し、配置済み設備を再タップして回転・外す
- ドラッグも許可するが、タップだけで全操作を完了できるようにする
- 必須設備不足は赤色だけでなく、欠品アイコンと短い文で示し営業開始を無効化する
- 推奨未満は黄色相当の警告に留め、営業開始を許可する
- 「推奨配置」は所有設備内で決定的に生成し、適用前後を一回だけ戻せる
- プリセット保存時は既存枠の上書きを明示する。自動保存だけにしない

## 4. 設備ショップ

設備の「種類Lv強化」と「追加台数」を同じカード内で分ける。

```text
┌ 店づくり ─ [設備] [外見] ─ 所持コイン ┐
│ まな板  Lv2  所有2/3                   │
│ [Lv3へ：時間84%　750] [3台目：450]    │
│ 解放条件：店ランク5                    │
│                                        │
│ 鍋 Lv2  所有1/3　「専用熱源付き」      │
│ [Lv3へ：加熱88%　750] [2台目：360]    │
└────────────────────────────────────────┘
```

- 鍋とフライパンは熱源付きの一枚のカードにする
- 未解放設備は、出張営業の該当ステージを短く示す
- ランク不足は必要ランクを表示し、コイン不足と混同させない
- 購入前に、数値変化、購入後の所有数、厨房へ置けるかを表示する
- 厨房面積、固定作業面、ソケットは販売しない
- 購入後は「配置へ移動」を表示するが、自動で現在のプリセットを上書きしない

## 5. 店ランク画面

表示項目は現在XP、次ランクまで、次の設備Lv上限、追加台数上限、通常営業Tier、節目報酬とする。厨房拡張は表示しない。

ランクアップ時の見せ方:

1. 新しい上限またはTierを大きく一つ表示
2. コイン・外見の節目報酬を表示
3. 新しく購入可能な設備カードへ直接移動できる

## 6. エラーと復帰

- 無効配置を保存しようとした場合も編集内容は失わず、該当設備と理由へフォーカスする
- 献立変更で現在配置が不適合になっても削除せず、「自動補完」「別プリセット」「献立へ戻る」を出す
- 通信失敗時は購入を二重送信せず、取引IDで結果を再照会する
- 営業開始送信中は配置編集をロックし、二重開始を防ぐ

## 7. 分析イベント

- 候補3枚の表示内容と選択結果
- 推奨配置の適用・取消・手動変更数
- 必須不足・推奨不足の発生と離脱
- ショップカード閲覧、購入、コイン不足、ランク不足
- プリセット保存、上書き、呼出し、互換性エラー
- 営業開始までの所要時間
