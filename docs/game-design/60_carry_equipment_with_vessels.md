# COOKED OUT! 器具を載せたままの設備移動仕様 v0.2

- 作成日: 2026-09-13
- 状態: 2026-09-13ユーザー「良いです。次に行きましょう」により、公開した一式運搬、短押し指離し確定、中身入り・調理途中の運搬、運搬中停止と進捗保持、火災時は消火優先を採用。具体的な長押し時間・競合処理・場外復旧は検証／検討待ち。未実装。本文の「案」は承認範囲に限り採用として読む

## 1. 同じ長押しで本体を運ぶ

手ぶらの時、「取る／置く」の短押しは上の鍋・フライパン・ジャーだけ、短い長押しは本体とその上の器具を一式として持つ案。本体しかなければ、同じ長押しで本体だけを運ぶ。短押しで空の本体を取得する別ルールは設けない。

一式は一つの手持ち枠を使い、他の料理・設備は同時に持てない。空き作業台へ置けば一式で設置される。空き台以外への自動交換や、既存コンロへの一式重ね置きはしない。通常速度、設備一式の投擲・ダッシュ不可という既定の設備運搬方針を使う。器具だけを持った場合は既存の通常運搬規則を使う。

## 2. 食材入り・調理中も運べる推奨案

器具が空の時だけでなく、中身入り・加工途中・完成後も一式運搬を許す。炎が出ている設備は消火が先。焦げ済みで未発火の中身を運んでも、食べられる状態には戻らない。

一式を実際に持ち上げた時に熱源・モーターを停止する。運搬中は加熱・混合・焦げ・未発火からの発火猶予の進行を止め、再設置で保持した状態から再開する。完成後のミキサーは停止したまま、完成後の鍋等を再設置すると焦げ方向への進行が再開する。停止中に進捗や焦げ猶予をリセット・回復しない。

注文・営業・配送の時計、別の設備の調理は進む。ソロの非操作キャラが一式を持って待機しても機械は停止したまま。持ち歩きながら加工する方式にはしない。

長押し判定中はまだ設備が設置されているため、調理も焦げも進む。長押し中に発火した場合は一式取得を拒否し、短押し取得へ代替しない。単なる入力開始で世界状態を止めない。

鍋だけを外す既存の保温運用に加えて、一式でも安全に退避できるため、焦げ回避の自由度は上がる。その代わり人の手と作業時間を使う。設備一式による退避が常に鍋単体より有利にならないか、空き台・運搬時間を含めて検証する。

## 3. 短押し即時取得との両立には変更が必要

同じ対象・ボタンで短押しと長押しを区別するため、ボタンを押した瞬間に器具だけを確定取得する旧規則は、その対象に限って維持できない。

第一試験案は、押した時点で輪郭・押下表現を即時に返し、短押しは閾値前に離した時に器具だけを取得、長押しは閾値到達時に一式を取得する方式。短押しに長押し閾値までの待ちを強制せず、短いタップを離せばすぐ取得する。長押し成立後の指離しで二回目の取得・設置は起こさない。

この変更は本体と上の器具を選び分ける対象に限定する。普通の食材取得、材料投入、配膳、手持ち状態での置く操作は一律に遅延させない。押下時に器具を実際に持ち上げて後で一式へ差し替える方式は、加熱停止や他プレイヤーとの競合を生むため第一案にはしない。

長押し時間は実機で決める。焦げ直前に器具だけを外す時の遅れ、長押しの誤発火、移動しながらのタップ、指が操作範囲を外れた場合を試験する。

## 4. 競合と安全性

押下時の対象を保持し、移動で届かなくなった・対象が変わった・別プレイヤーが取得または材料投入した場合は、その操作を中止して再入力を求める。別の物や新たに置かれた器具を黙って取得しない。長押しで仲間の設備を予約し続ける仕組みにはしない。調理進捗の自然な更新と、所有・内容物・取付け状態の変更は区別する。

取得時に本体・器具・中身を一緒に移し、同じ器具が台と手の両方へ残らないことを必須とする。投擲、落下、再接続、自動復旧による設備や料理の複製は不可。場外時の食品損失と本体復旧の細部は既存の未決事項として残す。
