# COOKED OUT! 描画性能・省電力と実機検証の目標案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、公開方針をユーザー承認で採用。標準60fps目標・省電力30fps、二つの設定、主要な視認性保持、描画設定でルールを変えない、5営業20分以上の初期試験。ユーザー指定でiPhone・iPadを対応対象とする。macOSは非対応の方向。性能測定・Unity設定変更は行わない
- 既定: iPhone／iPadで横持ち、厨房全体カメラと配達用カメラ、簡単な操作と視認性を重視。操作・音等の設定は端末別保存。最低対応機種・最低OSは未確定
- 確認待ち: ユーザーへ手元のiPhone／iPadの機種を質問済み。返答前に所持機種を推測しない。実機の追加購入を依頼したものではない

## 1. 標準60fps目標、省電力30fpsを用意する

厨房・配達とも、標準設定は60fpsを目標とする案。初期版で120fps対応を目標に加えず、継続的な安定動作を優先する。設定に30fps目標の省電力モードも用意する。

これは目標値であり、全対応端末・発熱状態で60fpsを保証したという意味ではない。実機で低性能側は省電力設定でも安定して操作できるかを確認し、成立しない機種は対応下限の見直し対象にする。端末の具体的な除外方法やOS下限は今後選定する。

Unity公式のiOS向け説明では、targetFrameRateによる描画レート制御と、レート低下による電力・発熱対策が示されている。ただし低減幅はゲーム負荷・端末条件によるため、設定だけで効果を達成済みとはしない。資料は末尾を参照。

## 2. 画質を細かい項目だらけにしない

初期の利用者向け選択は「標準」「省電力」の二つを推奨する。設定から任意変更し、端末別に保存する。変更反映は営業・練習の開始前を基本とし、営業前に毎回選ばせる画面は作らない。

内部では負荷に応じた画質段階を設計し、必要なら背景の装飾、影の精細さ、不要な粒子表現等から軽くする。料理の識別、注文票の文字・材料、危険予告、操作対象表示は保つ。火災を消して見せたり、当たり判定のある障害物を非表示にしたりしない。

負荷対策でゲームのコミカルな見た目自体を別物にするのではなく、識別しやすい主要形状を共通にする。具体的な自動画質調整・描画解像度・影設定・発熱時挙動は実装と実機試験で決める。

## 3. 描画設定でゲームのルールを変えない

30fps／60fpsで移動・調理・注文・配送の時間、物理の基本挙動、得点・星基準を変えない設計とし、実際に比較する案。画面更新回数をそのまま料理の進行や入力回数報酬へ使わない。

描画負荷とゲーム処理を分けたとしても、見た目の滑らかさ・入力の感じ方まで完全に同じとは保証できない。特にバイク運転・投擲・一式移動・二キャラ切替を両設定で試す。省電力設定でも主要操作が困難なら、調整してから対応対象に含める。FPS別ランキングは今回作らない。

## 4. 初期の連続プレイ試験は5営業以上

開始直後だけでなく、4分営業を5回続けた20分以上のプレイを初期の試験単位にする案。準備時間を含む実際の経過時間は別記録にし、20分一回で全て合格としない。より長い耐久・ネットワーク・メモリ試験は122の別項目として残す。

4人協力で料理や設備が多い状態、火災等の演出が重なる状態、街の配達、通常営業の設備が多い配置等を対象にする。平均FPSだけでなく瞬間的な引っ掛かり、入力応答、メモリ、端末の熱状態、電池消費を確認する。計測条件として画面輝度・充電有無・周囲温度等も記録し、条件の違う測定値を混同しない。

手元の機種を確認し、小画面・性能下限候補・標準的な端末の試験役割を割り当てる。ユーザー指定によりiPhone・iPadの両方を対応目標として検証する。対応目標の採用と、実機で対応確認済みであることは区別する。具体的な所持機種はまだ回答されていない。

## 5. 未決と情報源

最低機種・最低OS、初期設定の自動選択、フレーム時間の許容分布、入力遅延上限、メモリ・熱・電池消費の合格値、テスト台数は未決。サービス・実装環境の対応情報を確認してから具体化する。iPadの画面適応は124で相談する。

技術的根拠として2026-09-16に確認した一次資料:

- [Unity 6.0 Application.targetFrameRate](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Application-targetFrameRate.html) のiOS節。iOSでの描画目標レート制御、電力・発熱対策、画面のリフレッシュレートによる制約を確認した。プロジェクトのUnity版をこの資料へ変更する指示ではない。

60／30fps、設定二種類、5営業という値は本ゲームへの設計提案であり、公式資料が本作品に指定した基準ではない。未測定の達成保証や対応端末の購入推薦を行わない。
