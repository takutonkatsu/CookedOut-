# COOKED OUT! 器具の互換性と能力・進捗の所属仕様 v0.2

- 作成日: 2026-09-13
- 状態: 2026-09-13ユーザー「良いと思います。次に行きましょう」により、公開した共通コンロ、同種本体間のジャー・トレー共用、付属品の個数維持、能力の参照先、器具交換時の進捗保持、単体ジャーの途中停止・再開を採用。未実装。本文の「案」は公開承認範囲に限り採用として読む。59の強化対象・昇格条件等は引き続き別相談
- 前提: 60の設備一式運搬は採用済み。種類別Lvと付属熱源の非独立販売を維持する。59の強化9種類化・昇格条件を今回承認した扱いにはしない

## 1. 買った相手への専属をなくす

鍋とフライパンは、どの空き卓上コンロにも置ける案。鍋購入に付属したコンロでもフライパンを使用でき、その逆も可能とする。コンロは共通の熱源であり、鍋料理／フライパン料理の違いは上に置いた器具が決める。

ミキサージャーはどの空きミキサー本体へも、オーブントレーはどの空きオーブンのドックへも戻せる。同種設備間の共用であり、ジャーをコンロへ置く等の異種互換を認める意味ではない。フライヤーかごは既定の固定式のままで運搬・交換しない。

対象が埋まっていれば自動交換せず手持ちを維持する。設備一式を別の設備の上へ重ねる操作も不可。器具単体を載せる時の通常の置く入力を使い、新しい交換画面や確認を設けない。

## 2. 付属品の数と占有

初期営業開始時は、配置した鍋・フライパン一式ごとに器具一つ＋熱源一つ、ミキサー一台ごとにジャー一つ、オーブン一台ごとにトレー一枚を備える案。共用可能でも生成数は増えない。ジャー・トレー・熱源の単体追加販売は初期案にしない。

別の本体へ器具を移した後、元の本体に新しい器具が自動補充されることはない。同じ器具を使える本体は一度に一台だけ。追加台数の購入が必要かどうかは従来の同時加工枠・配置判断で決まる。未配置設備の付属品だけを持ち出して初期盤面の道具数を増やす仕組みは別途明示承認なしに導入しない。

## 3. 能力はどこで決まるか

- コンロ自体はLvを持たず、鍋の調理は鍋種類Lv、フライパンの調理はフライパン種類Lvを使う。鍋の強化でフライパンを高速化できない。
- 混合速度は使用中のミキサー本体の種類Lv、焼成速度は使用中のオーブンの種類Lvを使う。ジャー・トレーに個別Lvを付けない。
- 同種の本体には営業開始時にそのモードの設備条件を適用し、同一営業で元の購入者の個体Lvを持ち回らない。通常営業は本人の種類Lv、出張は固定条件、シーズンは選定済みロードアウトに従う。追加3設備へのLv適用自体は59の未承認案である。

これにより共用器具に所有者名・所属番号・Lvラベルを増やさず、設置可能な対象輪郭で扱える。異なる性能の同種本体が混在する特別ステージは今回新設しない。

## 4. 途中の料理は器具と一緒に移る

中身、投入済み材料、加工進捗、完成・焦げ状態と残り猶予は、鍋・フライパン・ジャー・トレー側で保持する案。本体を変えても進捗は最初からにならず、焦げ猶予も全回復しない。器具も料理も複製しない。

ミキサージャーを単体で取り外した場合も、混合を止めて進捗を保持し、対応する本体へ戻すと再開する案。完成物は戻しても混ぜ直さない。鍋等の単体退避は既定どおり熱源から外れれば加熱・焦げ進行を止める。

オーブンの焼成途中にトレーを取り出せない料理側の既定は維持する。共用可能とは、上部へ出ている取り外し可能なトレーを別ドックへ運べる意味であり、焼成途中の強制取出しを追加しない。完成トレーを別オーブンへ載せただけで自動再焼成しない。開始・取出しの作業ボタン方式を維持する。

## 5. 面白さと検証

手前のコンロを空け、奥のコンロへ鍋を移す、空いているミキサーへジャーを戻す等の工夫を可能にする。「元の機械へ返す」暗記を減らす一方、専用コンロ間の距離を制約として使う旧ステージ設計は見直しが必要。

固定原料箱・提供口、作業台の島、空き面積、器具数は引き続き制約として残る。共通化で全設備を一か所へ集めるだけが最適にならないかを盤面で確認する。

検証項目: 同種本体間の移し替え、鍋とフライパンの熱源交換、完成・焦げ警告直前の移動、満員ドックへの入力、二人の同時取得、一式運搬から単体運搬への切替、ジャーだけを戻した時の二重生成がないこと。

料理タスクのジャー・トレー共用に関する保留事項へ対応する全体提案として保存する。料理専用資料を独断で書き換えず、承認後に整合する。
