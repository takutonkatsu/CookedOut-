# COOKED OUT! 図鑑の並び順と未習得表示案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、未解放章の招待先で習得した料理は「完成画像＋鍵、料理名・材料・工程を閲覧可」へ修正して公開方針を採用。その他の固定順・未習得表示・閲覧位置保持も採用。続く116も承認され、鍵は章未解放を示すだけで新しい利用制限を追加しない方針に確定
- 既定: 3行横スクロール、同系統3品を縦一列、完成画像タップで共通詳細、マルチから練習不可、基本点は表示しコンボ等の細かい計算は非掲載。レシピ定義や解放条件は料理台帳と共通進行仕様に従う

## 1. 位置を覚えられる固定の並び

左から106の定番初登場営業Lv順（初期20系統）に並べ、同じ系統の縦3枠は上から基本1品目・基本2品目・3品目とする案。営業Lv順は表示整理の内部基準であり、図鑑利用に通常営業やそのLvの解放を要求する意味ではない。ソロ／協力の料理習得条件を変更しない。

習得順・使用頻度・最終閲覧順で自動的に並べ替えない。新章で系統を追加する時も基本は末尾へ足し、既存の料理位置を維持する。系統名は列見出しとして短く添えられるが、系統選択画面を挟まない。料理名・原料・基本点を全て一覧へ常時併記せず、詳細画面で確認する既定を維持する。

## 2. 未習得は本人の進行に応じて二段階で見せる

配信済み本編の料理枠は並びを固定して用意する。習得済みで本人が対応章も解放済みなら、通常の完成画像で表示する。

本人が自力でその章を選べる状態になったら、その章で習得できる未習得料理は完成画像＋鍵で予告する案。押すと料理名と習得先のステージを示す。材料・工程等の通常の詳細閲覧は習得後とし、未習得枠に練習ボタンは設けない。表示のみで恒久解放しない。

本人がまだ章を解放していない料理は、詳細を特定できない共通の伏せた枠＋鍵に留め、料理名・工程・先の面番号は出さない。未公開アプデの料理枠は先行表示しない。S面の存在や解放条件を図鑑から先に公開する導線は作らない。

ユーザー修正により、未解放章への招待先で正規に習得した料理は、本人の章が未解放でも「完成画像＋鍵」で表示し、料理名・材料・工程等の共通詳細を閲覧できる。未習得の伏せ枠へ戻さず、学んだ内容を見返せるようにする。単なる招待や説明閲覧だけでは恒久習得しない。

65の既定では先行正規クリアによるレシピ・設備種類解放を即時反映し、通常営業のLv・設備条件は別途判定する。116の承認により鍵は本人の章未解放の印とし、習得済み料理の練習と本店の既定利用条件は維持する。章解放後は鍵だけを外し、再習得・報酬再付与は行わない。

## 3. 招待先で必要な料理説明は例外として見せる

未解放章への招待でも、その営業の料理画像からは既定の共通詳細（材料・工程・基本点）を見られる。図鑑の伏せ表示を理由に、参加中の料理の作り方まで隠さない。

説明を見ただけでは自分の図鑑で恒久習得した扱いにせず、正規クリアで習得したものは第2項の表示にする。先行クリアの固有解放即時反映と、本人の章選択の前提待ちは65の既定に従って区別する。マルチから専用練習への遷移禁止は維持する。後日検討のロビー内調理遊びは今回決めない。

## 4. 戻ると見ていた位置を保つ

料理詳細を閉じると同じ列・スクロール位置へ戻す。ホームから開く図鑑も、同じ端末では前回の閲覧位置を保持する案。新端末では先頭からでよく、閲覧位置の端末間同期は不要。

新習得の小さな未確認マークは既定どおり表示するが、習得のたびに一覧を強制スクロールしたり、全件確認を要求したりしない。営業前の料理画像から直接開いた詳細を閉じる場合は元の準備画面へ戻し、図鑑一覧へ迂回させない。

## 5. 未決・検証

一画面の列数、画像寸法、鍵・伏せ枠のアート、長い料理名の表示、一覧のスクロール補助、検索・お気に入りの追加可否。料理と章の表示条件は最新台帳・先行クリア規則と照合してテストする。本案でレシピ・献立・章構成・料理の実際の習得条件を変更しない。
