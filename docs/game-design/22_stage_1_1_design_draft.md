# COOKED OUT! 出張営業1-1「はじめての一皿」詳細仕様案 v0.1

- 更新日: 2026-09-12
- 状態: 相談中。盤面候補と人数別設備を選択後に確定
- 初回対象: ソロ必修
- 再プレイ: 1〜4人、常設人数別ランキング対象

## 1. この面の存在理由

一つのレタスサラダを完成させ、厨房の最小文法を身体で覚える。

```text
移動 → 対象へ向く → レタスを取る → 置く
→ 作業を押し続けて切る → 容器へ入れる → 提供する
```

速さや複数注文より、「ボタンを押した時に何が選ばれたか」「持ち物がどこにあるか」を理解することを優先する。

## 2. 基本条件

| 項目 | 初期案 |
|---|---|
| 厨房 | 固定厨房、現地提供型 |
| 規模 | 10×8 |
| 料理 | グリーンサラダ一種類 |
| 新操作 | 移動、自動対象、取る／置く、継続作業、容器への組立、提供 |
| 使用不可 | 投げる、ダッシュ、鍋、フライパン、バイク |
| 初回安全注文 | 一件。完成・提供まで注文時計停止、採点対象外 |
| 採点営業 | 安全注文後120秒 |
| ギミック | なし |
| 初期星ライン | 1人60／110／150。多人数値は既存数値表を仮使用 |

## 3. 盤面候補

### A — 中央島パイプライン（推奨）

- 外周上側にレタス、提供口、容器を置く
- 中央3×2島にまな板二つ、組立面、仮置き面を置く
- ソロは島を回り込むことで移動・向き・置くを自然に覚える
- マルチは左右のまな板、運搬、容器、提供へ分かれられる
- 1-1として単純だが、COOKED OUT!らしい密な正方形厨房の基準になる

### B — コの字・最短学習

- 設備をほぼ外周へ置き、中央を広く空ける
- 最も迷いにくいが、受渡し、衝突、回り込みがほぼ起きない
- 操作検証専用としてはよいが、正式1-1の楽しさが弱い

### C — 調理と仕上げの二工程

- 左を食材・切断、右を容器・提供として明確に分ける
- 多人数の分業は強いが、最初から受渡しの理解まで要求する
- 第2章以降の協力面へ転用する方がよい

## 4. 推奨Aの設備構成

| 設備 | 数 | 役割 |
|---|---:|---|
| レタス箱 | 1 | 材料取得 |
| まな板 | 2 | ソロの予備、多人数の並列作業 |
| 組立・受渡し面 | 1 | 容器と切ったレタスの合流 |
| 通常カウンター | 7前後 | 仮置き、島形成、画面密度 |
| 共通容器供給 | 1 | 空容器取得 |
| 現地提供口 | 1 | 完成品の提供 |
| ゴミ箱 | 0 | 1-2で誤料理とともに正式導入するため、1-1では不要 |

まな板は全人数で二台を表示する案を推奨する。初回ガイドでは手前側一台だけを輪郭表示し、二台目は説明しない。これによりソロの情報量を増やさず、1-1の多人数ランキングでも仕事を作れる。

## 5. 初回ガイド

1. 3秒以内のカメラ移動で、レタス箱、まな板、容器、提供口を順に見せる
2. 左スティックだけを表示し、レタス箱へ近づかせる
3. 対象輪郭が出た後に取る／置くボタンを表示する
4. まな板へ置くまで、他設備の輪郭を出さない
5. 作業ボタンを押している間だけ進捗を進める
6. 切断後、容器供給と組立面を順に誘導する
7. 完成容器の蓋を閉じ、提供口を強調する
8. 提供成功後に採点営業120秒を開始する

全文説明は使わず、矢印、輪郭、拡大パルス、短いSE、振動で誘導する。一定時間入力がない場合だけ同じ手順を再表示する。

## 6. 採点営業

- 注文はグリーンサラダだけ
- 注文間隔28秒、注文タイマー90秒、1人同時上限1を初期値とする
- どの注文も同じ料理なので、注文順コンボはUIだけ先行表示し、深い説明は1-4へ送る
- 誤料理は発生しない。床落下した食材・容器は拾える
- 120秒終了時に星0〜3、得点、自己ベスト、再挑戦、次へを表示する

## 7. 人数別の狙い

| 人数 | 自然に生まれる役割 | 検証点 |
|---:|---|---|
| 1 | 全工程を一人で往復 | 次の対象が迷わず、単調すぎないか |
| 2 | 切断／容器・提供 | 島越しの受渡しが自然に起きるか |
| 3 | 供給・切断／第二切断／仕上げ | 一人が遊休しないか |
| 4 | 材料供給／切断二人／仕上げ・提供 | 一設備前へ全員が集中しないか |

4人でも単一料理だけなので、注文間隔と星ラインを上げすぎず、最適化と衝突自体を楽しむランキング面とする。

## 8. 必要アセット

- レタス箱とレタスの生・切断済み
- まな板、組立面、通常カウンター
- 開いた空容器、完成時に閉じる容器
- 現地提供口
- 対象輪郭、作業進捗、完成表現
- 取る／置く、作業、提供成功のSEと軽い振動

新規の舞台ギミック、背景アニメーション、火、皿、バイクは不要。

## 9. 受入条件

- 初見プレイヤーのガイド注文完了率95%以上
- 初回ガイド中に同じ手順を三回失敗する割合10%未満
- 初回ガイド後、説明なしで二件目を完成できる割合80%以上
- 1人の星1率65〜85%、一回再挑戦後85%以上
- 1〜4人で到達不能設備と遊休専用区画がない
- 画面上で生レタス、切断済み、空容器、完成容器を色だけに頼らず識別できる

## 10. 今回決めること

1. 盤面はA・B・Cのどれにするか。推奨はA
2. まな板二台を全人数で常設するか。推奨は常設
3. 初回安全注文を採点外とし、その後120秒を採点するか。推奨は採用
4. 1-1ではゴミ箱を置かず、1-2で正式導入するか。推奨は採用
