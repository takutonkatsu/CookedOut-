# COOKED OUT! シーズン報酬と通常営業の収入バランス v0.2

- 作成日: 2026-09-13
- 状態: 公開した順位コインの相対規模・全員共通固定額・開始前表示・最上位一区分・報酬名称の分離を採用。ユーザー指定で順位バッジ等の名誉を主な動機とする。絶対額・測定条件・未公開細部は未確定、未実装
- 前提: 通常営業とシーズンはソロ専用。シーズンの未挑戦厨房は0点とし、1厨房以上の有効得点で最終順位対象。全4厨房達成は共通外見だけの条件

## 1. 順位コインは通常営業の1〜5営業分を目安にする（採用）

通常営業で設備強化資金を稼ぎ、その設備でシーズンの記録を更新する循環を維持する。順位報酬だけで次月の設備差が大きく拡大しないよう、まず次の規模で試算する。

基準額Kは「通常営業Lv20を標準的な献立・設備・星2程度のプレイで正規終了した時のコイン収入」を複数ケースで測定して決める、全プレイヤー共通の固定額とする案。個人の過去収入・現在の店ランク・月末の所持設備に応じて変動させない。レシピ・設備価格・収支の調整前なので具体コイン数はまだ置かない。

| 順位区分 | 終了時のコイン目安（採用） |
|---|---:|
| 上位50% | 1K（基準1営業分） |
| 上位25% | 2K |
| 上位10% | 3K |
| 上位3% | 4K |
| 上位1% | 5K（基準5営業分） |

該当する最上位一区分だけを付与する。料理基本点に基づく各営業のコインとは別枠であり、スコアに比例させない。上位50%外には順位コインを追加せず、各営業コインと全4厨房達成時の共通外見を残す案。公開した50／25／10／3／1%の順位帯と1〜5営業分の規模は採用。割合の端数・少人数時の詳細は80の保留事項として残す。

報酬額はシーズン開始前にコイン数として確定・表示し、途中で変更しない。「1営業分」等は開発側の調整尺度であり、プレイヤーへ曖昧な単位で支払うものではない。

最上位でも一月につき5営業分なので、順位を主な資金稼ぎにする人には控えめ。上位の動機は順位と記念表現を主にし、資金稼ぎは通常営業が中心という役割を優先する。Lv5一種類の強化費に対する比率と、少人数開催時の影響を検証する。

## 2. 二つの達成条件を表示でも分ける（公開方針を採用）

- 「4厨房達成報酬」：全4厨房で有効得点を記録すると共通外見。順位に関係なし。「参加報酬」から表示名を整理するだけで、達成条件は変えない。
- 「順位報酬」：合計スコアによる最終順位で記念表現とコインを付与。未挑戦厨房があっても対象。

シーズン画面で達成報酬の外見と4つの厨房アイコンの達成状態、順位報酬の内容を分けて示す。厨房の未公開と未挑戦を同じ失敗表示にしない。暫定の順位報酬予想は確定した所有物として扱わない。結果確定後は既定どおり自動付与し、受取ボタンを作らない。

## 検証・保留

2026-09-14更新：割合の端数切上げ・少人数でも成立・同点全員対象・報酬判定は全体順位のみを83で採用。以下の保留は具体金額・測定・検証実装に限定して読む。

- 割合の丸め・少人数時の扱い、Kの測定に使う献立・設備・代表プレイの選定。星2程度という測定条件は試算案であり、報酬獲得に星2を要求しない
- 上位／中位／少人数時の月間収入とLv5設備価格、順位報酬が弱すぎないかのプレイテスト
- 共通外見・称号・バッジの具体デザインと制作量。毎月の新キャラクター制作は要求しない
- UIの具体レイアウト、絶対コイン額、不正対策・障害対応は別途
