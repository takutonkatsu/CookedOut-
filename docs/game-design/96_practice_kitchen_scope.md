# COOKED OUT! 報酬なし練習厨房の範囲 v0.2

- 作成日: 2026-09-14
- 状態: 2026-09-14、ユーザー承認で公開方針を採用。設備能力は本人の現在の設備Lvへ変更し、必要な原料箱・設備の自動推奨配置から編集可能とする。その他の公開方針も採用。具体盤面・保存枠・未公開細部は未確定。コード・盤面・UIは未実装
- 既定: 通信障害・メンテナンス・結果同期待ちでも報酬なし練習を利用可能にする。正式営業の開始はオンライン必須。出張は開始前の盤面下見なし。シーズンは無制限挑戦で専用の練習区分なし

> 台数・編集・保存の後続決定は[100](100_practice_inventory_layout_and_save.md)。2026-09-14に公開方針を採用。本人所有台数内、準備で設備・原料箱を並替え可能、系統ごと一つの前回配置、開始時保存等を用い、本書の旧未決表記より優先する。

## 1. 目的と入口

料理の作り方、取る／置く、投げる、移動可能な設備の持ち運びを落ち着いて試す場所とする。別の育成モードや必修チュートリアルにはしない。強制的な実地ガイドを追加しない。

障害時だけでなく、普段もホームの控えめな練習入口から利用できる。接続できない時は接続画面からも入れるようにし、端末保存済みの内容で遊べるようにする。新端末・初回未同期時はアプリに同梱した基本料理と基本設備だけを使う。具体内容とその設備能力は料理・ステージ設計時に決め、未取得の本人設備Lvを推測しない。

## 2. 専用厨房ひとつから始める

- 練習専用厨房ひとつで、1キャラ操作。「固定」は専用会場をひとつ用意する意味で、設備配置を編集不可にする意味ではない。出張全盤面や本人の本店配置を複製する機能は初期範囲に含めない
- 習得済みの料理系統を一つ選ぶと、必要な原料箱・設備の推奨配置をゲーム側が自動で用意する。そのまま練習を始めても、準備画面で配置を編集してから始めてもよい。営業前準備の既存仕組みを再利用できるか実装時に検討する
- 設備能力は本人の現在の設備種類Lvに合わせる。例えば鍋Lv4・フライパンLv2なら練習でもそれぞれLv4・Lv2とし、旧案の一律Lv3は撤回する。通信不可時は端末保存済みの確定した設備情報を参照する
- 練習設備は本人の所有種類・台数内で配置でき、本店に配置済みのものも取り外さず利用できる。推奨配置は必要分だけ置き、本人の所有全台を自動で並べない。本店の所有状態・配置を増減させない。原料箱は必要原料をゲーム側が用意する
- 配置編集は練習用の独立状態に対して行い、本店やシーズンの配置を上書きしない。準備では設備・原料箱を対応枠内で並替えでき、練習中は既定の可搬・固定ルールに従う。系統ごと一つの前回準備配置を保持し、開始時に保存する。開始せず編集画面を離れる場合だけ保存確認を行う。練習中に移動した結果では自動上書きしない。具体編集枠・保存の技術方式は未確定
- 一厨房内で材料や設備を常時全種類並べず、選択した系統の練習に必要な範囲に絞る。選択変更は練習の準備へ戻って行う
- 初期範囲は厨房内の練習のみ。バイク走行、協力接続、二キャラ切替の専用練習は含めない。必要性が出た時に別途検討する

## 3. 時間に追われず、実際の操作を試せる

- 営業全体の制限時間、注文期限、スコア、星評価は設けない
- 選択系統から作る料理の見本票を1枚ずつ自動表示し、正しく提供すると次へ進む。注文ウェーブや自分で毎回注文を発生させる操作は追加しない。料理の再選択・切替の細かな導線は未決定
- 加熱時間、焦げ・火災、誤レシピ・廃棄、食材投げなどの基本挙動は本番と同じ。加熱まで止める意味の「時間制限なし」ではない
- 必要な片付け手段を用意し、「やり直す」で練習開始状態へ戻せる。開始状態は本人が編集して開始した場合はその配置を指し、毎回自動推奨配置へ戻す意味ではない。盤面リセット前は確認し、本店の配置には影響させない
- いつでも終了可能。報酬のために4分待たせたり、途中終了で不利益を与えたりしない

## 4. 本編・競技と分離

コイン・評判・星・自己ベスト・ランキング・バッジ・料理解放・日課進捗は一切付与しない。デイリーの具体検討は引き続き保留。練習で作った料理・動かした設備・消費した材料は本店や次の営業へ持ち越さない。

未解放の出張盤面、ギミック周期、シーズンの固定注文列はここで練習させない。シーズンに専用練習区分を設けない既定を維持する。料理そのものの操作習熟が本番に役立つことは意図した効果。

練習中の強制広告は入れない。報酬のない基本練習が常時利用可能になることで、短時間の練習だけで満足する利用者が出る可能性はあるが、本編の進行・街・ステージ体験とは範囲を分ける。

## 5. 利点と限界

初心者が時間に追われず操作を試せ、通信障害時にも最低限遊べる。一方、固定の1キャラ厨房では分断盤面・二キャラ切替・配達・実戦の注文密度は習得しきれない。本編第1章と通常の再挑戦を置き換えるものではない。

具体盤面、見本票の選び方、料理別設備セットと台数、編集可能枠、練習配置の永続保存、初回未同期時の内容、端末キャッシュの整合、全系統への対応時期は未決定。利用可能な内容を一つも用意できないまま「オフラインで練習可能」と表示しない。
