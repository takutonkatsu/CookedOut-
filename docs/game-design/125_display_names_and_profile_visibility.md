# COOKED OUT! 表示名とプロフィール公開範囲案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、公開方針をユーザー承認で採用。初回自動名と任意の無料変更、重複名可・ID識別、外見と装備バッジ中心の公開、資産・全履歴非公開。12文字程度は初期表示試験値で最終文字数・入力制限等は未確定。実アカウント・名前・UIは変更しない
- 既定: 登録入力なしで開始、内部アカウントIDと表示名は別、動物キャラ共通能力、装備バッジ最大3個。ロビーとプロフィールは3個・小さい個人ランキング行は先頭1個、バッジ詳細は対象年月・順位・対象人数等を表示。ゲーム内自由文チャット・通話は将来も実装しない

## 1. 初回は自動の仮名で、そのまま遊べる

初回に「シェフ4821」のような短い仮名を割り当て、名前入力をソロ・マルチ開始の必須手順にしない案。例示の文字列・番号の桁数は未確定。キャラを変更しても名前を勝手に変更しない。

本名、Appleのアカウント名、端末名を自動的に公開名へ転用しない。自分で決めたい人だけ後から変更できる。自分の店名を付ける仕組みは追加しない。

## 2. 名前変更は無料、重複名も許可する

ホームの自分のプロフィールから名前を変更できる案。ロビー・ロード・営業中は変更不可とし、誰と遊んでいるかを途中で分からなくしない。名前変更にコインや課金を要求しない。

他プレイヤーと同じ名前を許可し、空いている名前を探させない。内部では変わらないアカウントIDで記録し、改名しても星・順位・チーム構成・報酬が別人扱いにならない。部屋内では既定の色＋形の識別を併用する。名前の一致を本人確認として扱わない。

長さは12文字程度を初期表示試験の上限案とし、日本語でも収まるか検証する。空欄・改行・制御文字、運営を装う表現や不適切な入力への制限は必要だが、具体の許可文字・判定方法・変更の連打制限・事後対応は別途決める。完全な不適切入力排除を保証しない。プロフィールに自由な自己紹介文・外部リンク欄は設けない。

## 3. 他人が見られるプロフィールは、外見と選んだ実績を中心にする

ロビーやランキングから他人のプロフィールを開くと、表示名、本人用キャラと装備衣装、選んだ最大3個のバッジを見られる案。バッジを押すと既定の実績詳細を確認できる。

非操作側のソロ相棒を別プレイヤーとして公開しない。個人プロフィールへチームの成績を本人だけの単独成績として表示しない。ランキングで既に公開している点数・順位・メンバー構成等は、そのランキングの既定どおり表示する。

ロビーから他人の詳細を見ている間も営業開始条件を勝手に変更せず、読み取り専用とする。開始遷移時は閉じ、進行を妨げない。具体的な開閉操作や表示サイズは別途設計する。

## 4. 資産と全プレイ履歴は、初期は他人へ公開しない

所持コイン、設備の保有数・Lv、通常営業の細かな進行、購入履歴、アカウント連携情報、全シーズン履歴、装備していないバッジの全コレクションは、初期の他人向けプロフィールへ載せない案。本人は既定の管理画面・実績履歴から確認できる。

見せたい実績は本人が選ぶバッジで表現する。プロフィールの項目ごとに複雑な公開設定を追加せず、初期の公開項目を限定する。既にランキングへ掲載されている正規記録を隠す・削除する設定を作る意味ではない。

本店の配置もプロフィールから勝手に閲覧できる機能は追加せず、本人が共有URLを渡す既定の導線を維持する。プレイヤーの現実の所在地・連絡先・端末機種を公開しない。

## 5. 未決・範囲外

最終文字数・フォントと文字種、入力の検証、改名後の表示反映タイミング、公開名に問題がある場合の運用、報告・ブロックの詳細。名前変更の無料方針は表示名だけに適用し、保留中の外見マネタイズを決めない。ランキングの成立条件や公開済み記録の扱いは変更しない。
