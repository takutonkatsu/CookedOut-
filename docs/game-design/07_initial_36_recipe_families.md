# COOKED OUT! 初期36料理系統マスター案 v0.1

- 更新日: 2026-09-11
- 状態: 初期リリース36系統、9工程文法、段階実装、飲料除外を大枠決定。個別料理・派生と文化監修は今後確定
- 制約: 実在料理、基本加熱器具は鍋とフライパンのみ、料理専用ボタンなし

## 1. 数の意味

既存調査で数えた「本家36料理系統」は、`Overcooked! All You Can Eat`に収録された二作品本編・DLC・季節コンテンツを横断した累計である。`Overcooked! 2`単体の公式FAQでは本編の主料理は9系統と説明されている。

COOKED OUT!では、企画時点から36系統を設計してデータ構造と美術規格を作る。縦切りやアルファの実装数を絞っても、初期正式リリースの目標は36系統とする。

```text
縦切り       4系統: 全操作文法が成立するか検証
内部アルファ 12系統: 量産構造と難易度曲線を検証
ベータ       24系統: キャンペーン全体を通して検証
初期リリース 36系統: 全系統を収録
```

36系統を一ステージへ同時に出す意味ではない。通常は1系統・3〜5注文派生、復習で2系統、章最終で最大3系統を維持する。

用語整理: ここでの料理系統と、その中の具材違い等による個別レシピ（注文派生）は別に管理する。また次節の工程文法は、複数の料理系統で再利用する作業の仕組みであり、料理系統数とは一致しない。通常営業で「2系統＋各系統の複数派生」を標準にする後続相談は[献立案 §8](40_menu_identity_and_coherent_player_experience.md#8-2品ではなく2料理系統と複数派生で献立を作る)を参照。上記のステージ別導入数を全モード2系統固定へ変更する決定ではない。

## 2. 共通工程文法

料理数を増やしても、プレイヤーが覚える操作は増やさない。

1. 切って直接組み立てる
2. 共通の土台へ具材を載せる
3. 複数食材を鍋で一括加熱する
4. 鍋で作った土台へ具材を合流する
5. 一品をフライパンで個別加熱する
6. 複数食材をフライパン内で合流する
7. 鍋とフライパンの二系統を最後に合流する
8. 主菜と副菜を一つの容器へそろえる
9. 同じ基本料理を注文別トッピングで分岐する

専用器具を増やさず、食材、投入順、同時タイマー、最終合流の違いで料理を分ける。

## 4. 採用上の注意

- 36系統すべてが異なる操作である必要はない。同じ工程でも完成シルエット、材料判断、合流順が明確に異なれば一系統とする
- 反対に、色を変えただけで判断が変わらないものは一系統内の派生へ戻す
- 一注文の部品数は通常4以下、難度5でも5以下を原則とする
- 鍋とフライパン以外の加熱器具を要求する料理へ無理に広げない
- 配達容器内で上から見た時、主材料と完成状態を大きな色面と形で識別できることを採用条件とする
- 36系統×3〜5派生で108〜180注文候補になるため、材料アイコンとレシピデータを完全にデータ駆動化する

## 5. 美術量産単位

一料理系統につき、最低限次を同じ仕様から作る。

1. 注文票用完成料理アイコン
2. 共通容器内の完成3Dモデル
3. 食材アイコンと食材3Dモデル
4. 未加工・切り済み・加熱済み・焦げ状態
5. レシピ工程カード

最初に12系統の代表画像で造形、カメラ、色、容器占有率を固定し、そのテンプレートを残り24系統へ適用する。

## 7. 後続の料理選定方針（2026-09-13採用）

具体的な料理・材料・工程の確定は保留し、再開時には次の順で検討する。

1. 簡単・標準・難しめの料理系統を幅広く考える。系統数はできる限り充実させ、現行36系統目標は維持する。
2. 各系統に複数の個別レシピを作る。名称だけを変えた重複や、全く同じ判断の水増しは避ける。
3. 系統を横断して使える汎用原料を優先し、原料種類数を抑える。共用できる見た目・加工状態も確認する。
4. 原料を減らした結果、完成品の区別や作業判断が単調になる場合は、意味のある原料を足す。原料数の最小化を最終目的にしない。
5. 一営業の献立として組み合わせ、食材供給口・設備・作業面の容量と、待ち中にできる別作業を確認する。

原料追加のレビューでは「何系統で使えるか」「どの見た目・判断の差を作るか」「既存原料で代替すると何が失われるか」を記録する。全原料に一律の最低使用系統数は課さず、少数の用途でも明確な価値があれば候補に残す。

難度は操作ボタンや精密操作を増やさず、手作業量、並列加熱、合流段数、共通設備の競合、注文派生の識別で設計する。難しい系統だけを増やさず、簡単な系統も組合せ・配達の戦略で役割を持てるようにする。

通常営業は序盤1系統、途中から定番1＋おすすめ1の2系統を標準とする。移行Lvや原料総数は未決定。ユーザーが例示したパスタ・サラダの具材構成や、38の個別レシピ案をこの方針の承認で確定しない。
