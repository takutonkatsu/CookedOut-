# COOKED OUT! 設備強化の説明・反映タイミング案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、公開した4点をユーザー承認で採用。工事待ちなし、能力差の購入前表示、配置維持・次回反映、未同期結果中の設備購入／強化停止。具体数値・取引技術・範囲外事項は未確定。コイン取引・UI・設備データは未変更
- 既定: 追加購入と種類Lv強化は別操作。追加分は未配置在庫、強化は同種全台へ反映。無料収納、初期売却なし、配置取消は購入取消ではない。67・68・84を参照し、大枠を再決定しない

## 1. 強化のための建設待ち時間は設けない案

強化条件とコインが足りて購入確認・サーバー確定が済んだら、その種類Lvを更新する。現実時間で数分・数時間の工事を待つ仕組みは初期版に設けないことを推奨する。通信確認に必要な待ちとゲーム上の工事時間は区別する。

強化中の設備を使用不能にしたり、新しい建設作業員・工事枠を管理させたりしない。稼ぐ、強化する、次の営業で試すという反復を切らない。待ち時間短縮広告等の収益化方式は追加しない。マネタイズの相談保留は維持する。

## 2. 何が変わるかを購入前に示す

設備詳細で現在Lvと次Lv、主な変化、既定の必要コイン・支払後残高を確認できるようにする。手作業短縮、加熱短縮、積載数増加等をアイコンと短文で示し、詳しい能力値を確認できるようにする案。

料理・配送先で実時間が変わる設備に、固定の料理秒数や固定到着秒数を保証表示しない。正確な相対短縮率や容量など、その種類に共通する実際の能力値を使う。数値が未調整の現段階では架空の秒数を商品仕様として確定しない。

同種全台が強化されることを明示し、配置中だけが対象・一台ずつ再購入が必要と誤解させない。追加台数の購入では現在の種類Lvの設備が増える既定を維持する。大量の性能項目を一覧へ常時並べない。

## 3. 配置を維持して次の営業から試す

強化しても配置中の設備を片付け直さず、プリセットを作り直さなくてよい。保存配置は設備の位置を参照し、過去のLvを固定するものにしない。通常営業・練習・シーズンは次回開始時に更新された本人能力を使い、出張の固定Lv3は変更しない。

営業途中の強化・追加購入はできないものとする案。別端末や同期イベントで能力情報が更新されても、開始済み営業の能力を途中変更しない。シーズンの次回反映・過去記録保持という既定を拡張して整合させる。強化のために毎回新規の練習を強制しない。

## 4. 結果同期待ち中はコイン取引を止める

未同期の営業結果がある間は、設備の追加購入・強化を行えない案。設備の閲覧はでき、未確定コインを支払原資にしない。既存の確定残高が足りる場合も、初期はコイン取引を一律に待たせて処理を単純化する。

欠点は通信障害中に確定済みコインを使った強化も待つこと。短い理由と再試行導線を示し、同期待ちが解消すれば通常操作へ戻す。保存・照会・復旧不能時の出口は95の既定を使い、画面を閉じるだけで未同期結果を破棄しない。

設備取引そのものの送信後に結果不明となった場合も、同じ取引を照会し、連打で別購入を発行しない。無償の配置編集・複数端末編集・他種の購入への適用範囲は別途相談する。有料商品全体の処理をこの案だけで決定しない。

## 5. 今回の範囲外

設備価格、Lv係数、必要評判の最終値、残高不足からの収益化導線、取引の技術・競合・返金処理。初期売却なしの既定を再審議せず、実測前の秒数・費用は確定しない。
