# COOKED OUT! 共通配送欄・期限バーと配達案内の具体化案 v0.1

- 作成日: 2026-09-13
- 後続決定: 落下パック上への注文番号・追加目印・画面外誘導マーカー案は取り下げ、パック本体のデザインと散乱配置で見つけやすくする。地図・注文票の番号や通常の操作対象輪郭まで廃止する意味とは解釈しない。その他の本書の提案は一括承認扱いにしない
- 採用方針: 自配達と代行の状況は一つの欄へまとめる。自配達期限は時間数値よりバー表示を第一方針とする
- 提案: 表示単位、バーの挙動、地図の向き、案内先の仮選択と切替、回収目印。未承認・未実装

## 1. 同じ配送状況欄の中で方法を見分ける

別タブへ分けず、同じ表示領域で自配達の顔アイコンと代行の車両等のマークを使い分ける。自配達は一出発で共通期限なので顔・残件数・一本の期限バーへまとめる案。代行は独立した到着予定があるため個別状況を確認できるようにする。代行へ自配達の失注期限を追加する変更ではない。

情報量が増えた場合の縮小・詳細展開を試作し、緊急な配送を切替画面の奥へ隠さない。具体的なカード数・幅・表示順は未確定。過去の帰還進行バー不採用は維持し、今回の期限バーとは別物として扱う。

## 2. バーは残り時間を表し、移動進捗ではない

自配達は出発時に満タン、時間経過で減り、ゼロで配送失注となる案。止まっていても回収中でも減り、納品や再積載で回復しない。初回出発時に記録した期限を描画し、画面切替でリセットしない。

ラベルは「配送期限」等、期限であることが分かる短い表現を使う。納品達成率や目的地への接近度を示すバーにはせず、残件数と地図を別に表示する。

代行もバー化するなら、残り到着待ちが減りゼロで納品になる表現を候補とする。自配達のゼロは失注、代行のゼロは到着なので、前者は時計等の期限印、後者は届け先等の到着印・短いラベルで区別する。代行の到着直前を危険な赤点滅にはしない。代行バーの採用まで今回決定したとは扱わない。

自配達の残りが少ない時は色に加えて枠の点滅や短い音を使う案。具体閾値・頻度は未決。同じ瞬間の複数警告はまとめ、騒音や強い点滅にならないようにする。

営業時計は従来どおり残す。配送バーが残っていても閉店すれば終了するため、閉店が先ならその旨を開始前や必要時に示す。バーだけを見て閉店後まで配達できると誤認しないかを検証する。正確な数値を常時併記する変更は第一案では行わない。

## 3. 地図と案内先

- ミニマップの向きは固定し、運転方向に合わせて地図全体を回さない案。自分の矢印だけ向きを変える。街の位置関係を覚えやすくする一方、進行方向との読み替え負荷は実機で確認する。
- 全行先を表示し、自分の積荷の届け先を強く、それ以外を弱く表示する。厨房の次の準備対象と、街の現在の案内先を混同しない。
- 出発時と選択先の納品後は、自分の残り積荷の中から道路距離が近い有効な届け先を次候補として仮選択する案。行先アイコンまたは積荷アイコンのタップで変更できる。近い順が全件の最短巡回になるとは保証しない。
- 地図に線を出す場合は選択中の一行先までとし、全行先への線を同時に描かない。道路上の目印・画面端の方向表示と併用し、ミニマップだけを凝視しなくてよいようにする。
- 自動で最適巡回順を固定せず、選択外の家へ先に納品できる。順番違反の追加減点はなく、出荷順コンボも変化しない。
- 納品先が無効・失注済みになった場合は案内を外す。選択しただけで納品が成立したり、期限が変更されたりしない。

## 4. 事故パックは物体自体で見つけやすくする

パック上へ注文番号・浮遊マークを重ねず、画面外のパックを追う追加矢印も初期案では付けない。ユーザー方針により、物体自体の大きさ・シルエット・道路との明度差・中身の見え方で識別性を作る。散乱時に重なりすぎない、車体下や背景装飾に完全に隠れない、極端に遠くへ飛ばさない配置を検証する。専用の光柱・常時発光を目印の代替として勝手に追加しない。

通常の近距離操作対象の輪郭表示は既存の入力仕様を維持し、落下パック専用の常時マーカーとは区別する。注文番号は内部の対応・注文票や荷台一覧に必要な情報として別途扱い、物体上への表示撤回と混同しない。自動回収にはせず、近くへ行って取る／置くで回収する操作を維持する。

落下したパックの荷物アイコンは落下状態を示すが、残り納品件数は減らさない。配送バーもそのまま進む。持ち上げただけでは配達完了・荷台へ戻した扱いにせず、実状態と表示を一致させる。回収中に案内先を勝手に変更して方向感覚を失わせない。全納品または時間切れの帰還は52を維持する。

## 5. 検証

- 同じ配送欄でも自配達の失注期限と代行の到着待ちを取り違えないか。
- バーの残りが移動距離や納品割合だと誤解されないか。
- 小画面で全行先を見分け、操作ボタンと地図タップを誤らないか。
- 地図の固定向きが記憶と運転の両方を助けるか。
- 自動仮選択が邪魔にならず、自分で巡回順を変える意味が残るか。
- 夜・暗い舗装・明るい舗装・最大積載散乱でも、パック本体だけで回収対象を見つけられるか。大きさや配置で改善できるかを先に確認し、無断でマーカーを復活させない。
