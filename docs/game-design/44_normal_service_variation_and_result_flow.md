# COOKED OUT! 通常営業の周回変化・結果から次営業への導線 v0.2

- 作成日: 2026-09-13
- 状態: 周回変化と再営業の方針を採用。ユーザー修正により昇格条件は結果に載せず、ホームの店ランク欄に集約。具体乱数分布・UI寸法等は未確定・未実装
- 範囲: 通常営業のみ。出張・シーズンの競技用固定条件、料理の具体材料・工程を変更しない

## 1. 同じ献立を繰り返す時の変化

献立・配置は維持できる一方、個別レシピの注文順と配達先の組合せは営業ごとに再生成する案。街の道路・建物配置、必要設備、解放済みの注文可能レシピ、同一営業Lvの星基準を抽選で変えない。選んでいない系統の飛び入り注文・日替わり特別ルール・強制イベントは追加しない。

完全な独立抽選ではなく、短い注文列ごとの料理構成・作業負荷、配送距離の分布に偏りの上限を持たせる。短い区間は内部生成上のまとまりであり、プレイヤーのウェーブ操作・休止・注文全件公開は不要。注文自動発生と、注文数・発生間隔・猶予の実測待ち方針は維持する。

同じ料理の連続注文や近い届け先が重なる機会は残す。それが仕込み共用・まとめ配達の工夫になる。ただし長工程料理や遠距離ばかりで、抽選の良し悪しが星評価を支配する列は避ける。確率・連続上限・距離帯の個数は実測して決める。

星基準は営業Lvに固定し、抽選ごとに自動変更しない。生成列間と献立間で星到達率・納品基本点の差を検証する。上手い人ほど不利な注文を出す裏の動的難度は使わない。

## 2. 結果表示

主表示は今回の星・スコア・獲得コイン・獲得評判と店ランクゲージ。通常営業の数値自己ベスト・ランキングは追加しない。料理基本点によるコインと、チップ等込みの評価スコアの違いは必要時に開ける内訳で説明する。

次ランク条件はホーム画面の店ランク欄で確認できるようにし、結果画面には掲載しない。ホームでは必要評判、指定出張のクリア、対象設備の最低Lv等を確認できる。昇格条件そのものは増やさない。詳細の常時展開かタップ展開かは後で決める。

- 評判が上限で止まる場合: 既定どおり700/700等と表示する。結果には不足条件一覧を出さず、内訳で評判上限による加算停止を説明できるようにする。今回加算されなかった余剰を次へ繰り越すように見せない。コイン獲得は継続する。
- 低い営業Lvで評判対象外の場合: 0獲得の理由を示し、コイン・最高星更新の対象であることは維持する。
- 条件達成で昇格した場合: 新ランクとゲージ初期化を表示するが、次の営業Lvを自動開始しない。

通常営業を続ける、設備を強化する、出張を進めるという判断に必要な情報だけを示す。NPC会話や別ミッション一覧の新設は不要。

## 3. 次の営業への操作

- 「同じ献立でもう一度」: 前回の営業Lv・献立・有効配置を維持し、注文順と目的地は再生成する。短い開始前確認を経て開始し、自動連続開始はしない。
- 「営業準備へ」: 営業Lv・おすすめ変更・配置・強化を選べる。昇格直後は新Lvへの案内を表示するが、自動で旧献立を置換しない。
- ホームの店ランク条件表示から、出張条件待ちなら該当ステージへ、設備条件待ちなら設備画面へ必要に応じて移動できる。結果には条件別の誘導を載せない。画面遷移だけで営業開始・購入・強化は実行しない。

昇格後に前回Lvを再営業する場合は「評判対象外」を開始前に明示する。別の未習得レシピを再営業の名目で追加しない。閉店時の料理・注文・配送の初期化は既定どおり。

## 4. 検証

- 同じLv・献立・設備で生成列を変えても、星到達率と納品基本点の差が許容範囲に収まるか。
- 二系統のうち片方が出なさすぎて、準備が無駄にならないか。
- 自配達の近距離まとめ・加熱中の出発などを判断でき、毎営業の正解が完全固定されないか。
- 再営業を押した人がLv・献立・評判対象の変化に驚かないか。
- 評判停止でもコインが得られること、次に何を満たす必要があるかが分かるか。
