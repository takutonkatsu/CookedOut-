# COOKED OUT! 先行習得料理の鍵表示と利用範囲の整合案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、公開4点をユーザー承認で採用。鍵は本人の章未解放を示し、習得済み料理の練習と通常営業の既定利用条件を維持。章解放後は鍵を外し、再習得・初回報酬の二重付与は行わない。具体文言・表示と実機検証は未確定
- 確認した既定: 65では先行正規クリアのレシピ・設備種類解放を即時反映し、本人のステージ選択前提待ちとは区別する。107・108では通常営業の追加候補に基本2品習得・現在の営業Lvより前の系統・設備適合等を要求する。96・100では習得済み料理を本人の設備で練習できる

## 1. 鍵は「この章を自分ではまだ選べない」の意味にする

先行習得済みの料理の鍵は料理の未習得を意味せず、本人の対応章が未解放であることを表す案。詳細に「習得済み／章は未解放」等の短い状態を示し、画像と鍵だけでは意味が衝突する点を補う。具体文言・アイコンは未確定。

未習得料理の鍵とは詳細の状態説明を分ける。新しいポイントや収集制度を作らず、既存の章解放状態とレシピ習得状態を別々に表示する。ユーザーが鍵を料理の利用禁止にも使いたい場合は65・96等の変更になるため、明示的な相談を経る。

## 2. 習得済みなら、ホームからの練習は許可する

招待先で正式に習得した料理は、対応章が未解放でも材料・工程を見返し、ホームから既定の練習厨房で練習できる方針を維持する案。既定どおり所有台数・種類Lvと練習の設備条件を使い、必要設備が足りない時に無条件貸出や自動購入は行わない。

マルチの料理詳細からは引き続き練習へ移れない。ロビーで少し料理する候補は後日検討のまま。閲覧しただけ・クリア資格のない参加だけでは習得扱いにしない。

## 3. 通常営業は、既定の営業Lv・献立条件で判定する

図鑑の章待ちの鍵を理由に、新しい通常営業の禁止条件は追加しない案。ただし学んだ料理をどの営業Lvでも自由に選べるわけではない。

定番は営業Lvごとに固定、追加系統は今回の営業Lvより前の定番系統だけ。各系統の基本2品が習得済みで、必要原料・設備・台数・配置に適合することを要求する既定を維持する。3品目は習得済みでも通常営業には出さない。店ランクの評判・設備・指定出張ゲートやシーズンの参加条件を飛ばさない。

このため、序盤に招待で後半料理を学んでも、低Lv営業へ高Lv系統を持ち込む抜け道にはならない。料理ごとの具体判定は既存台帳に従い、この説明のために系統の初登場Lvを変更しない。

## 4. 自分の章が解放されたら、鍵だけ外す

既に習得済みの料理を、本人の章解放後に再度作ったり同じ面をやり直したりすることは要求しない。章待ちの鍵を外し、先行クリアの星・固有報酬は既定どおり保存済みのままとする。初回報酬や設備を二重付与しない。

未習得の料理は章解放だけで習得せず、115の「完成画像＋鍵、料理名・習得先のみ」の表示へ進む。章解放と料理習得を一律に同じイベントにしない。

## 5. 今回の判断点

推奨は既定の先行習得の利点を残し、鍵は章の状態表示に限定すること。欠点は同じ鍵アイコンが未習得と章待ちの二つの状態に見えるため、短い状態説明と視認性の確認が必要なこと。厨房の新操作や得点ルールは追加しない。ユーザー承認前に、章未解放を理由として習得済み料理を利用不可にする変更は行わない。
