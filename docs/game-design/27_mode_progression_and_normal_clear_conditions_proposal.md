# COOKED OUT! 通常営業クリア条件・モード進行連携案 v0.1

- 作成日: 2026-09-12
- 状態: 一部撤回。通常営業クリア条件は有効だが、モードを必須化しない進行案は後続の店ランク20案により上書き
- 対象: 通常営業一回の成功条件、通常営業の長期目標、通常営業と出張営業の必須関係

## 1. 結論

通常営業にも一回ごとの明確な成功条件を設ける。ただし、出張営業のような番号付きステージにはしない。

推奨構造は次の通り。

```text
営業時間終了までに目標スコアへ到達
→ 星1で営業成功
→ 星2・3で高評価
→ コイン、XP、記録を獲得
→ 別メニュー、上位Tier、同条件再挑戦へ進む
```

モード間の関係について本書で提案した「非対称のソフト連携」は採用しない。店ランクと料理解放の乖離を防ぐため、店ランクの節目へ出張営業と通常営業の両方を要求する後続案を正とする。通常営業一回の成功条件に関する第2〜4節は引き続き有効な提案である。

## 2. 通常営業一回のクリア条件

### 2.1 終了条件

- 一営業は原則3〜5分の制限時間制
- 制限時間が0になると終了
- 一件の失注、火災、配達事故では終了しない
- 途中で目標を達成しても、残り時間は高評価と報酬を伸ばすため営業を続ける

### 2.2 成功条件

- 選択した営業メニューと難度Tierごとに目標スコアを持つ
- 目標スコア到達で星1となり、その営業を成功扱いにする
- 星2・3はより高いスコア閾値
- 目標未達は星0で、営業未成功扱い
- 星0でも一部のコインとXPを受け取り、時間を完全な無駄にしない

表示は「売上ノルマ」等の経営用語より、単に「目標」と星ゲージで示す。スコア、チップ、配達ボーナス等の既存式を合算し、新しい清算計算を増やさない。

### 2.3 動的な目標値

目標値を毎回その場で恣意的に変えず、次の組合せに対してデータを持つ。

```text
目標スコア
= 営業メニュー基準値
× 難度Tier係数
× 営業時間係数
```

- 所有設備Lvに合わせて自動的に目標を上げない。強化の効果を消さないため
- 注文傾向等を追加する場合は、同じ期待得点帯になるよう内部で調整
- 自前配達と配送代行のどちらでも、完璧に遊べば同等帯へ到達可能にする
- 星1は推奨Lvより一段低くても丁寧に遊べば届く
- 星2は推奨Lvで標準的に届く
- 星3は配置、優先順位、配達判断の最適化を要求する

## 3. 通常営業はステージではなく「営業記録」

出張営業のような1-1、1-2の番号は付けない。同じ本店で、次の組合せごとに記録を持つ。

- 営業メニュー
- 難度Tier 1〜5
- 注文条件またはシード
- 使用した配置プリセット
- 最高スコアと最高星

画面では「クリア済みステージ一覧」ではなく、メニュー別最高評価、Tier別達成状況、最近の営業履歴として表示する。

## 4. 通常営業の短期・中期・長期目標

### 4.1 一営業

- 目標スコアへ到達して星1
- 星2・3または自己ベストを狙う

### 4.2 店ランク帯

- XPで次の店ランクへ上がる
- コインで設備Lvと台数を強化する
- 新しいTierと通常営業用の料理派生を解放する

店ランクは既定通りXPだけで判定し、昇格へ特定営業のクリアを追加要求しない。

### 4.3 通常営業の大きな到達点

```text
店ランク10
かつ
通常営業Tier 5で星1以上
```

これを通常営業側の一区切りとし、任意の連続営業を解放する。物語上のエンディングにはせず、通常営業を極めた記録とする。

連続営業は終わりのない日常用であり、通常営業の主要進行へ必須にしない。

## 5. 三つのモード連携案

### 5.1 相互必須

```text
出張クリアが通常強化に必須
通常強化が出張クリアに必須
```

長所は両モードを体験してもらえること。短所は、好みでないモードが進行障害になり、友達と出張だけ遊びたい人も止まること。推奨しない。

### 5.2 完全分離

```text
通常と出張の進行・報酬・解放を完全に分ける
```

自由度は高いが、同じゲーム内に二つの別ゲームが置かれた印象になり、出張で料理を学ぶ意味や通常で店を育てる意味が弱くなる。推奨しない。

### 5.3 非対称のソフト連携

推奨案。

```text
第1章1-1〜1-8
        ↓
通常営業解放
        ↓
┌────────────────┬────────────────┐
│ 出張営業ルート                         │ 通常営業ルート                         │
│ 前面の星だけで最終面まで進行           │ XP・コインでランク10まで進行           │
│ 本店Lv・通常営業回数は不要              │ 特定出張面を設備強化の必須条件にしない │
│ 新しい料理文法と料理系統を先行解放      │ 習得済み料理の派生と設備を育てる       │
└────────────────┴────────────────┘
        ↓                                  ↓
出張エンディング                         Tier 5星1・連続営業
```

両方遊ぶと料理の種類、コイン、XP、外見、記録が早く豊かになるが、片方を遊ばないこと自体では進行不能にしない。

## 6. 出張営業は通常営業なしで最後まで進める

推奨仕様:

- 次の出張ステージは、直前ステージ星1と章進行星だけで解放
- 通常営業回数、店ランク、本店設備Lv、コイン購入を要求しない
- 出張営業ではステージ既定設備を使い、本店設備を持ち込まない
- ソロ出張または2〜4人協力のどちらの星でも章進行可能
- 最終大型出張の星1でエンディング

これにより、友達と出張だけ遊ぶプレイヤー、通常営業に興味がないプレイヤーも本編を完走できる。

## 7. 通常営業と出張営業の接続

### 7.1 出張から通常へ渡すもの

- 新しい料理文法と基本料理系統
- 新設備の初回体験
- コイン、XP
- 外見、称号、記念装飾

出張で新料理を学ぶと、通常営業のメニュー候補へ即時追加される。これは報酬であって、既存の通常営業を続けるための必須条件にはしない。

### 7.2 通常から出張へ渡すもの

- 共通XPと店ランク
- コイン、外見、プロフィール記録
- 操作と配置判断の上達

本店設備Lv、台数、配置は出張ステージへ持ち込まない。したがって通常営業をしていない人が、出張攻略で数値的に不利にならない。

### 7.3 通常営業単体でも増えるもの

新しい工程文法を通常営業だけで先行解放すると、実地チュートリアルが重複する。そのため、通常営業は習得済み文法の範囲で次を解放する。

- 同じ工程を使う料理派生
- より複雑な営業メニュー構成
- 設備Lvと追加台数
- 難度Tier
- 配置プリセットと外見
- 通常営業実績、称号、ランキング

第1章で習得したサラダ、鍋、フライパン等だけでも店ランク10とTier 5へ進めるようにする。ただし出張を進めると料理の種類が増え、通常営業が単調になりにくくなる。

## 8. 廃止を推奨する既存の硬い条件

現行仕様の次の条件は削除候補とする。

- 指定ソロ出張ステージを、本店設備Lvアップの必須条件にする
- 出張ステージ解放へ通常営業回数または本店設備Lvを要求する
- 連続営業解放へ最終大型出張9-4クリアを要求する

代わりに:

- 設備Lv: 店ランク＋コイン
- 出張解放: 出張星
- 連続営業: 店ランク10＋通常営業Tier 5星1
- シーズン競技: 店ランク10＋9-4星1という両モード熟練条件を維持可能

シーズン競技だけは、通常設備を使い、全料理の理解も求める統合エンドコンテンツなので、両方の到達条件を置く意味がある。

## 9. 報酬

| 評価 | 営業結果 | 報酬方針 |
|---|---|---|
| 星0 | 目標未達 | 少量コイン＋完了XP |
| 星1 | 営業成功 | 基本コイン＋基本XP |
| 星2 | 良い営業 | 追加コイン＋追加XP |
| 星3 | 卓越した営業 | 最大通常報酬＋記録更新 |

星0でも途中までの納品が無意味にならないようにする。一方、同じ簡単なTierだけの周回が最高効率にならないよう、上位Tierへ報酬係数を付ける。

## 10. 推奨する最終形

1. 通常営業一回は3〜5分で、時間内の目標スコア到達を成功条件とする。
2. 星1を営業成功、星2・3を高評価とする。
3. 通常営業はステージ番号を持たず、営業メニュー×Tierごとに最高記録を残す。
4. 出張営業は通常営業なしで最終面とエンディングまで進められる。
5. 通常営業の設備強化へ、特定出張ステージのクリアを必須化しない。
6. 出張営業は新しい料理文法を通常営業へ渡すが、通常営業は既習料理だけでもランク10へ進める。
7. 通常営業の一区切りは、店ランク10＋Tier 5星1とし、連続営業を解放する。
8. 両モードを遊ぶとより豊かで効率的だが、片方を遊ばないことを進行不能にはしない。
9. 店ランク10＋最終大型出張星1のシーズン競技だけは、任意の統合エンドコンテンツとして残す。
