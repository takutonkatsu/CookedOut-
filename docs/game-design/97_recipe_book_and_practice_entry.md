# COOKED OUT! レシピ図鑑と練習への導線 v0.2

- 作成日: 2026-09-14
- 状態: 2026-09-14、ユーザー承認。図鑑一覧は3行の横スクロールへ変更し、系統選択を挟む旧案を撤回。営業前の料理画像から図鑑と同じ詳細画面を開く。他の公開方針は採用。具体寸法・未公開細部・実装は未確定
- 既定: 料理は系統と個別レシピで管理する。基本点は10点単位で注文票と図鑑へ表示する。練習厨房は本人設備Lv、自動推奨配置から編集可、報酬なし。料理・原料・工程の具体選定は料理専用タスクで検討する

## 1. 個別料理を3行・横スクロールで一覧表示

系統を選ぶ中間画面をなくし、個別料理の完成画像を縦3行で並べ、横スクロールで閲覧する。一系統3品という指定を受け、同系統3品を縦一列に並べる解釈で整理する。画像を直接押して料理詳細を開く。料理系統の内部データ分類は維持し、図鑑の操作階層だけを変更する。列順・派生の並び順・一画面の列数は未決定。

初期案は複雑な検索条件・お気に入り枠・図鑑独自レベルを追加しない。完成画像はゲーム中の注文と対応した表現に統一し、文字を読まなくても見比べられることを優先する。

## 2. 個別詳細の情報

- 完成料理の画像と料理名
- 必要材料と個数
- 使用設備と、加工・加熱・盛り付けの順序
- 既定の料理基本点。コンボ・チップを含む最終スコアとは区別する

工程は材料・器具・中間品のアイコンを中心に表現し、必要な短文だけ添える。並行して作って最後に合流する部品を、必ず全部直列で作らないといけないように見せない。料理の具体工程はここで新しく発明せず、採用されたレシピデータと一致させる。

料理ごとの長い説明動画を必須にしない。多数の秒数や設備Lv別数値表を最初から詳細画面へ並べず、初期は工程の理解を優先する。数値表示を追加するかは後で実際の分かりにくさを確認する。

## 3. 準備から確認、確認から練習

通常営業の献立選択・準備、出張の開始前に見られる料理一覧、シーズンの既定の登場料理一覧で、料理画像を押すと図鑑の個別料理を押した時と同じ詳細画面を開く。別々の説明画面を作らず、表示元によって料理・工程の内容が食い違わないようにする。閉じると元の準備画面へ戻り、献立選択や配置編集をやり直させない。

出張準備で見られるのは料理情報だけで、盤面・原料箱の位置・ギミック配置は引き続き非公開。招待先の料理が本人未習得でも、そのステージで作るための説明は閲覧できる案。閲覧だけで本人の恒久解放・通常献立・練習対象へ追加しない。

習得済みの個別レシピ詳細から「この料理を練習」を選ぶと、96の練習準備へ移り、推奨配置を確認・編集して開始する。この入口では選んだ料理を繰り返し出し、別料理へ勝手に切り替えない。系統単位で練習に入った時の既定の見本票方式も残す。練習から戻っても本店の準備状態を上書きしない。ただし2026-09-14のユーザー指定により、マルチから開いた共通料理詳細では練習への入口を表示せず遷移不可とする。説明内容は同一画面で共通化し、起点によって操作の可否を変える。101を参照。

## 4. 営業中の誤操作を避ける

初期案では営業中に注文票をタップして全画面図鑑を開く操作を設けない。注文票の既定の完成品・材料表示で判断し、詳しい確認は営業前と練習に置く。新しい強制チュートリアルや営業中のポップアップは追加しない。

初見の協力参加者が営業前の説明だけで理解できるかは確認する。足りなければ営業中の補助表示を改めて検討し、声で教えてもらうことを必須にしない。

## 5. 未習得料理と新規解放

図鑑一覧は習得済みを中心とし、未習得の料理は鍵付きの簡素な枠にする案。通常の進行で案内可能なものには習得先の出張ステージを短く示す。未公開追加章や本人に非表示のS枠を図鑑経由で漏らさず、具体的な表示対象は解放ルールと照合する。

新しく習得した料理には一覧で小さな未確認マークを付け、詳細を見たら消す案。毎回の起動で大きな通知や全件閲覧を要求しない。図鑑閲覧数や全件読了にコイン・星・昇格条件を加えない。

## 6. 今回決めないもの

料理の正式名称・原料数・工程時間・基本点の具体値、図鑑の最終アート、画像量産、検索やお気に入りの追加、営業中の詳細ヘルプ、未習得枠の全表示条件は未確定。料理専用タスクへ変更依頼を送らず、本案のために既存レシピを作り替えない。
