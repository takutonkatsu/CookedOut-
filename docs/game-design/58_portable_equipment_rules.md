# COOKED OUT! 営業中の可搬設備・操作・配置方針 v0.2

- 作成日: 2026-09-13
- 状態: 2026-09-13ユーザー承認。前回公開した範囲・操作・移動制約・初期配置・保存方針を採用し、ミキサーを移動対象へ追加。具体秒数・復旧位置・熱源互換性は未確定、未実装。本文の「案」は承認範囲に限り採用として読む
- 目的: 「すぐ遊べる。何をすればよいか分かる。でも、慣れるほど自分なりの回し方が見つかる」を設備移動で実現する
- 前提: [25の可搬厨房案](25_mode_identity_and_portable_kitchen_proposal.md)を具体化する。CURRENT 8.2および19の「営業中は器具本体だけ」の旧制約を更新し、空の卓上熱源も移動可能とする

## 1. 動かせる範囲

営業中は共通作業台の場所を変えず、その上の小型設備を運ぶ。対象は、まな板、卓上コンロ、ミキサー本体、配達容器スタンド、卓上ゴミ箱。消火器と鍋・フライパンは従来どおり手持ち道具として運べる。ミキサージャーの取外しと本体移動の入力分離は59で具体化する。

床・壁・作業台本体・原料箱・水場・皿返却口・提供口・配送代行棚・バイクの発送拠点は営業中の配置変更対象にしない。固定の距離と通路で各面の個性を残す。本店の営業前編集とは別の範囲である。

コンロを別商品・別強化項目にしない既定を維持する。鍋／フライパン購入に付属する熱源を物理的に移せる案。熱源と器具の能力対応・互換性は別途整理し、運ぶだけで能力が増減しないようにする。

## 2. 普通の調理入力と設備移動を分ける

> 更新決定: 鍋・フライパン・ジャーは載せたまま本体ごと長押しで運べる。[60の一式運搬仕様](60_carry_equipment_with_vessels.md)を採用し、以下の対象3器具についての事前取外し・空限定・押下時即時取得を置き換える。短押しは指離しで上部器具を取得し、長押しは一式を取得する。他設備へ自動拡張しない。以下は旧案の経緯として残す。

- 食材・料理・鍋が載っている時の「取る／置く」は、従来どおりその物を即座に取る。
- 手ぶらで、上に物がない・未使用の可搬設備を対象にして「取る／置く」を短く長押しすると設備本体を持ち上げる。
- 空いている作業台へ通常の「置く」で設置する。専用編集画面、新ボタン、設置確認ダイアログは加えない。

コンロを動かす場合は「鍋を別の台へ置く→空のコンロを長押しで持つ→新しい台へ置く→鍋を戻す」。加熱中の鍋をすぐ火から外す操作に、長押し待ちを追加しない。

食材を取った同じ押下を続けても、その下の設備を連続取得しない。設備を持つには改めて押す。長押し成立前の対象輪郭・予備動作で何を持つか示す。秒数は未確定。

## 3. 持ち運び中のルール

設備本体は空・未使用・非火災時のみ移動可能とする。鍋の持ち上げは従来の調理操作として別扱い。設備は一つの手持ち枠を占有し、投げられない。

設備を床へ設置して通路を封鎖することはできず、有効な空き作業台へだけ置ける。置き先に料理や設備があれば自動交換・押し出しをせず、手持ちを維持する。運搬中は通常移動速度を維持し、設備本体の運搬中だけダッシュ不可を第一試験案とする。旧25の一律低速化と重ねて二重に不便にしない。鍋・料理等の通常手持ちには新制限を加えない。

移動にコイン・回数制限・耐久度は設けない。注文処理から離れる時間と置き場の消費が自然な負担になる。

設備の場外落下・復活・切断で必須設備が永久消失しないことを必須の設計条件とする。元セルが埋まった際の復旧位置などは別途決める。同時取得で設備が複製されたり、非操作料理人が作業中の設備を奪えたりしないことも検証する。

## 4. 出張の面白さを消さない盤面

初期配置のまま星1を狙える面を標準とする。移動の導入面は一度の安全な練習を設けてもよいが、全ステージを開幕模様替え必須にしない。1-3以前のマルチ参加に必須の技術にはせず、紹介面の配置は別途決める。

まな板を材料側へ寄せれば完成品を運ぶ距離が増える、コンロを寄せると料理を仮置きできる面が減る、等の分かりやすい交換条件を作る。通常の一時置き場まで欠乏させないよう、各区画に十分な共通作業台を用意する。

星2・3の必要条件として設備移動回数を設定しない。スコアのみで評価し、初期配置を使いこなす攻略も許す。個々の設備を理由なく固定して難度を維持するのではなく、固定された通路・原料・提供位置、島の構造で制約を残す。

## 5. 配置保存とモード差

- 本店通常営業: 営業前の選択配置から開始。営業中に改善した配置は準備画面で確認し、既存3枠へ明示保存できる案。既存プリセットは自動上書きしない。持ち運び中など無効状態は保存対象にせず、確認時に整える。
- 通常営業の「同じ献立でもう一度」: 選択中の有効な準備配置から開始し、直前営業中の変更を黙って引き継がない。残す時は準備画面を経由する。
- 出張: 毎回作者指定の初期配置に戻す。営業中の移動時間もスコア攻略の一部。持込み配置保存は追加しない。
- シーズン競技: 営業前カスタム配置の既定を維持する。営業中の可搬操作も同じルールを使う案。開始配置・移動履歴を結果検証に残し、途中移動で所持外設備や追加台数を得ない。

## 6. 検証の入口

同じ小さな試験盤面で、初期配置のまま／まな板だけ移動／コンロも移動を比較する。初心者の誤取得、配置に使った時間、注文処理、空き台不足、ソロ二人切替、マルチの同時取得を確認する。移動量が多いほど良いとは評価しない。

移動の操作秒数・速度・復旧場所・導入ステージ・熱源の能力対応は未確定。本書は仕様提案であり、Unity・アセット・レベルデータを変更しない。
