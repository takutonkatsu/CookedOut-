# COOKED OUT! 献立変更時の厨房準備と料理解放の整合 v0.2

- 作成日: 2026-09-13
- 状態: ユーザーが原料箱・設備準備・料理解放の方針を承認。共用原料位置維持、設備差分準備、配置に合う推薦、出張解放との整合を採用。具体料理・割当面・自動配置アルゴリズム・推薦の数値重みは未確定・未実装
- 前提: 各営業Lvで別定番、Lv1〜4は1系統・Lv5以降は2系統。具体料理・原料・工程は保留

## 1. 既定の準備ルール

厨房12×9と固定供給口の場所を維持し、営業前に献立へ合わせて供給内容を割り当てる。必要設備を所持していても未配置なら開始前に配置する。有効な配置は維持し、手動編集・保存3枠・推奨配置を使える。未所有設備の自動購入や保存枠の自動上書きはしない。

## 2. 原料箱の中身を変えても覚えた場所はなるべく維持する案

- 両献立で共用する原料は同じ箱位置に残す。
- 使わなくなる原料の枠と空き枠だけへ、新たな原料を割り当てる。
- 変更箇所を開始前に短く強調し、中身は営業中に変えない。
- 原料の購入・補充・在庫管理を新設しない。原料箱の位置移動を許可する変更でもない。
- 必要原料が供給枠に収まらない組合せは不適合。途中で箱を自動切替して成立させない。
- 保存配置読込時は保存の割当意図を可能な範囲で優先し、献立との差分を確認する。保存内容を勝手に書き換えない。

## 3. 設備は不足分だけ準備する案

献立変更で床・作業台・使用可能な設備を一括撤去しない。使わない設備も動線と必要設備配置を妨げなければ残せる。空き面があれば未配置の必要設備だけを案内し、衝突する場合は変更箇所を確認してから配置する。

ゲーム推薦の順位は、まず定番と組み合わせ可能であること、その中で配置変更の少なさ・原料共用・偏りを抑えた工程構成を考慮する案。最高得点や最高収入を保証せず、「今の設備で作れます」「配置変更が少なめ」等の根拠を短く示す。詳細な重みや同率の選定は後で決める。

## 4. 毎Lv別系統と出張での解放を接続する案

20営業Lvに別々の定番を割り当てるため、少なくとも20の異なる系統が必要。既存の正式版36系統目標を活用し、専用器具・新操作を20種類作る要件とはしない。名前だけ違う派生を系統数の水増しには使わない。

出張の昇格条件をクリアした時点で、その条件で進める営業Lv帯の定番が解放済みになるよう、料理解放表を先に照合する。料理ごとに追加のランク条件や強制出張を増やすことは第一案にしない。

現行の第1章はサラダ・スープ・ハンバーグプレートの3系統で、完了後に進める通常Lv1〜4の4つの別定番に1系統不足する。第1章の既存8面の中で、既習操作だけで扱える4つ目を自然に経験・解放させる案を推奨する。具体料理、割当面、全レシピの数は保留。教程の新操作や面数を増やさず、初心者の理解負荷を検証する。

第1章の既存8面内で既習操作による4系統目を経験・解放する方向を採用する。具体料理と割当面は料理専用タスクとの相談事項であり、各面の献立はまだ差し替えない。Lv5でも新しい定番とおすすめ導入が重なるため、既習工程の定番と、以前の定番を含む分かりやすい推薦で負荷を抑える。Lv5時点で以前のおすすめ履歴がない例外は42の表示案を使って検討する。

## 5. 検証項目

- 正常な必須進行で全20定番が使用可能になり、未習得料理・未所有必須器具で停止しない。
- 二系統解放後は定番以外に最低1つの適合候補がある。
- 原料共用で箱位置が安定し、初見でも変更箇所を把握できる。
- 有効配置で再営業する人は編集を要求されず、変更する場合も必要な差分を理解できる。
- 毎Lv別系統でも操作の再学習を強要せず、星1までの負荷が急増しない。
