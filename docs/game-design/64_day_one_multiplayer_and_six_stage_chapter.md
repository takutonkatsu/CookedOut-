# COOKED OUT! 初回マルチ解放と第1章6面への再編方針 v0.2

- 状態: 2026-09-13ユーザーが公開回答1・3・4を承認。最初からマルチ、第1章の章星8撤去、ソロ・協力をまたぐ第1章クリア／本店解放を採用。第1章6面を基本として、公開回答2の各面構成・導入要素の移設はステージ設計時まで保留。未実装。未公開細部は一括承認しない
- 採用済みの前提: 第1章自体がチュートリアル。別講習なし。初回と再挑戦は同一時間・初期条件・ランキング条件。開始前に盤面とギミックは公開しない

## 1. 最初から友達と開始する

初回からソロ出張とマルチの作成・招待・参加を選べるようにし、ソロ1-3クリアをマルチの条件から外す案。オンライン接続等の製品上必要な初期手続きは別とし、ゲーム内チュートリアルクリアを招待前に要求しない。

新規プレイヤー同士は1-1から一緒に進める。既存のホストが解放済みの後続面へ新規ゲストが参加することも許し、入口で強制講習を追加しない。ホストが選べるステージまで最初から全解放する案ではない。途中参加禁止は営業中だけの既定として維持する。

## 2. 第1章は6面、本店の基本へ絞る

> ユーザー指定により、この節の各面割当・皿洗い／動的厨房の導入章・補助操作の紹介位置は保留。下表は再検討時の候補であり、実装・料理解放の確定表として使用しない。

8面分をそのまま詰め込まず、皿洗いと動的厨房の本格導入を第2章以降の通常ステージへ移す案。別チュートリアルは作らず、新要素に適した簡単な初登場面で学ぶ。

| 面 | 主題 | 主な体験・境界 |
|---|---|---|
| 1-1 | 一皿作って提供 | 移動・取る／置く・切る・組立・提供。安全で短い動線、少ない材料。ソロとマルチ双方の入口 |
| 1-2 | 鍋を見ながら次の仕事 | 鍋加熱・完成通知・火から外す。ソロ二キャラ切替は加熱待ちと並行作業の中で紹介する候補 |
| 1-3 | 投げて、バイクで届ける | 食材投げ・積載・乗降・4ボタン運転。短い一本道、交通と複雑な配達順はまだ要求しない |
| 1-4 | フライパンで仕上げる | 個別加熱と盛付け。ダッシュは短いゲーム内ヒントで解放する補助要素とし、習得チェックや必須ダッシュ障害物は置かない |
| 1-5 | 厨房を整え、立て直す | 既習料理で消火・作り直し。既存の持つ／置くの延長で設備一式移動を紹介する候補。新料理・新加熱機器は重ねない |
| 1-6 | 本店営業の予行演習 | 既習料理で自配達と配送代行を選択。動的床・皿洗いなしの固定厨房で総合営業し、クリア後に本店解放 |

各面の主題と補助要素は検証候補であり確定割当ではない。1-3の投擲＋運転、1-4のフライパン＋ダッシュ、1-5の消火＋設備移動が過密なら、補助要素は紹介だけに留め後続章で活用する。新しい操作の必須試験を増やして面数減の効果を打ち消さない。

ミキサー・オーブン・フライヤーは第1章に詰め込まず、料理側の解放順と合わせて後続章で導入する。通常Lv1〜4には4種類の異なる定番系統が必要という既定があるため、6面内で既習操作による4系統を経験できるか料理側と整合させる。既存3系統だけで本店献立条件を満たした扱いにはしない。具体料理はこのタスクで独断確定しない。

## 3. 第1章だけは星更新による足止めを外す

第1章は各面星1で次へ進め、1-6にも旧「章進行星8」を追加要求しない案。初期5面が各星1なら1-6へ挑める。既定の第1章星基準15/30/50%と星3・自己ベスト・人数別ランキングは残す。

これは第1章を短くするための明示的なゲート変更提案。第2章以降の章星条件・終盤星更新・店ランク昇格条件まで撤回しない。

## 4. 協力で学んだことは、本店解放にも使う

本店解放は第1章の各面を一回以上星1でクリアしたことを条件とし、ソロ・協力のどちらで達成しても、途中で遊ぶモードを変えても認める案。

人数別の星・スコア・ランキング、ソロ出張と協力出張の実績トラックは引き続き分離する。それとは別に、第1章各面のクリア済み判定を学習・本店解放用に共有する。1-1〜1-3を協力、1-4〜1-6をソロでクリアした場合でも本店が開く。

第1章の次面を選ぶ権利もこの共通クリア順から得る案。モードを変えたせいで1-1からやり直す必要はなく、未挑戦側の星を自動付与するわけでもない。先行参加で1-6だけクリアしても、未クリアの前提面は免除しない。既存の先行報酬の二重付与防止・切断時参加資格は維持する。

料理・道具も、第1章の共有クリアで習得・初回解放を判定する方向を推奨。初回付与をソロと協力で二重に行わない。本店は引き続きソロ専用であり、通常営業をマルチ化する提案ではない。

第2章以降のソロ／協力進行、店ランクの指定ソロ出張条件、シーズン参加資格の共通化は今回自動変更しない。後続の進行整理で、初回自由参加とソロ成長の境界を再確認する。

## 5. 時間と全体ステージ数

面数6でも一面が長ければ負担は残る。4分という既定は通常営業の値であり、出張第1章全6面を4分固定へ自動変換しない。初回クリアまでの実時間・再挑戦回数・説明停止なしの理解度で評価し、具体秒数は別途決める。

全9章54面は制作目標として一旦維持するが、旧配分8＋7×6＋4は再編対象。第1章を6へ変えるだけなら52面となるため、54面を維持する場合の2面の移設先は未確定。皿洗い・動的厨房の導入を後続の既存面へ統合するか、移設した面を追加するかは章計画で決める。既存ステージや実装データを今回削除・改番しない。

## 6. 検証

初回インストールした二人が互いを招待して1-1へ入れるか、未経験ゲストの後続面参加、ソロ・協力の途中切替、先行クリアと報酬重複、全員初心者の理解度、本店解放直後の献立と設備の充足を確認する。個人ごとの強制的な操作達成チェックや貢献点を新設しない。
