# COOKED OUT! 協力プレイのクイック合図案 v0.1

- 作成日: 2026-09-14
- 状態: 2026-09-14、ユーザーの「全て良いと思います」で公開した方針を採用。初期版の3種、選んで送信、送り主の分かる短時間表示、ソロ非表示、連投抑制、任意非表示、自由文・会話履歴を初期範囲に含めない方針が対象。具体配置・秒数・未公開細部は未確定。Unity・通信・UIは未実装
- 前提: 友達とのオンライン出張営業。野良マッチなし。既定の配送中・事故・切断表示は維持。デイリーと追加章の具体数値は保留のまま

## 1. 目的と採用範囲

声を出せない環境でも、短い意思表示で協力しやすくする。初期版に軽量なクイック合図を入れることを提案するが、操作習得や送信を攻略の必須条件にはしない。ソロには表示せず、厨房や配送状態を見て理解できる設計を優先する。

## 2. 最初は3種類

| 合図 | 用途 |
|---|---|
| 助けて | 手が足りない、作業を手伝ってほしい |
| 了解 | 仲間の呼びかけに応じる |
| ありがとう | 手助けや受け渡しへの反応 |

配達中・事故・切断は既定の状態自動表示へ任せる。自動の「配達中」は出発前の意思表明を代替しないが、初期案では手動の「配達に行く」等を増やさず、必要性をテストする。

「助けて」は作業内容まで特定できない弱点がある。盤面と送信者の場所で十分に通じるかを確認し、通じなければ対象を指定する合図を再検討する。最初から役割担当、注文予約、作業指示の管理機能を追加しない。

## 3. 送信と表示の初期案

- 小さな合図ボタンから3アイコンを開き、選んで送信する。二段階操作の試案であり、旧説明の「一操作」を厳密に維持する決定ではない
- 走行中も使用可能な位置を検討するが、アクセル・方向操作を遮らないことを優先する。厨房用と配達用の実配置は未決定
- 厨房内は送信者の頭上に短い吹き出し。厨房外の仲間には顔アイコンを添えた小さな通知で送り主が分かるようにする
- 合図は数秒で消え、注文票や調理タイマーを覆わない。色だけに頼らず形で判別できるアイコンにする。最終アートと意味理解は検証する
- 自動状態表示を合図で消したり、合図を切断表示より優先したりしない
- 同じ人の表示は置き換え、短い送信間隔制限を設ける。正確な秒数は試作で決める
- 合図表示を控えたい人向けに非表示設定を用意する案。事故・切断等の必須状態表示は残す

## 4. 初期の範囲を広げない

自由文チャット、会話履歴、細かい対象指定、合図の課金販売は今回の初期案に含めない。ボイスチャットの採否は別論点とし、この文書で無断決定しない。合図によるスコア・報酬・担当割当・キャラクター自動操作は発生させない。

## 5. 確認すること

初心者がアイコンを理解できるか、助けてが曖昧すぎないか、走行操作と干渉しないか、画面が狭くならないか、連投が邪魔にならないかを確認する。公開方針の採用と、実機での操作・表示の検証完了は区別する。
