## 1. 開始前に盤面・ギミックを公開しない（決定）

出張のステージ詳細・ロビーでは盤面、設備配置図、具体的なギミックの印・動作例・下見を表示しない。ロード背景やサムネイルで実質的な盤面プレビューを行わない。旧案の任意ギミック動画も撤回する。

作る料理の完成品アイコン程度は事前に表示する候補として残す。全注文順・詳細攻略・ギミックの説明へ広げない。料理表示の必須化、提供方式等その他の事前表示範囲は今回一括確定しない。

開始前の仕込み・設備移動・自由歩行は設けない更新案。厨房の発見は本番の中に置く。営業前の役割登録も義務化しない。

## 2. 二重の準備完了を要求しない

ソロはステージ選択から「開始」。マルチは同じロビーで各自が「準備完了」とし、全員の準備完了後にホストが開始する。別の下見ルームへ移ってもう一度全員確認する段階は追加しない。この公開範囲は採用済み。

ホストがステージ、人数構成、ゲーム条件を変更した場合は準備完了を解除し、新条件を確認してもらう。営業前は従来どおりメンバー変更可能。初期案ではゲストの未習得要素を理由に強制実地ガイドを挟まない。

全員のロード・接続準備が整ってから共通の3秒カウントダウンを開始する公開方針は採用。通信同期の実現方法は別途検証し、端末差で一人だけ早く時計が進む設計にしない。準備中・カウントダウン中に参加予定者が切断した場合は開始を取り消しロビーへ戻る細部は未承認案。営業開始後の切断は既存の継続ルールへ切り替える。

## 3. 厨房公開・操作と営業時計は同時に開始する更新案

事前盤面非公開を守るため、3秒のカウントダウン中も盤面を見せず、「開始」と同時に通常の厨房カメラへ切り替える。第1章も含め、余分な見回しカメラ演出は設けない。この公開方針は採用済み。

3秒のカウントダウンは営業時間に含めず、その間はゲーム操作を受け付けない。終了時点で営業時計・料理人操作・本番ギミック・注文発生処理を一緒に開始する。

最初の注文は操作可能になった時点で現れ、その残り時間も同時に動く案。後続注文の既定間隔・最大数は変更しない。注文が出るたびにプレイヤーへ受付・ウェーブ開始操作を要求しない。

開始まで押し続けていた取得・投擲・作業入力を勝手に実行しない。カウントダウン中の視覚・音響演出はあってよいが、厨房の動的床だけ先に進める等の状態差を作らない。参加人数ごとの初期位置は作者指定の位置を使う。
