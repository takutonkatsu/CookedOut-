# COOKED OUT! 初期プレイ分析の記録範囲と改善判断案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、公開4点をユーザー承認で採用。営業結果と主な失敗要因、準備・成長の詰まり、条件別自動集計と人による改善判断、分析送信障害をプレイや正規報酬へ波及させない方針。項目定義・収集説明・選択・保持期間・サービス等は未確定。実ユーザーデータの取得・SDK導入・送信先設定は行わない
- 既定: 本名・住所・不要な自由入力文等は分析対象にしない。ランダムな内部ID、イベント定義・版管理、開発環境での確認、オフライン送信上限を設ける。問い合わせ本文・画像は通常のゲームバランス分析へ無条件流用しない

## 1. まず営業単位で結果と主な原因を記録する

営業開始と正規終了を区別して記録し、モード、面／営業Lv／シーズン課題、人数、初回か再挑戦か、献立、設備種類Lv・台数、ルール版等を比較条件として使う案。画面の全録画や、全プレイヤーの毎フレームの座標送信は初期の通常分析に設けない。

集計対象はスコア・星・納品／失注数、手配経路別の件数・得点、焦げ・火災・誤料理廃棄・大きな配送事故の回数等。ゲーム側で原因を特定できる場合だけ分類し、すべてのゴミ箱利用を誤料理扱いにしない。営業内の回数は可能な範囲で端末側に集約して送信量を抑える。

「注文票が空だった時間」や、到着済みなのに次の注文が供給されなかった状態等、既定ルールから定義できる待ちを確認する。入力がない時間だけで退屈・放置と断定しない。工程別のボトルネックを追う詳細記録は必要性と予算を見て限定する。

開始だけが残り終了情報がない営業は、クラッシュ・切断・未送信・任意終了を確認できる範囲で区別する。理由不明のものを難しくて諦めた扱いに一律変換せず、「理由不明／結果未確認」として区別する。

## 2. 遊び始める前と、成長で詰まる箇所も見る

献立の前回／おすすめ／ほかのメニューの利用、献立変更、必要設備不足などによる開始不可、昇格条件待ちの理由を集計する案。画面中のすべてのタップを収集するのでなく、意味のある選択・開始失敗・状態到達に絞る。

昇格では必要評判に到達してから、出張条件・設備条件のどちらを待っているかを分ける。設備の購入・強化と営業回数を確認し、目標としている稼ぎ回数から大きく外れていないか評価する。実際の残高・昇格・付与は正規取引を正とし、分析イベントを資産台帳として使わない。

ロビーでは集合から開始までの時間、準備解除・ロード失敗・切断等を集計し、待機が長い原因を確認する。プレイヤー同士の会話や端末の連絡先を記録する機能は設けない。後日検討のロビー調理の採用をこの案で確定しない。

## 3. 条件を分けて自動集計し、調整は人が決める

初回／再挑戦、人数、設備Lv、献立、ルール版、開発・テスト／本番を区別して集計する案。人数も設備も異なる全プレイの平均だけで難度を判断せず、対象の件数も示す。開発者のテストを一般プレイヤーの成功率に混ぜない。

星の分布・初回クリア率・配送方法別の結果・昇格までの営業回数などを自動でまとめ、急なエラー増加や特定面の極端な失敗を確認できるようにする。警戒基準・必要件数・集計周期は未決で、少数データから即断しない。

自動化するのは集計と気づきの補助まで。個人の失敗数に応じて注文をこっそり簡単にしたり、分析値を見て本番の星基準・価格を無承認で変更したりしない。必要な改善案は試遊・再現確認と合わせて判断し、ルール版と既定の競技公平性を保って反映する。数値だけで「面白い」と判断しない。

## 4. 分析送信の失敗で、プレイや正当な報酬を止めない

任意の改善分析と、営業結果の検証・資産確定に必要な処理を分ける案。分析送信先が落ちても、それだけを理由に営業開始や正当な報酬確定を止めない。正規結果の検証ができない場合に95の同期待ちへ進む規則は維持する。

分析用の未送信データは件数・容量・保持期間に上限を設け、超過時は古い分析用情報を破棄できる設計にする。未同期の正規営業結果や資産情報を同じキューの都合で捨てない。再送の重複は分析でも除外して回数を水増ししない。

匿名化済みと無条件に称さず、ランダムIDでも継続的なプレイ記録であることを踏まえて扱う。収集の説明・ユーザーの選択、保持期間、閲覧権限、利用サービス、年齢・プライバシー上の対応は別途具体化し、今回の承認だけで実収集を開始しない。

## 5. 次の実装前に決める項目

イベント名・必須項目・送信タイミングと量の上限、分析用識別子の扱い、定義表、保持・削除期間、収集説明と選択、アクセス権、サービス費用、サンプリング対象。日課・マネタイズが保留なので、それらの具体効果測定も仕様決定後に定義する。SDKや外部サービス選定時は公式情報を確認する。
