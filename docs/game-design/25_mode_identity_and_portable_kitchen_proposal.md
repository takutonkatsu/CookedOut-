# COOKED OUT! モード棲み分け・可搬厨房・ソロ切替案 v0.1

- 作成日: 2026-09-12
- 状態: ウェーブ廃止、自動注文、ソロ出張の二人切替、作業台を十分配置する方針を決定。可搬設備の詳細は推奨案
- 目的: 複雑化せず、初心者が参加でき、熟練者が自分なりの回し方を見つけられる構造を定める

## 1. 上位テーマ

> **すぐ遊べる。何をすればよいか分かる。**  
> **でも、慣れるほど自分なりの回し方が見つかる。**

新しさを、追加ボタン、長い選択画面、細かな経営管理から作らない。料理中に使う既存の「持つ・置く・作業する」から、厨房そのものを少し整えられることを本作固有の奥行き候補とする。

## 2. 決定事項: 営業ウェーブは作らない

- 注文票は営業時間中、ルールに従って自動的に追加される
- プレイヤーが次ウェーブの開始時刻を選ぶ仕組みは実装しない
- 忙しさは、注文間隔、同時注文数、工程競合、厨房構造から自然に発生させる
- 圧力と息継ぎは内部の注文生成曲線で作るが、プレイヤーにウェーブという管理単位を意識させない
- 競技ステージでは注文列と発生時刻を同一条件に固定できる
- 通常営業では、難度帯を守った範囲で注文種類と順序に変化を持たせる

## 3. 通常営業と出張営業の棲み分け

| 項目 | ソロ通常営業 | 出張営業 |
|---|---|---|
| 主な対象 | 反復・最適化を楽しむプレイヤー | 初心者を含む友達同士・家族・ソロ攻略 |
| 操作人数 | 一人の料理人だけを操作 | ソロは必要に応じ二人を切替、協力は一人一キャラ |
| 厨房 | 12×9の自分の本店 | 開発側が設計した固有厨房 |
| 注文 | 選んだ営業メニュー内から自動発生 | ステージ既定の注文票が自動発生 |
| 配置 | 営業前に広く編集できる | 初期配置は作者指定、営業中に可搬設備だけ移動可能 |
| 成長 | 設備、メニュー、記録、効率化 | 星、自己ベスト、章進行、ステージ攻略 |
| 難度 | 反復するほど配置と処理を詰められる | 星1はワイワイ完走、星2・3は連携と工夫 |
| 失敗の感情 | 次の改善策が分かる | 仲間と笑えて短時間で再挑戦できる |

出張営業を浅くするのではない。星1への入口を広くし、同じ面の星3とランキングには十分な奥行きを残す。通常営業は長く遊べる最適化と成長の中心にする。

## 4. 「注文群選択」の具体像

先に「注文群」と呼んでいたものは、営業中に次の注文を一件ずつ選ぶ仕組みではない。通常営業の開始前に、その営業で扱う料理の組合せを一つ選ぶ**営業メニュー選択**を想定していた。

例:

| 候補 | 料理構成 | 必要設備 | 特徴 |
|---|---|---|---|
| A 手軽なメニュー | サラダ、野菜スープ | まな板、鍋 | 安全、低〜中報酬 |
| B バランスメニュー | 野菜スープ、ハンバーグ | まな板、鍋、フライパン | 標準 |
| C 加熱中心メニュー | スープ二種、炒め物 | まな板、鍋、フライパン複数 | 忙しい、高報酬 |

一つを選んだ後は、その料理群の注文票が自動で追加され続ける。個別の注文を選ぶ操作はない。

### 4.1 推奨仕様

- 通常営業の開始前だけ、解放済み料理から互換性のある三候補を提示する
- 各候補には料理画像、必要設備、難しさ、基礎報酬を絵中心で表示する
- 初心者向けに「おすすめ」を最初から選択済みにし、そのまま一操作で開始できる
- メニュー決定後、必要設備だけを強調し、推奨配置を一操作で適用できる
- 注文発生は完全自動とする
- 出張営業には営業メニュー選択を持ち込まず、ステージ固有料理を使う

これは通常営業のやり込みには有効だが、Core Alphaで準備が長く感じる場合は三択をやめ、「おすすめを即開始／変更したい人だけ開く」という二段階表示へ簡略化する。

## 5. 可搬厨房の基本構造

### 5.1 ステージ作者が固定するもの

- 床、壁、穴、通路
- 共通作業台の形と位置
- 原料箱
- 水場と皿返却口
- 提供口
- 配達用の退出地点や大型の配送代行棚
- 扉、橋、移動床等のステージギミック

これらが、そのステージ固有の距離、分断、受け渡し、混雑を作る。

### 5.2 プレイヤーが動かせるもの

- まな板
- 卓上コンロと鍋の一式
- 卓上コンロとフライパンの一式
- 配達容器スタンド
- 卓上ゴミ箱
- 必要に応じ、消火器等の小型安全設備

設備は空いている共通作業台一セルへ置ける。専用配置画面を開かず、厨房内で既存の「持つ・置く」を使う。

### 5.3 操作案

1. 手ぶらで、使用中でない可搬設備へ近づく
2. 「持つ／置く」を短く長押しする
3. 設備が持ち上がり、両手がふさがる
4. 空いている作業台へ近づくと設置先が輪郭表示される
5. 「持つ／置く」で設置する

新しい専用ボタンは作らない。通常の食材を誤って取らないよう、設備を持ち上げる時だけ短い長押しと明確な予備動作を使う。

### 5.4 移動制限

- 食材や料理が載っている設備は移動できない
- 加熱中、焦げ中、火災中のコンロは移動できない
- 設備運搬中は食材を持てず、投げられない
- 運搬中の移動速度は通常より少し遅くする
- 空いている作業台だけへ設置できる
- 原料箱、水場、提供口等へ重ねられない
- 設置不可理由はその場で形と音により示す

移動そのものを難しい操作にせず、「いま二秒を配置改善へ使うか、注文処理を続けるか」を判断にする。

## 6. 作者が作る不便さを残す方法

設備を動かせるからといって、ステージの面白い不便さが消えるとは限らない。最終的な距離とボトルネックを、動かせない構造側へ持たせる。

### 6.1 残り続ける制約

- 原料箱と提供口の距離
- 水場と皿返却口の位置
- 作業台の島、向き、空きセル数
- 狭い通路と交差点
- 分断された区画
- 食材を渡せる窓やベルト
- 配達口までの退出経路
- 床ギミックや障害物

まな板を原料箱の近くへ移せても、鍋、容器、提供口まで全部を近づける作業台面積はない、という状態を作れる。どこかを便利にすると別の距離が伸びる配置が理想である。

### 6.2 初期配置の役割

作者は意図的に少し不便な初期配置を作る。初心者はそのまま「遠い！」と笑いながら星1へ到達でき、慣れたプレイヤーは営業中の数秒を使って直せる。

- 星1: 初期配置のままでも十分可能
- 星2: 一か所の明確な改善で届きやすい
- 星3: 注文構成と分担に応じた二〜三か所の改善が有効
- ランキング: 移動する時刻と順序まで最適化対象

可搬厨房の導入面だけは、一度の設備移動をクリアに必要な安全な学習として使ってよい。それ以外では毎回の移動を義務にしない。

### 6.3 「正解配置が一つ」の対策

- 全設備を最良位置へ集められない作業台面積にする
- 固定された入口と出口を複数方向に置く
- 一営業に複数料理を出し、優先する工程によって配置を変える
- 人数ごとに混雑しやすい場所が変わる
- 配置結果ではなく、配置変更に費やす時間もスコアへ自然に反映させる

完全に正解配置をなくす必要はない。良い配置を発見すること自体を、通常営業のやり込みと出張営業の星3攻略にできる。ただし全ステージで同じ並びが正解になる場合は、固定設備と作業台構造が弱い。

## 7. 出張営業での使い方

可搬設備は全出張営業で利用可能にできるが、全ステージの主役にはしない。

| 面の型 | 可搬設備の役割 |
|---|---|
| 初心者向け固定厨房 | 動かさなくても完走。偶然動かして発見できる |
| 可搬厨房の導入面 | まな板一台を明らかな空き台へ移す |
| 分断厨房 | 各区画へ何の設備を残すか考える |
| 狭い厨房 | 移動より、混雑しない置き場所を考える |
| 配達面 | 容器スタンドを厨房側か退出側へ寄せる |
| 加熱面 | コンロを材料側か組立側へ寄せる |
| 動的厨房 | 動く床の上へ何を置くかを選ぶ。操作レバーは不要 |

本家型の「なぜこんなに離れているのか」という笑いは初期配置と固定構造で残し、本作では「だったら営業中に自分たちで直してみよう」という次の遊びへつなげる。

## 8. ソロ出張営業の二人切替

### 8.1 決定方針

- ソロ通常営業は一人のキャラクターだけを操作する
- ソロ出張営業では二人のキャラクターを切り替えられ、分断厨房も同じ盤面で成立させる
- マルチ出張営業は一人のプレイヤーが一人のキャラクターを操作する
- 序盤チュートリアルでは二人目を段階的に解放できるが、切替習得後のソロ出張は原則二人を使用する
- 最初の分断厨房より前に、安全な場面で切替操作を教える

### 8.2 切替操作

- 専用のキャラクター切替ボタンをソロ出張時だけ表示する
- 切替は即時、待ち時間なし
- 厨房全体固定カメラのまま、選択中のキャラクターへ輪郭、足元マーカー、顔アイコンを付ける
- 画面外カメラ移動は発生させない
- 切替先が危険状態の場合は、顔アイコンと音で先に知らせる

### 8.3 非操作キャラクター

非操作中のキャラクターは、自分で歩いたり次の仕事を判断したりしない。AI代行にはしない。

完全停止案は採用せず、指示済み作業だけを継続する。

切る、洗う等、プレイヤーが開始した定位置作業は、キャラクターを切り替えても完了まで続ける。これは自動で仕事を探すAIではなく、開始済みの一作業の継続に限定する。終了後はその場で待機し、食材運搬、設備移動、消火、提供等は行わない。

### 8.4 作業台数

- 各区画に、料理を置くための空き作業台と可搬設備用作業台を十分に用意する
- 可搬設備を一台置いただけで、料理の一時置き場がなくなる盤面を標準にしない
- 狭さを主題にするステージだけ、意図的に空き台を減らす
- 分断厨房では、各側に最低一つの一時置き面または受け渡し面を保証する
- 正確な台数は厨房規模、料理数、人数ごとに盤面レビューで決める

### 8.5 ステージ設計上の条件

- 二キャラクターの完全同時精密操作を要求しない
- 片方の区画で作業を開始し、切替後にもう一方を進められる構造にする
- 受け渡し点を画面内で同時に確認できる
- 非操作キャラクターだけが突然不可逆な失敗を受けないよう予告する
- ソロ星ラインは一人が二キャラクターを切り替える操作量で個別調整する

## 9. Core Alphaで確認する最小範囲

全設備と全ステージへ一度に入れず、次だけを試す。

1. 一つの10×8厨房
2. 固定された原料箱、水場、提供口、作業台
3. 移動可能なまな板一台とコンロ一台
4. 自動的に流れる注文票
5. 初期配置のままと、一台移動した配置の両方で完走
6. 一人操作版と、二キャラクター切替版
7. 初見、慣れた人、スコア狙いで行動差を観察

合格条件:

- 初見者が説明なし、または一枚の絵で設備を移動できる
- 誤って設備を持つ、食材を取る割合が許容範囲に収まる
- 初心者が設備を動かさなくても星1相当へ届く
- 設備を一台動かした時、移動時間を含めても別の有効な攻略になる
- 全員が同じ配置だけを選ばない、または同じ配置でも発見の楽しさがある
- ソロ切替が作業量ではなく段取りを生む
- マルチで他人の設備移動が継続的な不快や妨害にならない

## 10. 現時点の推奨結論

1. ウェーブ操作は廃止し、注文票を自動発生させる。
2. 通常営業は一人操作、配置・営業メニュー・設備成長・記録更新によるやり込みを中心にする。
3. 出張営業は星1の入口を広くし、ステージ固有のハチャメチャさと協力を中心にする。
4. 可変厨房はレバー切替ではなく、共通作業台上の現実に動かせる設備を既存操作で移動する仕組みにする。
5. 作者の不便さは、固定作業台、原料箱、水場、提供口、通路、分断で残す。
6. 初期配置でも星1、改善配置で星2・3とランキングを狙える構造にする。
7. ソロ出張営業は必要な面で二人を切り替え、指示済みの定位置作業だけ継続する案を試す。
