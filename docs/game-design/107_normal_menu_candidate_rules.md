# COOKED OUT! 通常営業の追加系統候補と選択維持案 v0.1

- 作成日: 2026-09-15
- 状態: 2026-09-15、ユーザーは後半系統の先行選択を再検討し、それ以外の公開方針を承認。基本2品習得・調理適合、三入口の例外処理、Lv別前回選択保持、Lv5のサラダ推薦、候補ゼロ回避を採用。後半系統を選べるかは108で相談し、未確定。実装・料理・ステージデータは変更しない
- 前提: 通常営業Lv1〜4は定番のみ、Lv5〜20は定番＋選択系統。各系統は基本2品のみ。106の定番割当と既定昇格ゲートを維持

## 1. 選べる条件

選択する追加系統は、基本2品がどちらも習得済みで、定番とは別の系統に限る案。3品目の習得は不要。定番2品と追加2品の合計4品について、必要原料の供給枠・所有設備・設置容量で調理と提供が成立するか確認する。

所有しているが今は未配置の設備は候補判定に使える。配置前なら開始前の準備を案内する既定を維持。新しい料理を一品見ただけ・招待先で説明を読んだだけで系統全体を通常営業に追加しない。

旧提案の後半系統の先行選択可は撤回。108の後続承認により、定番として初登場する営業Lvが今回の営業Lvより低い系統だけを追加候補とする。現在の店ランクが高くても、低Lvへ戻ればその営業Lvの制限を使う。基本2品習得・設備容量適合も維持する。

## 2. 三つの入口

- 前回のメニュー：選択中の営業Lvで前回使った追加系統。同じLvへ戻ればその選択を呼び出す
- ゲームからのおすすめ：適合候補から一つ。配置変更の少なさ、原料共用、作業の偏りを考慮する既定を使う
- ほかのメニュー：今回選べる候補をすべて表示する

初回は前回欄を未選択と分かる状態にし、推奨候補を初期選択する案。前回と推薦は可能なら別系統にする。適合候補が一つだけなら同じカードを二つ並べず、一候補と一覧入口へ整理する。候補を増やすために未習得・調理不能なものを混ぜない。

初めて2系統になるLv5では、寿司の定番に対しサラダを最初の推薦候補とする案。既習で非加熱の作業を組み合わせる意図であり、最高得点の保証ではない。実際の配置・習得・設備条件が成立する場合に限り使う。

## 3. 前回の選択を保持する

前回選択が有効なら維持し、営業のたびに選択画面を必ず操作させない。別のものを試したい時だけ本人が変更する。推薦は自動決定・強制ローテーションではない。

前回が不適合なら、短い理由を示し有効な推薦候補を提示する。本人の確認なしで元の保存配置を上書きしたり、未所有設備を購入したりしない。営業中に候補や原料箱の中身を変更しない。

## 4. 候補ゼロを通常の体験にしない

各定番へ最低一つの適合する既習系統を組み合わせられるよう、料理・設備解放・供給枠を事前に検証する。Lv5以降に候補ゼロなら自動で1系統営業へ落として同じ星基準を使う方式にはしない。

不足が発生した場合は不足設備・基本料理の習得等の理由を示すが、正常な進行で避けられない不足はコンテンツ設定上の問題として修正する。固定原料枠や共有原料の扱いは既定を維持し、全組合せが実測済みと主張しない。

## 5. 今回決めないもの

推薦の数値重み、四品の注文比率、低Lvで後半系統を使った時の収入、候補一覧の最終アート、同点順位や並び順、開始前の表示寸法。三品目を通常へ戻す案や毎日強制で献立変更する課題は追加しない。マネタイズとデイリーの保留を維持する。
