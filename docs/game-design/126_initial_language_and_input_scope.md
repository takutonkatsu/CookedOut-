# COOKED OUT! 初期の言語・入力範囲と拡張準備案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16に公開方針を採用。外部コントローラー・キーボード／マウスによるゲーム操作は非対応へ修正。翻訳・入力実装・配信設定は行わない
- 既定: 日本を主な配信想定、iPhone・iPad横持ち、仮想スティックとアクション、バイク四ボタン、設定からの反転・サイズ変更。自由文チャット・内蔵通話は将来も非採用

## 1. 初期のゲーム内言語は日本語に絞る

初期版のメニュー、ヒント、レシピ説明、エラー、問い合わせ案内は日本語で統一する案。正式タイトル・ロゴ等の固有表記は維持し、英語や他言語の完成・検証を初期公開の必須条件にしない。

初期は言語が一つなので、起動時の言語選択や設定内の形だけの言語メニューは設けない。将来の追加言語は候補として残すが、種類・公開時期を今回は決めない。日本語以外の利用者には不便なことを認識し、多言語対応済みとして案内しない。

ゲーム内言語と配信対象国は別の判断であり、この案だけで日本国外へのストア配信を禁止・許可しない。ユーザー名の許可文字も日本語だけに制限する意味ではなく、125の表示・入力検証で別途決める。

## 2. 後から翻訳できる構造にはしておく

表示文章とゲームのルール・進捗の識別を分け、料理名や説明文を差し替えても別の料理や別セーブにならない構造を要件にする案。メニュー・ボタン・説明の文字は可能な範囲で画像へ焼き込まず、絵と文章を別々に扱う。

料理画像、材料・工程アイコン、共通のボタン背景等は言語に依存しない素材として再利用する。ロゴや意図的な装飾文字まで一律禁止にはせず、言語依存素材として管理する。ノンバーバル方針は維持するが、必要な説明まで消して意味を分かりにくくしない。

将来長い翻訳が入っても収まるよう文字列の長さ・改行を検証できる構造にする。実際の翻訳、フォント、地域別の日付・数値・ストア説明・サポートは追加言語を決めてから対応する。初期から全言語対応を実装する意味ではない。

## 3. ゲーム操作はタッチに絞る

正式に対応するゲーム操作は画面タッチとし、外部ゲームパッド、キーボード／マウスによる移動・調理・運転は対応しない。外部機器向けボタン表示、キー割当、接続切替等の画面と試験は追加しない。

タブレットを置いてコントローラーで遊びたい人には不便だが、iPhone・iPadのタッチで全内容を遊べる操作感を整える。ユーザー指定により単なる初期見送りではなく非対応とし、将来実装候補には残さない。再検討はユーザーが方針を変更した場合に限る。

表示名や問い合わせの文字入力でOSの入力機能を使うことと、外部キーボードでゲームキャラを操作することは別とする。OSの補助入力を意図的に封じる方針ではない。具体のアクセシビリティ対応や機器互換性は別途検証し、未確認の動作を保証しない。

## 4. 未決・範囲外

配信国の最終リスト、最低OS・機種、追加言語、iPadのウィンドウ・外部画面対応、翻訳・入力の具体技術。言語や操作系を変更する場合もスコア・星・報酬の比較条件を確認し、既存記録を独断で変更しない。今回の文書から翻訳タスクや入力実装を自動的に開始しない。
