# COOKED OUT! シーズン4課題の出題方針 v0.2

- 作成日: 2026-09-14
- 状態: 2026-09-14、公開整理を承認。1キャラ・全課題外部配達型、本人の厨房配置・固定街、既習料理による4課題を採用。2／2／2／3系統を初期方針として進める。具体テーマ・料理・供給枠等は保留、未実装
- 既定: ソロ専用、本人設備、月次4課題、公開済みは終了まで残す、課題別自己ベストの合計。「4厨房」は4つの別会場ではなく4つの営業条件を意味するものへ整理。画面上の正式名称は別途

## 1. 通常営業で磨いた操作と判断を競う（採用）

初期シーズンは全4課題を外部配達型に統一し、通常営業と同じく1キャラを操作する。16の現地提供型との混在可能という旧記述より、この採用方針を優先する。

自前配達と配送代行を全厨房で選択できる。配送テーマでもバイク必須にしたり、代行を禁止したりしない。通常営業と共通の注文・調理・配送・設備移動のルールを使い、新しいボタンや競技専用の失敗条件を増やさない。

出張ソロの2キャラ切替は持ち込まず、2人いないと成立しない完全分断盤面を競技に使わない。通常営業の経験が配置と手順の改善へ直接つながる設計にする。

## 2. 4課題で攻略の重点を変える仕組みを採用、具体内容は保留

以下の段取り／加熱／配送／総合という4テーマと順番は未確定の旧候補。ユーザーがもう少し考えたいと指定したため、章や週の正式内容として実装・割当しない。

| 公開順 | 主なテーマ案 | 得点差を生む判断の例 |
|---|---|---|
| 第1厨房 | 段取り | 共通食材の切り置き、組立の順番、運搬距離を減らす配置 |
| 第2厨房 | 加熱の並行処理 | 待ち時間に別工程を進める、器具の使い回し、焦げる前の回収 |
| 第3厨房 | 配送の組立て | 早めに1件出すかまとめるか、加熱中に出発するか、代行との分担 |
| 第4厨房 | 総合 | 調理・加熱・配送の組合せに合わせて、自分の手順と配置を詰める |

これらは「何を考えると伸びるか」という設計上の重点であり、特殊な得点ボーナスや行動義務を追加するものではない。全厨房で従来のスコア計算を使う。

第4厨房だけを突出した難度や重みにせず、厨房別基準点で4厨房の寄与をそろえる既定を維持する。公開済みなら他厨房のクリアを要求せず選択可能。第1厨房の星や順位で第2厨房の参加を制限しない。

上位を狙う難しさは繰返しの最適化で作り、まず有効得点を出すためにLv5全種・追加台数最大を必須にしない。少なくとも既定の参加条件で成立する構成を検証する。

## 3. 既習料理を組み合わせ、系統数は2／2／2／3を初期方針にする

料理は本編で習得済みの系統を組み合わせる。ユーザーが提示し、その後の公開整理に承認した第1〜3週2系統・第4週3系統を初期方針として設計を進める。具体料理・派生は料理設計と合わせて決め、検証で成立しない組合せを固定しない。シーズン限定の必須新料理や未習得操作を追加しない。

第4週の3系統化は一皿あたりの工程を増やす指定ではなく、扱う料理の幅を増やす案。材料の共用度、供給箱数、必要設備と空き作業面、1キャラでの処理可能性を確認して組合せを決める。3系統だから注文数まで一律1.5倍にする変更は提案しない。課題別基準点による換算を維持し、第4課題だけが合計を支配する設計にしない。

## 4. 自分で配置する厨房と固定の街で競う（ユーザー指定）

シーズンは通常営業の延長であり、厨房の配置を決めるのはプレイヤー。運営が週ごとに別の盤面や作業場所・固定施設位置を出題する旧案は撤回する。街も固定とし、週ごとに新しい街や道路構成を用意しない。単に毎月別マップを既存素材で作る、という再利用方針ではない。

本店の通常の配置ルール・固定施設と可動設備の区別を使う整理を推奨する。今回の発言を、壁・水場・提供口等の既定の固定範囲をすべて自由移動可能にする許可とは解釈しない。本店12×9の基礎空間を共用する具体化と編集範囲は、必要なら次に確認する。

出題側が変えるのは主に料理の組合せと注文条件。配達先の建物を固定された街の中で課題ごとに指定する既定と、街の地形を変えることは区別する。注文列・配達先等は各課題内で固定し、再挑戦で抽選し直さない。

本人は同じ基礎空間に対して課題に合う設備配置と手順を考える。84の課題別準備配置・明示保存を維持し、今回の修正で通常営業の配置を自動上書きする共有方式へ変更しない。4つの別会場を作らず、4つの課題記録・公開日程・合計点を維持する。

- 2／2／2／3系統を初期方針にするが、具体料理・派生、材料供給枠、営業時間・注文猶予・基準点は別途
- 「週替わり営業課題」等の表示名と、本店基礎空間の共用の具体化は提案段階。実装・画像生成・毎月配信の自動化・別タスクへの指示は行っていない
