# COOKED OUT! シーズン報酬の対象と受取 v0.2

- 作成日: 2026-09-13
- 状態: ユーザー指定でシーズンはソロ専用。その前提で公開した参加外見・順位記念表現とコイン差・自動付与・期限なしを採用。具体区分・金額・外見・未公開細部は保留、未実装
- 既定: 一シーズン4厨房・個人のソロランキング。同順位は同じ報酬。人数別・チーム別のシーズン記録と報酬を設けず、本人へ一度だけ付与する

## 1. 4厨房への挑戦そのものにも報酬を用意する

本人がソロで4厨房すべてに正規完走した有効な1点以上の記録を残すと、シーズン参加報酬の対象になる。ソロ専用なので人数の混在・協力メンバー変更は存在しない。

後続80で、最終順位と順位報酬は全4厨房を要求しないと確定。1厨房以上の有効得点があれば未挑戦を0点として集計する。本節の4厨房条件は共通外見だけに適用する。

無得点放置・途中終了だけでは対象にならない。出張常設の星3掲載条件をシーズンへ追加せず、順位に関係なく4厨房で有効記録を残せば参加報酬を受け取れる。締切後完走は旧シーズン記録を作らないため、その月の4厨房達成にも算入しない。

共通のシーズン外見（プロフィール枠など、性能差のない一種類）を参加報酬にする案。初期から毎月新しいキャラクターや多数の衣装を作る約束はせず、制作負荷の小さい共通形式を検討する。名称・形・具体アセットは未確定。

## 2. 順位は記念表現とコインで報いる

順位に応じた称号・バッジの見た目とコインを差別化する案。共通外見そのものを上位限定にせず、上位は順位記録・バッジの豪華さで栄誉を示す。性能付き装備や設備Lvを報酬にしない。上位ほど次月の設備強化が過度に有利にならないよう、コイン差は通常営業経済と合わせて試算する。

順位帯の具体境界・コイン額は16の過去案を参考に後で決める。上位割合とトップ100等の重複、少人数母集団、同点境界を未解決のまま固定しない。今回新しい順位区分や固定人数受賞枠を確定しない。

後続81で50／25／10／3／1%の区分と通常営業Lv20の標準収入1〜5営業分の相対規模を採用。上位の主な動機はバッジ等の名誉とする。全員共通の固定額を開始前に表示し、最上位一区分のみ付与。共通外見の表示名は「4厨房達成報酬」。絶対額・端数処理などは引き続き保留。

以前の複数人数最高区分一回・人数別バッジという仕様は撤回する。本人のソロ最終順位で一度だけ報酬を決める。出張常設の人数別記録・チーム順位は変更しない。

共通の外見は将来再入手可能にする既定を維持する。ただし年月・実順位を示す達成記録は後から購入して当時の実績に置き換えるものではない。再入手機会・条件は別途。

## 3. 結果確定後に自動付与し、受取期限を設けない

月末21時に仮順位で配るのではなく、78の集計・検証後に確定報酬をアカウントへ自動付与する案。ログインして「受け取る」を押さなかったため失効する仕様にしない。ユーザーが数か月後に戻っても確定した所有物を保持する。

次回ログインのホームやシーズン画面で短い結果・獲得内容を見せ、営業中の操作を遮らない。表示の既読と付与処理を別にし、同じ通知を再表示しても二重付与しない。通信失敗・再送でもシーズンと報酬の単位で一度だけ付与する。具体サーバー構造は未決。

## 保留

- 最低参加人数、割合の丸め。母集団は1厨房以上の有効得点を持つ本人記録とし、未挑戦0点で最終順位を付ける
- コイン額、順位帯、外見形式、再入手条件、過去の結果画面と通知のまとめ方
- 不正・重大障害時の再集計／補償、付与失敗時の運用、送信猶予の具体時間
