## 1. 初期スコア式

```text
注文得点 = 料理基本点
         + floor(料理基本点 × 納品時注文残り率)
         + 注文順コンボ
         + 自前配達ボーナス

注文順コンボ = 連続納品2件目から +4、+8、+12、+16、最大+20
注文失効 = -10点、注文順コンボを0へ戻す
```

料理基本点の初期値:

| 料理 | 基本点 |
|---|---:|
| #1 グリーンサラダ | 20 |
| #7 野菜スープ | 40 |
| #19 ハンバーグプレート | 50 |
| #2 フルーツサラダ | 30 |
| #5 サンドイッチ | 35 |

- 残り時間チップは最大で料理基本点と同額
- 自前配達ボーナスは既決定の1人50%、2人30%、3人20%、4人15%を、料理基本点＋残り時間チップへ掛ける
- 配送代行には自前配達ボーナスを付けない
- 星ラインは10点単位に丸める
- 料理点、コンボ、ペナルティはすべてデータ設定とし、実測後に一括調整できるようにする

## 2. 人数別の注文負荷

各ステージ表の`基準注文間隔`と`基準注文タイマー`は1人用である。人数別には次の係数を掛ける。

| 人数 | 注文間隔係数 | 注文タイマー係数 | 同時注文上限の基本 |
|---:|---:|---:|---:|
| 1人 | 1.00 | 1.00 | 2 |
| 2人 | 0.65 | 0.95 | 3 |
| 3人 | 0.48 | 0.90 | 4 |
| 4人 | 0.38 | 0.85 | 5 |

- 注文間隔には最低10秒を設ける
- 初回チュートリアルで新要素を教える最初の注文は、同時注文上限へ数えない安全注文にする
- 人数増加分を注文数だけで処理せず、厨房の混雑と設備競合を見て星ラインも個別に調整する
- 星1は初見クリア、星2は一回の理解・再挑戦、星3は安定したマルチタスクを目標にする

## 6. 合格基準

内部テストでは、各人数20走以上を最低サンプルとする。

| 指標 | 目標 |
|---|---:|
| 初見プレイヤーの星1率 | 65〜85% |
| 一回再挑戦後の星1率 | 85%以上 |
| 操作理解者の星2率 | 45〜70% |
| 操作理解者の星3率 | 10〜30% |
| 1-1〜1-3初回所要時間 | 9〜11分 |
| 1-8の自前中心／代行中心理想スコア差 | ±5%以内 |
| 人数別の星1達成時間差 | 主要人数間で±15%以内 |

星1率が低い場合は、最初に注文タイマーと星1ラインを緩める。星3率が高すぎる場合は、単純に全注文を速める前に、同時注文上限と工程競合を調整する。

- ステージ、人数、採点時間、最終得点、星

- リトライ回数、離脱地点、1-3後のマルチロビー遷移率、1-8後の通常営業遷移率
