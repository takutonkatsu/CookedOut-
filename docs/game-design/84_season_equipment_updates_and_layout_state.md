# COOKED OUT! シーズン設備強化と配置更新 v0.1

- 作成日: 2026-09-14
- 状態: 2026-09-14、公開した次回開始時の強化反映・過去自己ベスト保持・設備状態の異なる記録の合算・営業中可搬操作と準備編集の区別・リトライ開始配置と明示保存を採用。具体の保存UI・未公開細部は未確定、未実装
- 既定: 通常営業の延長のソロ競技。本人の所持種類・台数・Lvで競い、シーズン中にも本店を育てられる。厨房・注文列・基準点などの出題条件は原則固定。営業前編集と営業中可搬操作は両立する

## 1. 強化した設備は次の挑戦から使える案

各営業の開始時に、その回で使う設備の種類・台数・Lvと開始配置を確定する。シーズン初日の所持状態へ一か月間固定するのではない。

通常営業で資金を稼ぎ、鍋をLv4からLv5へ強化した場合、次に開始するシーズン挑戦から鍋はLv5になる。公開済みの第1厨房へ戻って挑戦しても最新の本人Lvを使う。営業途中に外部から所持情報が更新されても、進行中の回の能力は書き換えない。

追加購入した設備は未配置一覧へ入り、既存の競技配置へ勝手に追加しない。使いたい時は準備で本人が置く。Lvだけの更新なら配置を組み直す手間は要求せず、種類に紐付く最新Lvで次回を開始する。

競技画面で新しい強化システムは作らない。本店での既存の購入・強化を利用する。

## 2. 設備を強化しても過去の得点は書き換えない案

設備更新によって過去の得点を自動増加・再換算したり、自己ベストを消したりしない。再挑戦で更新した時だけ、その厨房の自己ベストを置き換える。

各厨房の自己ベストはその記録を出した時の設備情報と開始配置とともに保持する。結果として、鍋Lv4で出した第1厨房の自己ベストと、Lv5で出した第2厨房の自己ベストが合計に混在してもよい。全4厨房を同じ設備状態で取り直す義務は設けない。

本人設備の成長は既定の競争要素であり、運営による能力係数・料理得点ルールの変更とは区別する。運営が比較条件を変更する場合は77の記録保全方針を優先する。

## 3. 準備配置と営業中の動きを分ける案

営業前に厨房ごとの競技配置を準備し、そこから挑戦を開始する。通常営業の本店配置や共有URLとは別管理を維持し、一方の変更で他方の配置を上書きしない。

営業中にまな板・卓上コンロ・ミキサー等を運ぶ操作は既定どおり可能。オーブン・フライヤー本体、作業台・原料箱等の固定範囲は通常の可搬ルールを維持する。器具ごとの例外入力やシーズン専用移動ボタンは増やさない。古い16の全面配置変更禁止はこの既定と整合させた。

一方、営業中に準備用配置編集を開いて瞬間移動させることや、倉庫から設備を追加することは認めない。移動に使うゲーム内の時間は通常どおり消費する。

リトライはその回の終了配置ではなく、選択済みの準備配置から開始する案。営業中の移動結果で準備配置を自動上書きしない。動かした配置を今後も使いたい場合は準備画面で確認して明示保存する流れを推奨する。具体の取り込み操作・保存UIは別途で、専用プリセット枠を増設する案ではない。

## トレードオフ・検証

- 月末までに強化を進めた人は後から公開済み厨房を更新できる。これは成長を持ち込む設計の利点だが、終盤に記録更新が集中する可能性は残る
- 初期設備固定の別リーグや設備Lv別ランキングは追加しない案。公平な固定設備競争は出張常設の役割
- 開始時スナップショット、強化後再挑戦、旧自己ベスト保持、追加購入後の未配置、リトライ配置、移動後の明示保存を検証する
- 保存UI・データ形式・同時操作や通信復帰時の詳細は未確定。Unity・サーバーへは未実装
