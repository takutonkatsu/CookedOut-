# COOKED OUT! 遊び方・ヘルプの入口と説明範囲案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、細かいスコア計算の非掲載という修正を加えて公開方針を採用。画面・画像・ゲームルールは未実装／未変更
- 目的: 第1章以外の必須チュートリアルを増やさず、必要な時に既定のルールを見返せるようにする。第1章の面構成・具体的ヒント配置はステージ専用タスクで扱う

## 1. 設定内に任意の「遊び方」を用意する

ホームやマルチの待機中から設定経由で閲覧できるようにする。初回に自動で全ページを開かず、営業前に毎回読ませない。閲覧完了を営業開始や解放の条件にせず、追加の必須講習・確認テストは作らない。

ソロ営業中に開く場合は既定の全体ポーズを使い、盤面は隠す。マルチ営業中の閲覧で営業は止めず、「営業は進行中」の短い表示とすぐ閉じられる操作を用意する。操作説明の閲覧と、営業前に限定する操作配置変更を混同しない。

## 2. 長いマニュアルより、項目別の図と短文

厨房操作、配達、お店の成長のように目的別で選び、ひとつのルールを図と短文で示す。既存の設備・料理・ボタン画像を使う。すべてを文字なしで伝えることは要求せず、誤解する部分には短い説明を残す。動画や専用3Dアニメーションの量産を必須にしない。コンボ倍率表・得点計算式・内部判定の詳細解説は掲載しない。

料理材料・工程はレシピ図鑑を正とし、ヘルプへ全60品の説明を複製しない。操作図は本人の現在設定に合わせるか、画面の左右に依存しないボタン記号を使い、標準位置の説明を左右反転利用者へ誤って示さない。具体レイアウト・分類名・全ページ文面は後で確定する。

## 3. 見た目だけで分からないルールを優先掲載

掲載優先候補は次の通り。新しいルールを作るのではなく、最新版の確定仕様を説明する。

- 注文順に用意するとチップが増えやすいこと、積み直しではやり直せないことを短い遊び方のヒントに留め、細かい得点判定を説明しない。配送先を回る順は自由という操作上のルールは伝える
- 注文期限と発送後の配送期限の違い。発送しただけでは配達成功の得点が入らず、配送失敗時の扱いもあること
- 短押しと長押しによる器具単体／設備一式の持ち運びの違い
- コインと評判の違い、評判が条件待ちで上限停止する理由

前案の④→③→④等を追う詳細なコンボ図解は採用しない。数式や倍率を理解しなくても遊べる説明にする。既定の料理基本点の注文票・図鑑表示や、スコアそのものの表示は撤回しない。ゲーム内部のコンボ計算・判定時点も変更せず、表示・説明の範囲だけを修正する。

## 4. プレイを止める説明を増やさない

ミスのたびにヘルプを自動表示したり、再挑戦前に説明を強制したりしない。第1章の既定の短いゲーム内ヒントは残すが、別の必修学習フローにはしない。

共通操作の説明に、未プレイ面の盤面・ギミック配置・攻略手順は載せない。出張営業の開始前に厨房を見せない方針を維持する。未習得料理や隠しステージの紹介も図鑑・解放表示の既定範囲を越えない。

## 5. 未決・範囲外

全ページ構成、具体の文面・図版、ヒントの長さ・頻度、視認性検証、検索機能の要否。配達専用練習や追加チュートリアル、既存コンボの再設計、ステージ配置変更をこの提案だけで追加しない。
