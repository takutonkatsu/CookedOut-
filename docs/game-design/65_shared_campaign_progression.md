- 前提: 最初からマルチ、第1章の学習・本店解放はソロ／協力共通、人数別の記録は分離する。第1章の各面構成は今回は扱わない

## 1. 遊べる場所は共通、記録は人数別

第2章以降も、一度正規に解放したステージはソロと協力の両方で選べる案。ソロで2-3を進めた後に友達と2-4へ行く、協力で3-2まで進めた後に一人で3-3へ行くことを認める。

保存は人数別の星・自己ベスト・実績トラックを維持し、未挑戦の人数へ記録をコピーしない。共通進行による選択可能なステージが、ソロ記録では未挑戦と表示されることを許す。入口の進行と腕前の記録を別にする。

## 2. 章進行星は一面あたり最高3まで

第2章以降の章最終に必要な章進行星8は維持し、その集計だけを各面の全人数中の最高星へ変更する案。対象面の最高星を合計し、同じ面のソロ星と協力星を足して水増ししない。

例: 同じ面でソロ星1、2人星3、3人未挑戦、4人星2なら、章進行への寄与は3。モード別画面の記録は1／3／未挑戦／2のまま。全人数の星収集実績は従来どおり別に集計してよい。

単に一本道の途中へ飛び込んだだけで前提面を省略しない。ホスト解放済み面への先行参加・正規クリア記録と報酬の即時保存は認め、本人の前提達成後に選択解放へ反映する。既存の先行クリア再評価・二重報酬防止を維持する。

## 3. 持ち帰る料理と設備解放も共通

学習に対応する正規クリアをソロ／協力のどちらで達成しても、料理・設備種類の解放を本人へ反映する案。協力で学んだ料理を本店で使うためだけに、同じ面のソロクリアを要求しない。既定どおり出張を学習源とし、未解放レシピを本店注文へ勝手に出さない。

種類解放と初回設備付与はアカウント単位で一度だけ。別人数で再クリアしても無料設備を増殖させない。営業ごとの通常コイン報酬や人数別記録は別に受け取れる。種類別Lvや購入台数を他プレイヤーからコピーしない。

先行参加での種類・レシピ解放は、その面の正規クリアに対する固有解放として即時反映する案。本人の店ランク・営業Lvは上がらず、献立のLv・供給枠・設備条件も既定どおりチェックする。前提達成後に同じ初回設備を再付与しない。

## 4. 店ランクの指定出張条件は残し、ソロ限定だけ外す

既存の「指定ソロ出張ステージをクリア」を「指定出張ステージをソロまたは協力で正規クリア」へ変更する案。指定面、必要評判、全設備Lv条件、評判ゲージ上限、通常営業の個人進行は維持する。

例: 2-6を協力でクリア済みなら、本店昇格の2-6条件を満たせる。ただし本人の必要評判・設備条件が未達なら昇格しない。友達に手伝ってもらうことは許すが、他人の評判・強化済み設備を自店へ持ち帰ることはできない。

シーズン参加も本人の店ランク20＋通常営業Lv20星1＋最終大型出張星1を維持し、最後の出張クリアだけソロ／協力どちらでも認める案。既定で初期新規マルチ参加を認めることと、シーズン参加資格を免除することは別。ソロの実力はソロ記録・通常営業の本人進行で評価し、共通解放をソロクリア実績と表示しない。

## 5. 利点と代償

友達と遊んだ後に同じ章を一人で最初からやり直す強制を減らし、出張で学んだことが店へ戻る意味を揃えられる。一方、協力が得意なチームによって個人では未達の面を解放できる。これを不正ではなく協力の利点として認める方針の提案であり、個人の無操作検知・強制操作試験は新設しない。切断者のクリア資格は既定を維持する。

全員一人で遊ぶ場合も同じ進行を完了でき、マルチ必須料理・必須報酬を作らない。出張星は進行と腕前、通常営業は店の成長と資金という役割分担を保つ。
