# COOKED OUT! 外見の入手方法とショップ範囲案 v0.1

- 作成日: 2026-09-15
- 状態: 2026-09-15、ユーザーは全体案を肯定したうえでマネタイズ方法を後日決定と指定。全動物共通の帽子＋衣装セット、性能差なし、試着、手動装備、所持済み表示は採用。動物・衣装の具体入手経路、有料商品の構成、有償通貨・ガチャ・直接販売の扱い、価格等はマネタイズ相談時まで保留し、本書の販売案を最終決定や実装指示にしない。既存の無料配信等の基本方向を自動撤回する意味ではない
- 既定: 動物キャラのみ、外見に能力・当たり判定差なし、共通帽子・衣装の基本形。外見課金と広告削除を採用、通常コイン販売と初期ステージ課金は不採用。初回有料購入前のアカウント連携は103で採用

## 1. 動物キャラと着せ替えの入手を分ける案

初期名簿の動物キャラクターはすべて無料プレイで入手可能にすることを推奨する。最初から選べる動物を複数用意し、残りは進行または通常コインで解放する。どの動物を初期配布にするか、全体の解放順と価格は別途相談する。未所有キャラの使用可否を変えたり、初期全キャラを自動配布したりする決定ではない。

購入対象の中心は衣装とする。無料の着せ替えも用意し、有料衣装だけが個性の出し方にならないようにする。現時点で新しい有料限定動物種やキャラ別能力は導入しない案。

## 2. 初期の衣装は全動物共通のセット

一商品はコック帽＋衣装の組合せをまとめた衣装セットとすることを推奨する。一度入手すれば、本人が使えるすべての動物に装着可能とし、動物ごとの買い直しを不要にする。初期は帽子・上着・靴等を別々に買い集めて組み合わせる機能を設けない。

既定の共通形状を基本に、色・柄・小さな装飾で変化を作る。大きな帽子や発光で食材・目印・隣のキャラを隠さず、外見を変えても手持ち位置・判定・能力は変えない。耳・角・尻尾との干渉は各モデルで検証が必要であり、共通商品にしただけで全モデル対応が自動完了するとは扱わない。

厨房・バイクの見た目変更、特殊モーション、プロフィール枠は初期商品範囲に含めず、必要なら後日追加を検討する。

## 3. 三つの入手経路を分かりやすくする

- 通常コイン：無料プレイで集められる基本キャラ・衣装
- 有料購入：内容が事前に分かる衣装セット
- 達成報酬：出張やシーズン等の既定条件で得る記念品

同じ商品を毎回どの方法で買うか選ばせる意味ではなく、商品ごとに入手方法を明示する。ゲーム内コインで買えるものと実通貨の商品は区分を分け、購入時に混同しないようにする。

実際の成績を示す順位・制覇バッジは購入対象にしない。シーズン共通外見の将来再入手機会は既定の検討余地を残し、すべての報酬外見を永久限定と新たに決めるものではない。

## 4. 初期版では有償通貨・ガチャを作らない案

有料衣装は表示価格で直接購入する。先に有償通貨を買って衣装へ交換する段階を設けず、通常コインとは分ける。内容不明のガチャ、重複キャラ合成、有料衣装による性能強化、時間制レンタルは初期範囲に含めない。

価格・販売点数・限定販売・セット割引は未決定。直接販売だけで必要な収益が成立するとは保証せず、制作負担と購入状況を検証する。ストア価格や規約、税・返金の仕様をここで断定しない。

## 5. 購入前に試着、入手後に本人が装備する

商品を選ぶと、現在選択中の動物に着せた見た目を確認できる。商品内容・価格・入手方法を同じ画面で明示する。試着は表示だけで、未購入の衣装を営業へ持ち込めるようにはしない。

入手しただけで現在の衣装を自動変更しない。「着る」を選んだ場合だけ装備する。装備中／所持済みを明示し、同じ非消費衣装を二重に買わせない。購入の保留・失敗・復元・返金は後続の購入フローで設計する。

## 6. 本件の判断点

公開した外見・装備体験は採用し、収益化に関わる入手経路・販売制度は後日相談へ分離した。第1・3・4節の具体販売案は参考として残す。商品アートや新しいキャラ名を勝手に確定しない。
