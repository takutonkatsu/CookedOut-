# COOKED OUT! 追加章の進行とSステージ拡張 v0.1

- 作成日: 2026-09-14
- 状態: 2026-09-14、公開した追加章6面・直前本編からの一本道・章最終前5面8星・対応S1面と18星解放・習得と高難度の役割分担を採用。ユーザー追加指定で本編1章追加につき店ランクと通常営業Lv上限も各2段階拡張する。昇格具体化は90の提案、未実装
- 前提: 本編第9章以降を追加可能。S枠は本編と独立。シーズン参加には必要進行・料理習得を含む最新本編章クリアを要求し、追加する月は月末21時の新シーズン開始に合わせて正式公開する

## 1. 追加章も6面・一本道を基本にする案

第9章は9-1〜9-6、第10章は10-1〜10-6のように、既存章と同じ6面構成を基本とする。毎月必ず追加する約束ではなく、章追加時の標準単位。

第9章の入口は通常の進行上で第8章クリア済み、第10章は第9章クリア済みとする。追加章の入口に店ランク20・設備Lv5・過去の全星・Sクリアを要求しない。これにより通常営業の成長待ちでも、出張は順に楽しめる。

各面星1で次へ進み、章最終は直前面星1と章前半5面の進行星8を必要とする既存方式を追加章にも適用する案。章進行星は既定どおり各面の1〜4人記録の最高値を使い、人数分を足さない。全星18はS解放用であり通常の章クリアには要求しない。

未解放の追加面へ招待参加できる既定は維持。本人の前提が未達なら選択解放は待つが、先行クリアした正当な記録・報酬を保持し、前提達成後の再クリアは要求しない。シーズンの必要進行・料理判定とは別に管理する。

## 2. 追加章に対応するSステージを1面用意する案

第9章にはS-9、第10章にはS-10を対応させる。対応章の6面全て星3＝18星で本人が選択できる、独立解放の方式を維持する。S-9を遊ぶためにS-1〜S-8制覇を要求せず、Sのクリア自体をシーズン参加条件にしない。

追加本編6面と対応S1面を一つの制作単位として推奨する。既存Sの表示条件や招待例外を崩さず、公開前のS面を入口として出さない。新章本編で必要な料理・操作を習得でき、Sはその応用を楽しむ任意の挑戦とする。

初期S-1〜S-8の制覇バッジは初期8面だけを対象にし、S-9以降を追加しても既得バッジを未達へ戻さない方針を推奨する。追加分の達成報酬は別の対象集合として設計できるが、今回面ごとの新バッジを自動追加する約束はしない。

## 3. 追加章は新要素の習得、Sは応用という役割を守る案

追加章を以前の最難関より常に難しくし続ける必要はない。序盤で新料理・新しい組合せを試し、後半で従来要素と組み合わせる。毎章の具体導入位置・料理数・盤面はまだ決めない。

本編章の通常クリアは「シーズンに必要な料理を扱えるようになる」通過点であり、ランキング上位者だけが突破できる難関にはしない。難度の高い目標は星3・自己ベスト・常設ランキング・対応S面に残す。

出張は本人の設備を持ち込まないLv3固定、料理数だけで専用操作を増やさない、星基準25／40／60%という既定を維持する。新章を理由に自動的なLv4・Lv5化や設備購入条件を付けない。

## 保留・検証

- 6面＋S1面・入口・章最終8星条件は採用済み。各2段階の通常営業拡張の詳細は90を参照
- 具体料理・新要素・各面の配置・星基準の基準スコア。既存の料理設計・ステージ設計で後日決める
- 新章公開月の攻略負荷とシーズン参加までの所要時間。全S・全星を要求しない前提で検証する
- 追加Sのバッジ等の報酬単位、未公開章の見せ方・運用例外
- 恒久ID・章一覧等を拡張可能なデータとして扱い、面数を実装へ埋め込まない。具体面を制作・実装したものではない
