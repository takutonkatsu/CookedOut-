## 1. 引継ぎ確認

ユーザーは料理専用タスクで出張第1〜8章の料理構成が決定したと報告。最新台帳は本編48面、中核20系統×3品＝60品、原料全17種類、各面の必要原料種類最大4。S・通常営業は集計対象外で、本編4種類の努力目標を通常営業・Sへ拡張しない。同原料の複数箱配置まで確定した数字ではない。

台帳は第2〜8章承認済み、第1章の元資料に比較案表記が残ることを明記している。今回のユーザー報告を受け本タスクでは掲載された第1章も最新の計画基準に用いるが、料理専用原文の承認ラベルを書き換えたり、別の未掲載比較案まで承認扱いにしたりしない。

旧全体仕様の36系統目標・一系統3〜5派生・1-2鍋／1-5フライパン導入は最新献立と不一致。最新台帳と区別する。8-3〜8-4のピザ採用は料理としての採用であり、店全体をピザ専門店へ戻す変更ではない。

## 2. 推奨順序

1. 全48面の役割を粗く決める：何を学ぶか、主な難しさ、面白さ、新規要素と復習の配分、現地提供か外部配達か。最初は細かな配置や数値を入れない
2. 第1章の操作導入表を確定する：最新献立に合わせ、基本操作・加熱・投げ・ダッシュ・設備移動・二キャラ切替・配達等をいつどの範囲で教えるか照合。1-6後に通常営業へ入れる既定と整合させる
3. 章ごとの景観とギミック割当を決める：料理以外に同時に初見になる要素を絞り、面ごとに主な難しさを一つにする。プレイヤーの設備移動による工夫を残す
4. 第1章を1-1から一面ずつ盤面設計する：グリッド寸法、通路、作業台、固定供給・提供、水場、編集不可範囲と可搬機器、初期台数、二キャラ開始位置、配送動線。ソロ二キャラと2〜4人の成立を確認する
5. 小規模試作で工程時間・注文供給・配送時間・基本点・星基準の基準点を調整する：4分と星割合の既定は維持し、実測なしに全48面の具体スコアを完成値としない
6. 通常営業Lv1〜20の定番割当・料理解放・昇格条件・必要設備を照合する：後回しにしすぎず、最初の役割表時点で進行不能だけは先にチェックする。実測を受けて評判量・設備費・おすすめ適合を調整する
7. 第2〜8章の詳細盤面、対応S面、シーズン出題へ展開する：前段で確認した動線・調理負荷を再利用し、48面の完成アートと数値を先に固定して手戻りを増やさない

全体の骨格確認と第1章の細部設計を分け、全48面の完成を待たずに第1章と通常営業の試作へ進める。今回の順序提案は別タスクへの実装開始指示ではない。

## 3. 最初の役割表の列

| 列 | 決める内容 |
|---|---|
| 面・既定献立 | 台帳の料理を参照し、別料理を勝手に追加しない |
| 学習・復習 | 新操作・新しい段取りと、既習の何を使うか |
| 主な難しさ | 加熱の見張り、受け渡し、設備競合、巡回等から主役を一つ |
| 面白さ・工夫 | 移設・分担・仕込み・投げ・配送選択で改善できること |
| 提供方式 | 現地提供か外部配達か。外部は自配達／代行の既定を維持 |
| 失敗と立て直し | 初心者が失敗しても再び作業に戻れる仕組み |

厨房の構造上の分断と、景観だけが動く演出を区別する。料理の多さだけで難しさを増やさない。

## 4. 第1章で先に整合を取る理由

台帳の第1章は1-1グリーンサラダ、1-2サラダ派生、1-3オムレツ、1-4焼きそば、1-5スープ＋サラダ、1-6焼きそば＋スープ。旧案の1-2鍋導入はこの献立では成立せず、加熱はフライパンが先、鍋が後になる。具体操作の面割当は次の相談で決める。

さらに通常営業開始前に、自配達と代行、パックの扱いをどこで経験させるかが必要。料理の初出に加えて毎面多数の新操作を詰めず、既習料理を扱う面も操作の習得に活用する。第1章以外の別必修チュートリアルや最初からマルチに入れる条件は無断変更しない。

## 5. 復習と育成側への接続

台帳によれば60品中35品は本編で一面だけ登場し、新料理のない面は3-6・5-6。これは注文候補への登場面数で、実プレイ回数ではない。全料理が一度きりの体験になると断言せず、通常営業・再挑戦・S・シーズンに復習機会を設ける方針を検討する。確定献立を増やしたり8-6を別献立へ差し替えたりせず、まず盤面・進行の役割で支える。

料理解放は系統だけでなく個別派生の初出も考慮し、未習得派生を通常注文に混ぜない。初期4系統と営業Lv1〜4、その後2-6等の昇格ゲートが次の定番解放に足りるかを点検する。全設備の台数・価格・工程時間の確定は別工程とする。
