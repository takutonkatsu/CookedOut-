## 1. ミキサー本体とジャー

> この節の「一緒に持ち運ばない」案は、採用された[60の一式運搬仕様](60_carry_equipment_with_vessels.md)で撤回する。59の他節は引き続き未承認。

ジャーが載っていれば通常の「取る」でジャーを持つ。ジャーを別台へ置き、空の本体を短い長押しで持ち、新しい空き作業台へ設置し、ジャーを戻す。鍋とコンロの移動文法に合わせる。ジャーと本体を一緒に持ち運ぶ新操作は設けない案。

移動に電源コード、コンセント配置、配線編集を要求しない。有効作業台へ置けば使用できる。可搬化によって混合時間や材料を初期化したり、完成物・ジャーを複製したりしない。混合途中にジャーを外せるか等の加工状態ルールは料理設計側へ委ね、本体を動かせることを加工の自動継続と解釈しない。

## 2. オーブンとフライヤー

> 後続資料70を優先。料理側C-D089〜094でフライヤーかごは着脱式へ変更済みのため、以下の固定かご記述は撤回する。70への承認で営業中本体固定／準備中配置変更、各1マス試作、形による区別を採用した。本書冒頭の本体固定未承認という旧状態はこの後続承認で解消。具体的な既定18枠等まで今回確定した扱いにはしない。

オーブンは作業台内蔵の既定形状に合わせ、営業中は本体を動かせない案。上部トレーは料理側で決定したとおり持ち運べる。フライヤーも固定かごを備える本体は営業中固定とする案。油を持ち運ぶ・こぼす・補充する新システムは設けない。

通常営業の準備画面では対応する設備設置枠の中で両者の配置を変更できる。出張は作者指定の初期位置を使う。すべての設備を動かせるわけではなく、固定大型設備へ材料を運ぶ動線をステージ設計に残す。

標準占有は各1セルを第一試作案とする。オーブンの天面は専用トレードックであり、まな板やミキサーを重ねる汎用面にはしない。フライヤー上にも他設備を重ねない。動かせる本体は独立した脚・底面、固定機器はカウンターへの組込み等の形で区別し、常時文字ラベルを加えない。12×9、既定18汎用枠と最大2系統の献立が成立するかはレシピ構成後に検証する。

## 3. 購入とレベル

新3設備も種類別Lv1〜5、出張Lv3固定へ揃える案。既定6種類と合わせ、本店の強化対象は計9種類になる。ジャー・トレー・固定かごを独立購入・独立Lvにはしない。一台一食の料理側方針を強化で複数食へ変更しない。

最初に学ぶ出張ステージで種類解放とLv1一台を付与し、追加台数と強化にはコインを使う既定文法を適用する。ソロ・協力のどちらで習得してもよいという65の決定を適用し、種類初回付与は一度だけ。本店にはその献立で必要な設備だけ配置し、9種類すべてを同時設置する条件にしない。

### 3.1 強化対象9種類と効果の案

対象は、まな板・鍋・フライパン・ミキサー・オーブン・フライヤー・配送代行棚・バイク・消火器の計9種類。作業台、卓上ゴミ箱、容器スタンド、ジャー、トレー、コンロ自体へ新しいLvを設けない。皿洗い場は従来どおり本店の強化・昇格対象外。

新3種類の強化効果は加工時間の短縮を中心にする第一案。ミキサーなら混合、オーブンなら焼成、フライヤーなら揚げ時間を短縮する。Lv3を出張の基準とし、Lv1・2を遅く、Lv4・5を速くする既存の基準設計を適用する。係数・秒数は未確定。

一回一食、材料構成、操作ボタン、器具容量をLvで変えない。完成後の焦げ猶予を加工短縮に連動させて短くせず、強化したのに取り出しの操作猶予が狭まる副作用を避ける。完成が早い分、投入から焦げまでの総時間も変わり得るため、焦げ警告・配達中の不在との組合せは試験する。Lv強化で自動盛付け・自動取出しを追加しない。

### 3.2 台数追加の案

ミキサー・オーブン・フライヤーも本店の所有上限は各4台を第一試験案とする。解放直後から4台を無料付与せず、最初の1台は無料、追加分はコイン購入。種類Lvを上げると所有する同種全台へ適用され、後で買った台も現在の種類Lvを使う。

4台所有は4台同時配置の義務でも保証でもない。選んだ献立、必要設備、12×9の設置枠と料理の仮置き場に合わせ、配置する台数を選ぶ。星3に常に最大台数が必要な前提を置かない。出張の台数は作者指定であり、本店の上限を持ち込まない。

ジャー・トレーの単品追加販売なし、一台に付属品一個、別本体と共用しても増殖しない点は61で採用済み。追加3種類の上限4台はユーザー承認済みの初期試験方針とし、厨房容量・価格・献立が揃った段階で検証する。

## 4. 昇格条件への追加

6→7で対象設備全Lv2、12→13で全Lv3、16→17で全Lv4という節目は維持する案。ただし新設備を早期から未解放のまま必須にしない。

各節目の必須出張までに習得させる設備を、開発側の解放表で固定して、その節目の対象へ含める。先行クリアした個人だけ対象種類が増える方式にしない。新設備を導入した直後に高Lv強化を強制せず、学習・通常営業で使用・貯金の区間を挟んで次の節目へ組み込む。

16→17では3新設備も含めた9種類すべてLv4を要求する方向を推奨する。そのために3設備の解放を十分早く配置できるかを解放表で確認する。Lv5は従来どおり任意。設備の種類解放と強化上限Lvの解放を区別する。

必要評判やゲート位置を動かすことは今回提案しない。対象増によるコイン不足・反復回数増を試算し、既存6種類での価格予測を9種類へ無条件流用しない。具体的な各設備の導入章は料理設計がまとまってから確定する。

台数最大化は昇格条件にしない。「対象種類すべてLv4」は各種類の種類Lv条件であり、各4台を購入する条件ではない。Lv5は高額な任意のやり込みとして維持するが、3種類追加による全種強化の総営業数を試算してから具体価格を決める。旧6種類向け価格をそのまま各新種類へコピーし、進行負担を自動で1.5倍にする決定はしない。各面構成はユーザー指定の保留を維持する。
