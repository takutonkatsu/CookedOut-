# COOKED OUT! 公開上限到達時の評判と拡張後の昇格 v0.1

- 作成日: 2026-09-14
- 状態: 2026-09-14、公開した上限時MAX・未公開評判先取りなし・上限拡張後の新ゲージ0開始・育成途中の既存評判保持・追加昇格ゲート・新最高Lv星1からの競技参加を採用。更新またぎ等の未公開細部は保留、未実装
- 既定: 本編1章ごとに店ランクと営業Lvを各2段階増やす。シーズン参加条件も最新上限と最高営業Lv星1に連動。星別評判80／140／220、現在ランクに対応する最高営業Lvからだけ評判を得る

## 1. 公開上限に到達したら評判はMAX表示にする案

初期の店ランク20など、その時点の公開上限に到達すると、次のランクに向けた評判の蓄積は停止する。ホームの店ランク脇は評判ゲージの代わりにMAX表示とする案。

未公開の21・22へ向けて評判を貯めたり、後日の追加時に過去の営業を新しい評判へ換算したりしない。通常営業のコイン、Lv別最高星、設備強化などは引き続き進められる。既存記録を消す処理ではない。

章・設備待ちで公開済みの次ランクがある場合は、既定の「必要量／必要量」で停止する表示を維持する。公開上限のMAXと、条件待ちの満タンゲージを区別する。

## 2. 追加後は次の1ランク分の評判を新たに貯める案

第9章と上限22が公開されたら、上限20だった人には20→21のゲージを0から用意する。ランク20・設備・コイン・星は維持する。上限より下の人は現在の昇格用評判をそのまま保持し、更新で全員の評判をゼロにはしない。

90の出張ゲート案を具体化する。

| 昇格 | 条件案 |
|---|---|
| 20→21 | 第9章クリア＋営業Lv20で必要評判 |
| 21→22 | 営業Lv21で必要評判 |
| 22→23 | 第10章クリア＋営業Lv22で必要評判 |
| 23→24 | 営業Lv23で必要評判 |

新章を先に遊んでも、通常営業から始めてもよい。新章未クリアでも現在の必要評判までは貯められるが、そこで停止して次段階へ持ち越さない。既に新章を正規にクリアしていれば記録を照合し、同じ面の再クリアは求めない。

一営業で昇格しても、余剰評判で次まで飛び越さない。新しい営業Lvを遊んで次の評判を得る既定を維持する。必要量の具体数値・所要営業回数・追加設備ゲートは今回決めない。

## 3. 新最高Lvの星1を取ったらシーズンへ進める

第9章公開時なら、店ランク22へ到達した後に営業Lv22を星1以上でクリアし、必要進行・料理習得も満たせばシーズン参加できる。Lv22では未公開のランク23用評判を要求せず、MAXのまま最高星とコインを獲得する。

第10章公開時も同じ流れで24・Lv24星1へ進む。Sのクリアや設備全Lv5を追加要求しない。公開済みシーズン課題は終了まで残り、育成後にまとめて挑める既定を使う。

参加条件はホーム／シーズン入口で確認できるようにし、毎回の通常営業結果画面へ昇格条件一覧を追加しない。3条件の具体表示は別途。
