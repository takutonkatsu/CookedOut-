# COOKED OUT! 配達先での停車・納品操作 v0.2

- 作成日: 2026-09-13
- 状態: 停車による自動納品、ボタン・降車・精密駐車不要、対応荷物のみ納品、自由な巡回順、全件後自動帰還を採用。ユーザー指定でキャラクターがパックを手に取り玄関へフリスビーのように投げる演出に変更。演出と論理判定の分離も後続72で採用、未実装

## 1. 道路沿いでほぼ停止すると自動納品

届け先の道路沿いに配達エリアを設け、対応する発送済み料理が荷台にあり、そのエリア内でバイクがほぼ停止すると自動納品する。納品ボタン、精密な駐車方向、降車して玄関へ歩く工程、料理選択、確認ダイアログは追加しない。

走り抜けるだけでは納品しないが、速度が数学的に完全な0になることは要求しない。短い停止確認の長さ・速度閾値・エリア寸法は実機で調整する。自動操舵・自動駐車は追加しない。近づき、ブレーキを使って止まり、次へ向かう手触りを中心にする。

## 2. 場所と完了を絵・動き・音で伝える

対象建物の配達エリアに路面の枠や配達口の絵を使い、停まる場所を把握できるようにする。常設文字看板、会話、受取人操作は不要。納品時はキャラクターがパックを手に取り、フリスビーのように玄関の受取位置へ投げる短い演出と音を出す。配送表示の残件数更新も行う。自動納品のコミカルな見せ方であり、手動の照準・投擲ボタンを追加する意図ではない。新たな長い納品ゲージや待機演出は加えない。

これは落下パックへ番号・浮遊マーカーを付ける変更ではない。配達エリアは建物の受取地点の表現。交通や背景で停車が極端に困難にならないことは試験する。

## 3. 対応する荷物だけを渡す

同じ届け先の同時注文を重複させない既定方針を維持し、一地点一件の納品とする。別の家に止まっても誤配送・誤配減点は起こさない。落下中・手持ち回収中で荷台にない料理は納品不可。拾って元の荷台へ戻す既定を守り、家の前へ散乱しただけで納品しない。

案内中でない届け先でも、有効な荷物を積んで停車すれば納品できる。巡回順は自由で、初回積載・代行受理時の準備順コンボを到着順で再判定しない。実際の納品時に既定の得点・コイン対象処理を行い、未達の依存注文に関するコンボ上乗せ保留は維持する。

## 4. 最後の納品後は既定の自動帰還

残りがあれば停車後すぐ次の届け先へ向かえる。最後の一件が納品済みになったら既定の短い切替で発送拠点へ帰還し、改めて帰還ボタンを押させない。配送期限切れ・閉店は51・52の既定を維持する。

## 実装前の保留

- 停止成立・期限切れ・閉店が同時刻の場合の判定順と通信時刻検証
- 停車確認中の被衝突、切断待機・非操作キャラ状態での成立条件
- 納品イベントの二重処理防止、荷台表示と報酬表示の同期
- 街形状、具体建物、ルート案内先の自動選択、ミニマップ回転方式はこの相談で確定しない
