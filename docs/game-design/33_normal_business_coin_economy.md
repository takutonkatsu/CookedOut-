# COOKED OUT! 納品料理の基本点連動コイン・設備強化価格案 v0.6

- 作成日: 2026-09-13
- 状態: 納品料理基本点合計による報酬、通常1.0・出張／シーズン各プレイ0.1の初期係数、最後に切り捨て、正規終了時付与、任意リタイア報酬なし、反復減衰なしを採用。設備価格と収支は調整前
- 前提: 通常営業4分、評判は今回の星1／2／3で80／140／220。設備条件は6→7で全Lv2、12→13で全Lv3、16→17で全Lv4。Lv5はランク17で購入解放する任意強化

## 1. 営業コインの基本式

営業コインは、その営業で実際に提供・配達が完了した料理の基本点を合計し、係数を掛けて計算する。旧星倍率案、最終スコア比例案は撤回する。

```text
納品基本点合計 = 営業終了までに注文を完了した各料理の基本点の合計
通常営業コイン = floor(納品基本点合計 × 1.0)
出張営業コイン = floor(納品基本点合計 × 0.1)
シーズン競技の各プレイのコイン = floor(納品基本点合計 × 0.1)
```

各料理には工程等を基に決めた10点単位の基本点がある。その料理基本点を使い、材料一個ごとの点数や料理種類数では計算しない。同じ料理を3件納品すれば基本点を3件分加える。

- 時間チップ、注文順倍率、自前配達チップ、失注減点、星、ランキング換算はコイン算出に含めない
- 同じ料理を同じ件数だけ納品すれば、順番やチップにより最終スコアが異なっても同じ営業コインになる
- 得点や星が0でも、成立した納品があればその基本点を集計する。旧「最終スコア0なら必ず0コイン」案は撤回する
- 納品が0件なら納品基本点合計は0となる
- 評判は星1／2／3＝80／140／220のまま。評判満タンでも営業コインは得られる
- 本節は通常営業・ソロ出張・マルチ出張・シーズン競技各プレイの営業報酬を扱う。練習厨房は報酬なし

## 1.1 集計対象とタイミング

既存の注文完了ルールに合わせ、集計対象は納品済み料理と解釈する。

| 状態 | 納品基本点へ含めるか |
|---|---|
| 現地提供口で注文を完了した料理 | 含める |
| 自前配達で期限内発送し、閉店までに届けた料理 | 含める |
| 配送代行で期限内発送し、閉店までに届いた料理 | 含める |
| 調理完了したが厨房や積込場所に残っている料理 | 含めない |
| 発送済みだが閉店時に配送中の料理 | 含めない |
| 一致注文がなく発送できない料理、廃棄した料理 | 含めない |

同じ注文の完了を二度数えない。自前・代行の発送確定時には基本点を確保せず、実際の到着時に納品実績を加える。失注時に過去の納品基本点を差し引かない。既存所持コインも減らさない。

## 1.2 出張営業の低報酬化

通常営業を本店のコイン稼ぎ・設備成長の主な場とし、出張営業はステージ攻略、料理解放、店ランク上限解除、星・ランキングを主目的とする。ソロ出張も低報酬の対象であり、ソロだから通常営業と同額にはしない。

まずソロ・マルチ出張とも係数を通常の10分の1とする。これは同じ納品基本点合計に対して10分の1という意味であり、一営業または一分あたりの収入が厳密に10分の1になる保証ではない。実際には注文数、料理基本点、人数、規定時間が異なるため、一人あたりの収入/分も確認する。

マルチはチームの納品基本点合計から計算した出張コインを各参加者へ同額付与し、山分けしない既存方針を維持する。人数別の追加係数は現時点では導入せず、4人時でも通常営業より大幅に低収入になるか試算後に検討する。

採用した初期係数での計算例:

| 営業 | 納品基本点合計 | 係数 | コイン |
|---|---:|---:|---:|
| 通常営業 | 1,000 | 1.0 | 1,000 |
| ソロ出張 | 1,000 | 0.1 | 100 |
| マルチ出張 | チーム合計1,000 | 0.1 | 各100 |
| シーズン競技（ソロ専用） | 本人の合計1,000 | 0.1 | 本人100 |

## 1.3 付与と画面表示

- 整数化は料理ごとでなく、営業全体の基本点合計へ係数を掛けた後に一度だけ小数点以下切り捨てとする
- 営業コインは正規終了時に一度付与する。任意の途中リタイアでは付与しない。切断・障害の救済は既存規則を優先する
- 同条件の反復は納品内容が同じなら同額とし、回数減衰・日次上限は設けない
- 結果画面は「スコア」「星・評判」「納品報酬のコイン」をそれぞれ示す。スコアがそのままコインへ変換される演出にはしない
- 詳細表示では料理別納品件数・基本点合計・換算後コインを確認できる案

初回・固有報酬、日次・週次課題、ログイン、任意広告等は別枠。今回の出張0.1倍をそれらへ自動適用しない。ただし、出張に紐付く追加報酬だけで通常営業並みの反復収入にならないかは、別枠も含めて検証する。

シーズン競技の各プレイにも納品料理基本点合計×0.1のコインを付与する。シーズン終了順位報酬は別制度とする。

## 1.4 配達・得点との関係

自前配達と代行は同じ納品料理なら同額のコインになる。自前配達チップはランキング・星・評判に関わる得点上の利点として残す。

コイン/分を伸ばすには納品できる料理基本点合計を増やす必要がある。代行を使って厨房の処理量を上げる判断、バイクの複数積載で不在時間を減らす判断、工程が複雑で基本点の高い料理を扱う判断が収入へ影響する。代行の方が稼ぎやすくなる可能性もあり、実測前に自前配達がコイン効率でも有利とは約束しない。

## 2. 設備種類ごとの旧価格候補

| 強化 | 一種類 | 全6種類 | 購入解放 | 必須昇格 |
|---|---:|---:|---|---|
| Lv1→2 | 450 | 2,700 | 店ランク2 | 6→7 |
| Lv2→3 | 900 | 5,400 | 店ランク7 | 12→13 |
| Lv3→4 | 1,500 | 9,000 | 店ランク13 | 16→17 |
| Lv4→5 | 5,000 | 30,000 | 店ランク17 | なし |

これらは旧星報酬式を基にした未確定候補。新しい納品基本点集計と換算係数で購入所要時間を再計算する。一度の購入で同種類の全所有個体へLvを適用する。

Lv5は終盤の標準的な納品内容で一種類10〜12営業分を中心目安とする（試験範囲8〜12回）。星や最終スコアに応じた定額報酬を意味しない。既に持っているコインは使え、購入解放後に所定の営業回数を要求するものではない。

## 3. 再試算に必要な値

- 各営業Lvの料理基本点、注文構成、提供・配達完了件数
- 通常係数1.0、出張・シーズン各プレイ係数0.1という採用初期値での収入
- 失注、厨房内残品、閉店時未到着が納品数へ与える影響
- 人数別の出張納品基本点/分と、一人あたり収入
- 出張の報酬を減らした後の序盤強化費の充足と、日次・広告等の別枠収入
- Lv5解放時の貯金、店ランク17〜20中の収入、追加台数・外見支出

旧「星2のみなら店ランク20で余剰19,880コイン、Lv5を3種類購入可能」等の予測は適用しない。最終スコアからも基本点合計は一意に逆算できないため、参照プレイでは両方を別々に記録する。

現在の必要評判候補と評判値による昇格用営業数187／109／78回は変わらないが、設備資金不足による追加周回を含む総回数ではない。

本書v0.3以前の最終スコア換算、ステージ・人数別の参照スコアから換算係数を作る案は撤回する。係数や強化価格は、料理基本点と実際の納品量から調整する。

## 4. 承認済みの報酬仕様

以下は2026-09-13にユーザーが採用を承認した報酬仕様。係数は初期値として採用し、設備価格は別途調整する。

### 4.1 換算係数の採用初期値

| 営業モード | 納品基本点へ掛ける係数 | 位置付け |
|---|---:|---|
| 通常営業 | 1.0 | 本店設備を育てる主要収入 |
| ソロ出張 | 0.1 | 攻略・解放に伴う少量収入 |
| マルチ出張 | 0.1 | チームの納品基本点から各参加者へ同額 |
| シーズン競技の各プレイ | 0.1 | 挑戦を続けながら少量を得る。順位報酬は別枠 |
| 報酬なし練習厨房 | 0 | 現行仕様を維持 |

通常係数1.0はコイン単位を決める試験値であり、料理基本点の実数や設備価格が確定したことを意味しない。料理基本点が10点単位なので通常1.0・出張0.1なら整数になり、最低基本点の料理でも納品がコインに反映される。

例: 基本点40の料理を10件、基本点60の料理を10件納品すると、合計1,000。通常営業は1,000コイン、出張は100コイン、マルチ出張では各参加者100コイン。これは説明用納品例であり、4分で20件納品できると保証するものではない。

係数の絶対値だけを変えても設備価格を同じ割合で変えれば強化所要時間は変わらない。今回の試験値を理由に旧価格5,000等を固定せず、Lv5一種類の目標営業数から価格を算出する。

### 4.2 シーズンの役割

各プレイは出張と同じ係数0.1を採用する。通常営業でLv5強化資金を得て、シーズンへ戻って記録を更新する循環を維持する。シーズンの周回だけでは通常営業並みの反復収入にならないことを目標にする。

この選択には、競技だけを続けたい人の設備成長が遅くなるというトレードオフがある。競技参加時点で全Lv4を保証する既定条件と、Lv5の性能差・価格を併せて検証する。シーズン終了時のコイン・外見等の順位報酬は今回の各プレイ係数とは別であり、廃止しない。

### 4.3 計算・付与

- 営業終了までに完了した納品の基本点を合計し、モード係数を一回掛け、小数点以下を最後に一回切り捨てる
- 星0・最終スコア0でも納品済み基本点に応じたコインを付与する。納品0件は0コイン
- コインは正規終了時に一度だけ付与し、任意の途中リタイアでは未確定報酬を付与しない。通信切断・障害は既定の保持・再送・減額規則に従う
- 同じ営業の反復でも通常の納品報酬を減衰させない。初回・固有報酬の重複禁止は既定どおり
- 評判ゲージが満タンでも、納品コインの獲得は続く

### 4.4 結果画面と次工程

結果画面ではスコアと星を示し、その下に「納品報酬：○○コイン」を表示する。初回報酬、課題等の追加があれば別行に表示する。スコアからコインへ変換する演出は行わない。

報酬の構造と初期係数は採用済み。次の検討は料理と設備の共通ルールへ進む。料理基本点、工程時間、設備Lv効果、代表営業の納品量を揃えてから、コイン価格・副収入・昇格所要時間を再計算する。
