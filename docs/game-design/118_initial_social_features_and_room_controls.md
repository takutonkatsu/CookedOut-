# COOKED OUT! 初期版の通話・フレンド機能と部屋管理案 v0.1

- 作成日: 2026-09-16
- 状態: 2026-09-16、自由文チャット・ゲーム内通話は将来も実装しないというユーザー指定へ修正して公開方針を採用。フレンド一覧の初期見送り、ロビー限定退出操作と部屋内再入室制限、参加受付の開閉も採用。具体UI・技術方式は未確定。通信機能やモデレーション基盤は未実装
- 既定: 友達との2〜4人出張のみ、公開検索・野良なし。コード／招待リンクで参加、フレンド登録は必須にしない。自由文チャット・履歴は初期に設けず、助けて／了解／ありがとうの合図を使う。営業中の新規参加なし

## 1. 自由文チャット・ゲーム内通話は将来も実装しない

自由文チャットとゲーム内通話は初期版だけでなく将来も実装しない。既定の画面情報と三つの合図で意思疎通できるゲームを目指す。通話を使わないプレイヤーにも同じゲーム条件を適用し、声での指示を必須にしない。

利点はマイク権限・通話状態・ミュート等の画面と運用を初期実装範囲から外せること。欠点は離れた友達と細かな相談をする際にゲーム内だけでは足りないこと。利用者が外部の通話を併用する場合のiOS上の音声・バックグラウンド挙動は別途実機確認し、併用が必ず問題なく動くと保証しない。特定サービスの機能・費用や法的要件は今回断定しない。

前案の「将来の追加候補として残す」は撤回する。試遊で伝わりにくい点が見つかった場合は、自由文・通話ではなく、画面情報や既定合図の分かりやすさで改善する。ユーザーが将来明示的に方針を変更しない限り、追加候補として再提案しない。

## 2. ゲーム内フレンド一覧・申請は初期版に設けない

登録を必須にしない既定から一歩進め、初期版にはフレンド一覧・申請承認・オンライン状態表示を実装しない案。友達との合流は既定のコードと招待リンクに一本化する。

アプリ内から特定の友達を直接呼び出せない不便さはあるが、遊ぶ前に別の人間関係リストを作る必要をなくす。端末の連絡先の取り込みや、自動的な知り合い検索を追加しない。将来のフレンドランキング等も今回一括採用しない。

## 3. ホストはロビーで参加者を退出させられる

ホストだけが他の参加者のプロフィール内メニューから「部屋から退出させる」を選べる案。対象の顔・名前を確認して実行する。通常の顔タップ一回で退出させず、誤操作を防ぐ確認を挟む。

対象は営業前後のロビーに限り、ロード・カウントダウン中と営業中は使用不可。既に成立した営業報酬・記録を取消しせず、営業中に相手を追い出して報酬を奪える機能にしない。人数変更により残る参加者の準備完了は既定どおり解除する。

退出させられたアカウントは、その部屋が存続する間は同じコード／リンクで再入室できない案。管理役の交代だけでは解除しない。誤って退出させた友達と再合流する際は部屋を作り直す不便さがあるが、初期は個別解除画面を増やさない。アカウント全体の永久ブロックや通報・処分とは区別し、それらの採否を今回確定しない。新しいアカウントによる再入室まで完全に防ぐ保証はしない。

## 4. 部屋を壊さず新規参加受付を閉じられる

ロビーのホスト用部屋メニューに「参加受付」のオン／オフを用意する案。初期値はオン。メンバーがそろったらオフにして、新しい参加者を止められるようにする。オフでも現在の参加者は残り、コードの再発行や全員の再入室は不要。

この設定は新規入室だけを止める。既存メンバーの一時切断からの正規再接続は妨げない。明示的に退出した人や第3項で退出させた人を、再接続枠として戻さない。ホスト交代時も受付状態を維持する。

営業中・ロード中の新規参加禁止は受付オンでも維持する。コードを知る人に現実の友達かどうかを自動判定する機能はなく、コード／リンクの転送で入れる範囲をユーザーに誤解させない。初期は入室ごとのホスト承認ポップアップを追加しない。

## 5. 範囲外・確認事項

外部通話互換性、永続ブロック・通報、コード推測対策の実装値、招待の未インストール導線。部屋管理UIの実寸・文言と、ホスト交代／切断／退出の同時発生は実装時に検証する。ロビー内で料理できる候補は後日検討を維持する。内蔵通話の技術選定・費用検討は将来の残件からも外す。
