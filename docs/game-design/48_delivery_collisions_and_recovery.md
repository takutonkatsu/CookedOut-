# COOKED OUT! 配達事故・復帰の基本方針 v0.2

- 作成日: 2026-09-13
- 状態: ユーザー指定で軽い接触は減速、強い衝突は短い転倒演出と容器パックの散乱・手動回収・再積載へ変更。無敵時間とコミカルな通行キャラの吹飛びを検討。血しぶきは禁止。具体閾値・散乱個数・秒数は未確定・未実装
- 既存との差分: CURRENTには「配達事故で時間と配達ボーナスの一部を失う」が残る。本案はその直接ボーナス減額を廃し、時間損失を主な代償にする変更提案。まだ現行確定値として差し替えない

## 1. 接触と事故を分ける

- 壁をかする・低速の接触: 減速または軽い押し戻し。毎回の転倒や長い操作不能は避ける。
- 強い衝突: 短いコミカルな転倒演出後、操作へ復帰する。料理は容器パックごと近くへ散らばり、プレイヤーが拾って荷台へ積み直す。自動的に全荷物を荷台へ戻す旧案は撤回する。連打・精密タイミング入力の復帰ミニゲームは追加しない案。
- 車輪が引っかかる・走行不能な場所に入る: 復帰操作で直近の安全な道路位置に戻せるようにする。最寄りの目的地や店へ瞬間移動する機能にはしない。
- 落下があるステージでは最後にいた安全な道路付近へ戻す。海・崖等を全ステージへ増やす決定ではない。

## 2. パックを拾って積み直す

強い事故で料理を容器パックごと散乱させ、拾って再積載する仕様を採用。料理の中身や注文対応まで消失させる意味ではない。以下は具体化の提案:

- 転倒後は路上を歩いてパックを回収できる。これは徒歩での荷物回収であり、徒歩納品を解放するものではない。
- 地面のパックへ置く／取るで1個拾い、荷台へ置くで再積載、作業で乗車して再開する。自動吸着・全件一括回収は第一案では使わない。
- 容器は閉じたままで食品がむき出しにならず、洗浄・作り直しは不要とする案。散乱範囲は歩いて回収可能な道路周辺に限定し、水中・屋根上・壁内部へ失われないようにする。
- 注文番号、料理、配送中状態、記録済み時間帯・倍率を保持し、再積載・再乗車でコンボやチップを計算し直さない。事故自体で共有コンボを切らない案。別注文の失注等によるリセットは通常どおり起こり得る。
- 復帰中も営業時間は進むが、発送済み注文のタイマーは再開しない。閉店までに到着しなかった分は既定どおり無得点・無コイン。
- 落下したパックが目的地の近くにあっても、それだけでは納品成立にしない。荷台へ戻し、乗車状態で既定の到着条件を満たして納品する案。
- 仲間の回収支援、別バイクへの発送済み荷物の移載、散乱する個数の固定／可変は未決。初期案として積載パックすべてを回収対象にする場合、最大5個時の復帰負荷を検証する。

事故の罰金、コイン減額、配達追加点の直接減額を初期版では設けない案。移動遅延、厨房へ戻る遅れ、営業中に完了できる件数の減少で失敗の代償を表現する。取出し・出荷順判定などとは別の失敗要素として明確にする。

燃料補給・修理費・耐久度管理・荷物破損率を追加しない。加熱中の料理が厨房不在中に焦げる既定の時間進行は止めない。

## 3. 復帰で悪化や近道が起きない条件

- 復帰地点は衝突前の走行履歴等から安全に停止できる道路位置を選ぶ。道路を塞がず、壁の中や別車両と重なる場所に戻さない。
- 崖越え・閉鎖道路越え・店への高速帰還に使えるワープにしない。
- 復帰直後の重なりで連続転倒する場合は短い再衝突保護を検証する。時間・当たり判定方式は未決。
- ユーザーから復帰時に若干の無敵時間を設ける案が提示された。短い再転倒防止として検討し、壁を通り抜けたり荷物を自動回収したりする効果にはしない。徒歩回収中も交通との重なりで操作不能が連鎖しないようにする。
- 通常走行より事故復帰を繰り返すほうが速くならないか確認する。
- 切断時の安全な路肩停止は既存の通信仕様を維持し、通信断を操作ミスとして追加減点しない。

## 4. 仲間への影響を抑える

プレイヤー同士がすれ違っただけで大きく転倒しないよう、軽い接触の扱いを基本にする案。悪意ある押し出しや通路封鎖が起こる場合は、接触判定や復帰規則を試作で調整する。歩行者・交通車両の数や事故演出の量を今回決定するものではない。

ユーザーは自由運転中に通行キャラクターが少し吹っ飛ぶようなコミカルな物理表現を希望。血しぶきは禁止とする。人間シェフを追加する指定ではなく、既存の動物キャラクター中心の方向と整合させる。追加案として星やほこりの演出、短く転がって立ち上がる反応を使い、負傷・死亡や轢くことへの得点報酬、警察追跡・犯罪システムまでは増やさない。年齢区分の取得を保証する記述はしない。

## 5. 検証

- 初心者が曲がり角で毎回転倒せず、ブレーキ・旋回を覚えられるか。
- 熟練者の経路・運転の改善が配送完了数に表れるか。
- 一度の事故で長時間操作不能にならず、拾い直す忙しさが楽しく、食品の作り直し義務にはならないか。最大5パック回収の時間と通常営業の厨房不在時間を確認する。
- 復帰を最短ルート代わりに悪用できないか。
- 自配達と代行の得点/分差を新しい事故方針で再計測する。既存の5〜10%目標や配達係数を無断確定しない。
