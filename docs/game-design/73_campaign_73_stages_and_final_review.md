## 1. 結論と規模

推奨する。料理の初登場だけでなく反復・組合せへ面数を使い、章の学習が最後に報われる構成にできる。ただし料理候補をすべて採用するための面数増ではなく、学んだ料理と操作を使いこなす余地として扱う。

8章×8面＋復習8面＋最終1面＝73面。現行制作目標54面から19面増、約35.2%増。第1章6面化を単純反映した52面と比べると21面増。1〜4人の記録・星基準を検証する基本組合せは216から292へ76増える。これだけで総工数も35.2%増と断定せず、盤面・アート再利用と特殊実装量に左右されると区別する。

採用時の星最大は各人数219、全4人数区分876。現行162／648は改訂対象だが、本書だけで既存記録値を変更しない。

## 2. 章の役割

| 範囲 | 役割の推奨 |
|---|---|
| 第1章8面 | 基礎学習と初めての実戦。8面すべてを新操作の説明にしない |
| 第2〜8章各8面 | 新しい料理・工夫を導入し、既習要素との組合せを試し、章のまとめへ進む |
| 9-1〜9-8 | 対応章の代表的な料理・協力課題を、新しい盤面条件で使いこなす |
| 9-9 | 代表的な既習要素を絞って組み合わせる最終大型営業。星1でエンディング、星2・3とランキングが熟練者の目標 |

通常章の8面は「導入2面→練習・変化2面→組合せ・応用3面→まとめ1面」を配分の目安とし、固定フォーマットにはしない。各面に新料理・新器具・新ギミックを同時追加しない。料理系統を増やしても共用操作は増やしすぎない。

第9章は原則新しい料理系統・操作を解放する章にせず、既習内容の再構成に使う。対応章の全レシピを一面に入れる意味ではない。9-9も全設備・全料理・全ギミックの同時盛り合わせにしない。主な難しさと補助的な難しさを絞る。注文は既定の自動継続方式とし、ウェーブを復活させない。

## 4. 第1章と本店解放は分けて考える

推奨は第1章を8面に増やしても、本店解放を従来どおり1-1〜1-6各星1時点に保つ案。1-7・1-8は最初の実戦・まとめとして、そのまま出張を進めるか本店を始めるかを選べる。マルチは初回からの既定を維持。出張経路は1-1〜1-8→2-1の一本道で、分岐面を新設する意味ではない。

これは現在の「第1章全クリアで本店解放」を明示的に変更する提案であり、未承認。序盤通常Lv1〜4に必要な4定番系統・最低限の操作を1-6までに経験できる導入表が条件。各面具体構成はユーザー指定の保留を維持する。8面全部を必須チュートリアルに戻す場合は、本店へ進むまでの時間増を検証する。

## 5. 第9章の解放・報酬・最終への接続

推奨は現行の全章一本道を維持し、8-8→9-1→…→9-9と進む。対応章復習という意味付けと、対応章の星全回収を要求する解放条件は別。後者を自動採用しない。第9章を任意の最高難度のみのボーナス章にすると、最終面の星1がシーズン解放条件である設計と衝突するため、星1は本編クリア用、星2・3を高難度目標とする。

9-1〜9-8は対応章の素材やモチーフを活かすが、旧盤面の単純速度増しにはしない。「序盤の切って組む作業を分断厨房の受渡しと組み合わせる」等、既習の仕事の回し方を変える。各面の具体料理・ギミックは後で相談する。

## 7. 料理側と制作スケジュール

料理側の最新ログC-D173〜174は、初期中核20系統を通常Lv1〜20に一つずつ割り当て、同20系統を出張へおおむね均等配置する選定目標。67系統比較表は候補一覧であり全採用ではない。C-P133〜138の具体20種・Lv順・章配分は未承認。今回の面数提案を理由に全67系統を初期実装確定しない。

Core Alphaは第1章と本店基盤を優先する既定を維持し、73面すべての制作を2週間へ入れない。採用後は73面の役割・再利用資産・主要ギミックの企画表を並行整理し、ステージ制作は共用ギミックの検証後に展開する。2週間完了を今回保証せず、現行実装状況の確認と工数見積りは別途。
