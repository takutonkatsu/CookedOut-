# COOKED OUT! キャラクター選択とプレイヤー識別案 v0.1

- 作成日: 2026-09-14
- 状態: 2026-09-15、ユーザーの「すべてよいです」で公開方針を採用。同キャラ重複可、色＋形の識別、自分だけの補助目印、部屋内の対応維持、自分の顔から変更・本人のみ準備解除、営業中変更不可、厨房の名前／バッジ常時表示なしが対象。具体色・形・サイズ・未公開細部は未確定。モデル・UI・操作は未実装
- 前提: 動物キャラクターのみ、共通能力・当たり判定。外見で性能差を設けない。ロビーの参加者プロフィールは一か所へ集約し、各端末には本人の人数別実績を表示する。マルチの料理詳細から練習へ遷移しない

## 1. 同じキャラクターの重複を許可する

複数人が同じ動物・同じ外見を選べる方式を推奨する。好きなキャラを先着順で取り合わず、全員同じ動物で遊ぶこともできる。選択できるのは本人が利用可能なキャラクター・外見の範囲とする。新しいキャラの貸出・交換・課金方式は今回決めない。

## 2. 衣装を強制変更せず識別マークを添える

参加者ごとに異なる色と簡単な形を組み合わせた識別マークを付ける案。足元の小さなリングやマーク、ロビープロフィール、配送中の顔アイコン、クイック合図の送り主で同じ対応を使う。色だけに依存せず、衣装・毛色を強制的に塗り替えない。

自分のキャラには本人の端末だけに追加の小さな目印を付け、自分を見失いにくくする。具体的な4色・4形、表示サイズ、頭上か足元かの最終配置は実機検証。料理や対象選択輪郭、バッジと混同しないデザインにする。

識別は部屋内の参加枠に紐付け、キャラ変更で変えない。営業中と切断復帰時に既存参加者の対応を入れ替えない。次の面でも同じ部屋に残っている人の対応を維持する。部屋を移った後まで同じ色を永久に予約する仕様ではない。

## 3. 自分のプロフィールから選択する

ロビーの自分の顔を押して、キャラクター・装着外見・既定のバッジを変更する案。閉じるとロビーへ戻り、別の店や街へ移動しない。他人の顔を押してその人のキャラを変更することはできない。

自分の変更画面を開く時は本人の準備完了だけを解除し、選択中に営業が始まらないようにする。変更していない他人の準備を解除しない。ロード・カウントダウン開始後と営業中には変更させず、戻ったロビーで再び選べる。

他人のプロフィールを詳しく見る操作の有無は未決定。選択画面にショップや課金購入を直接組み込むことも今回の承認対象にしない。

## 4. 名前を厨房へ常時並べない

厨房内は動物の外見と識別マークを中心にし、全員の長い名前・バッジを常時頭上表示しない案。名前とバッジはロビーのプロフィールで確認できる。顔だけでは同キャラを区別できない配送状況・合図にも対応マークを用い、誰の状態かを維持する。

この方式の弱点は識別マーク分だけ表示が増えること。小画面で注文・対象輪郭・料理が読みにくくならないか、同キャラ4人と色の判別が難しい場合を試す。ソロ二キャラの選択・識別の詳細は別途とし、操作切替を自動化しない。
