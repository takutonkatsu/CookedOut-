# COOKED OUT! 大型設備の固定範囲と視覚的な区別 v0.2

- 作成日: 2026-09-13
- 状態: 公開した営業中本体固定／準備中配置変更、各1マスの第一試作、専用天面、形による可搬・固定の区別をユーザー承認により採用。具体モデル・数値・配置枠数は検証待ち。未実装

## 0. 料理側で更新された事項

料理決定ログのC-D089〜094では、フライヤー本体は固定、かごは着脱して持ち運べる方式へ変更済み。油面上へ引き上げた状態だけ着脱可、一台につき一かご、かごがない本体は使用不可、外したかごへ材料投入可となっている。全体仕様の古い「かご固定」はこの料理側決定と食い違うため、今後の判断に使わない。

今回、料理側ログを直接確認した。料理の材料・レシピ等を一括承認・変更するものではない。全体の本体可搬範囲と一緒に整合を相談し、61等の全面改訂はその範囲が確認できてから行う。

## 1. 本体は営業中固定、準備中は配置変更可能とする案

オーブン・フライヤーの本体は営業中持ち上げられない。通常営業と既定のシーズン準備では対応設備枠の中で配置変更可能。出張営業は作者指定の初期位置とし、事前盤面公開や編集を解放しない。

ミキサー・卓上コンロ等の可搬方針は維持する。固定大型設備へ向かう動線と、小型設備を自分で動かせる工夫を両立させる。固定大型設備ばかりにして可変厨房の意味をなくさない点はステージ設計で検証する。

トレーやかごの運搬は本体移動と分ける。オーブントレーの焼成途中取出し不可は維持し、フライヤーかごは料理側の引上げ後着脱へ揃える方向を確認する。

## 2. 占有は各1マスを第一試作案とする

オーブン・フライヤーとも標準1マス。複数マス専用の配置操作を初期版へ増やさない。オーブン天面は専用トレー用で、まな板等を重ねる共通作業面にはしない。フライヤーの上にも別設備を重ねない。小画面での視認性と実物モデルの大きさは検証する。

## 3. 可搬・固定は設備の形で区別する案

可搬機器は台上に独立して置かれた小型機器、固定機器はカウンターへ組み込まれた形を基本とする。常時「移動可／不可」の文字を載せず、対象選択時の操作表示は実行可能な操作だけを出す。新規操作ボタンや移動料を加えない。

色だけで区別せず、底面・取っ手・組込み形状等で判断できるようにする。具体的な造形・配置枠数・章導入位置は本提案で確定しない。
