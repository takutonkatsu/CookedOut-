# COOKED OUT! 月末21時のシーズン切替と公開日程 v0.2

- 作成日: 2026-09-13
- 採用: シーズン切替は毎月末日21:00、日本時間（Asia/Tokyo）。従来の4週間固定を暦月単位へ変更。一シーズン4厨房は維持
- 状態: 公開した開始・7／14／21日後の4厨房公開、締切前完走判定、検証可能な遅延送信の猶予、締切またぎ営業の継続と順位対象外、新シーズン開始と旧集計確定の分離を採用。具体猶予時間・未公開細部は保留、未実装。監視やスケジューラーの実作成ではない

## 1. 公開は開始・7日後・14日後・21日後

新シーズン開始時に第1厨房、7日後に第2、14日後に第3、21日後に第4を公開する案。すべて日本時間21:00。5番目の厨房は増やさず、第4厨房公開後から月末までは全4厨房を遊べる追込み期間とする。公開済みは終了まで残す。

例：10月シーズンは9月30日21:00開始、10月7日・14日・21日21:00に追加、10月31日21:00終了。最後の全厨房期間は10日。月の長さによりこの期間は7〜10日になるが、同じシーズンの全員に共通。一か月の固定条件で競い、別の月の合計点を同一ランキングへ混ぜない。

前月末21時から始まることを終了日時とともに表示し、「毎月1日0時開始」と誤認させない。切替時刻は端末の時計やタイムゾーンで変えず、運営側の時刻で判定する。実装では日時を一意に保存し、表示は日本時間。閏年・月28〜31日・年跨ぎを検証する。

## 2. 締切は営業を終えた時刻で判定

ランキング対象は、旧シーズン終了時刻より前に営業終了が成立した有効記録とする案。開始時刻だけでは対象を保証しない。月末21:00ちょうどからは新シーズンの期間とし、旧記録には含めない。

通信遅延で結果送信だけが21時を越えても、締切前完走を検証できれば、別途決める受信猶予内で旧シーズンへ反映する。端末自己申告の時刻だけを信頼しない。猶予は追加プレイ時間ではなく、終了済み結果の送信・検証用。期限・上限・検証不能時の扱いは実装前に決める。

21時にまだ営業中なら旧シーズン順位には算入しないが、即座に強制中断はせず、営業を終えて通常の有効プレイ分のコインを受け取れる案。新シーズンへの得点移し替えはしない。締切直前の開始には「終了までに完走が必要」と短く警告し、ソロ一時停止でも暦上の締切は延びない。終了間際の開始を制限するかは別途検討し、今回未承認の禁止条件は加えない。

## 3. 新シーズン開始と旧結果確定を分ける

月末21時に新シーズンを開始し、旧シーズンは「集計中」とする案。締切前完走の遅延送信・検証が済んだ後に最終順位と報酬を確定する。21時に未確定報酬を即配り直す方式にはしない。新シーズンの公開を旧集計待ちで遅らせない。

新シーズンの4厨房スコアは新規集計。店ランク・コイン・設備・本編星・バッジはリセットせず、旧シーズン結果は履歴へ残す。報酬受取のボタン・自動付与・期限と具体報酬は別途相談。

## 4. 正式公開前に固定条件を十分調整する

77のユーザー希望を受け、正式リリース前は実機・1〜4人・初心者と熟練者・配置・献立・配送戦略を検証し、公開後の条件改訂を例外にする。修正ゼロを保証はせず、公平性を守る記録分離手段は残す。テスト版の記録を正式ランキングへ移すかは別途。

シーズン内の条件固定は、運営側の盤面・注文列・採点等を指す。本人が通常営業で設備を購入・強化し、次回の競技挑戦へ反映できる既定の成長要素を凍結する変更ではない。営業開始後の装備差替えは既定どおり不可。

## 検証・保留

- 月末境界前／同時／直後、閏年、端末時刻変更、結果重複、送信遅延、一時停止・切断
- シーズンはソロ専用のため部屋・招待リンクは不要。締切時に配置準備中の場合の導線と、メンテナンス時の例外は別途
- 検証と集計の所要時間・受信猶予、報酬受取、シーズンIDと結果一意性
