# COOKED OUT! ランキング同点と条件更新時の記録 v0.2

- 作成日: 2026-09-13
- 状態: 公開した同点同順位・同順位同報酬、条件変更時の記録分離と正当な過去達成保全、シーズン内の原則条件固定を採用。ユーザー希望で正式リリース前の調整を重視し、公開後の記録分離は例外時の備えとする。本文の4週間表現は後続の毎月末21:00 JST切替（78）へ変更。未実装

## 1. 同点は同じ順位

通常の出張常設ランキングと4週間シーズン競技を対象とする。スコアが同じなら同順位、次の順位は前にいる記録の件数に応じて飛ばす競技順位方式を推奨する。例：1000、900、900、800点なら1位、2位、2位、4位。

早く到達した人・先に投稿した人・納品数・ミス数等を隠れた順位決定条件にしない。共通表示スコアの同点を内部の非表示小数で分けない。同順位内の一覧表示は安定した内部キー等で揃えてよいが、順位や報酬の優劣は付けない。シーズンは4厨房合計の同点に適用。別設計の連続営業ランキングに自動適用しない。

シーズンの順位帯報酬は同順位なら同じ報酬とする案。境界に同点があれば対象者が予定人数より増え得ることを予算設計へ反映する。報酬の具体額・順位帯・割合帯の丸めは別相談。固定人数しか受賞できない報酬を先に作らない。

## 2. ゲーム条件が変わった記録を混ぜない

出張常設で、盤面・注文列・設備能力・得点式・制限時間・ギミック等、スコア比較の条件を実質変更した場合は、新条件のランキングと旧条件の記録を分ける案。順位への影響がある不具合修正も同様に判定する。得点を推定変換して混ぜず、新条件の自己ベストは新たに記録する。

旧条件の自己ベスト・獲得星・章解放・バッジ・正当に確定した報酬は保持し、過去の実績として扱う。星基準を変えても獲得済み星を下げたり解放を取り消したりしない。新条件ランキングの登録は新条件で正規完走した記録を使い、旧星3保有だけで新記録を掲載しない。これは正当記録の条件更新時の扱いであり、不正記録を永久保護する意味ではない。

スコアに影響しない装飾・説明修正等だけならランキングを分けない。見た目変更でも視認性や当たり判定・入力が変わるなら影響を確認し、単純に全部「見た目だけ」と扱わない。変更の影響区分と記録条件の版を内部管理する。

プレイヤーの通常画面には現在の条件のスコアと順位を表示し、旧記録は必要な時だけ「過去の記録」で確認できる形を候補とする。旧自己ベストと新順位を同じ条件のものに見せない。条件変更時だけ短く案内し、常時バージョン番号を大量に表示しない。

## 3. シーズン中の競技条件は原則固定

公開済み4厨房を後から追い付いて遊べる既定を守るため、シーズン途中の意図的なバランス調整は原則避け、次シーズンへ反映する案。通常営業や無関係の見た目修正まで停止する意味ではない。週次公開と、そのシーズンの得点計算・条件固定を両立させる。

重大不具合・不正の修正が必要な場合は公平性を優先し、告知・対象記録の扱い・必要な競技停止を個別判断する。無条件の全記録削除・補償額・シーズン打切り権限は今回決めない。整合しない条件の得点を黙って同じ4週合計へ混ぜない。

## 保留

正式リリース前は全56面の1〜4人、初心者／熟練者、献立・配置・配達方式・事故復旧、得点の極端な稼ぎ方、実機・通信差を検証し、盤面・得点条件・星ラインを十分調整してから固定する。自動検証と人間のプレイテストを併用する。公開後の改訂を頻繁な前提にはしないが、完全に不具合や最適戦略の発見をなくせるとは保証せず、今回の記録保全方針は残す。

- 旧ランキング全件の保存期間、閲覧範囲、サーバーコスト
- 順位帯報酬の詳細、同順位の一覧表示順、重大障害時の運用手順
- 更新中の進行営業の結果受理、同点・境界値・再送・条件版ごとの試験
