# COOKED OUT! 音・振動・操作設定の範囲案 v0.1

- 作成日: 2026-09-15
- 状態: 2026-09-15、公開方針を採用。ユーザー指定で全ボタン自由配置の採用可能性を残し、操作変更画面は設定画面からだけ開く。営業前の自動表示はしない。具体寸法・未公開細部・実装は未確定
- 既定: 横持ちiOS、厨房は左スティックと右アクション群、配達は左アクセル／ブレーキ・右左右操作。ソロは全体ポーズ、マルチは個人の設定操作で営業を止めない。クイック合図の任意非表示は採用済み

## 1. 音量はBGMと効果音を分ける

BGMと効果音の二つの音量調整を設け、各々ゼロにして消せるようにする案。調理音・警告音・操作音は初期は効果音へまとめ、種類ごとの多数のスライダーは作らない。ボイスチャット音量は機能自体が未決定なので今回追加しない。

焦げ・注文期限・火災等を音だけで伝えず、消音でも既定の表示で分かるようにする。BGMの終盤変化という演出は維持するが、消音ユーザーだけ残り時間に気づけない設計にはしない。具体音源の選定は音声側の台帳で進め、ここで差し替えない。

## 2. 振動はオン／オフ

初期は強度の細かい調整ではなくオン／オフを用意する案。短い振動を重要な操作成立・事故等に絞り、刻み続ける・歩き続けるたびに振動させない。初期値・対応機種・イベント割当・強度は実機検証で決める。振動がなくても全操作と状態判断が成立することを前提にする。

## 3. 操作配置は標準と左右反転

標準は既定配置を維持し、厨房と配達で独立して左右反転を選べる案。厨房は移動スティックとアクション群の位置を交換し、配達はアクセル／ブレーキ群と方向ボタン群の配置を交換する。左右の操舵の意味そのものを逆転する設定ではない。

操作ボタンの大きさは小・標準・大の3段階を初期案とし、ボタン同士・注文票・端末の安全領域へ重ならないプリセットとして検証する。小でも押せる最低サイズを守り、大でゲーム画面が読めなくなる場合は配置を再調整する。世界内の判定・移動速度・調理能力は変えない。

全ボタンを自由配置する機能の採用可能性は残す。現時点では左右反転とサイズ3段階を基本案とするが、自由配置を永久不採用とも初期版必須とも決めない。具体範囲と採用時期は後で検討する。プレビューで配置を確認でき、初期設定に戻す操作を用意する。

## 4. 視覚演出の軽減

画面揺れ・装飾的な点滅を抑える設定を用意する案。事故や厨房ギミックそのものを無効にする機能ではない。危険予告・火災・対象選択の必要表示は消さず、揺れや点滅を減らしても位置・輪郭等で情報が伝わるようにする。具体軽減対象と初期値は未決定。

クイック合図の非表示設定は既定を維持し、重要な自動状態表示を消す設定とは分ける。料理・設備を見分けやすくする基本アートは設定の利用を前提にせず、通常状態でも成立させる。

## 5. 開く場所・変更タイミング・保存

ホームとメニューから設定へ入る。操作配置・サイズの変更画面への入口は設定画面内だけとし、営業前に毎回自動表示したり準備フローの必須手順にしたりしない。利用者が必要な時だけ設定から開く。操作配置の変更は営業・練習の開始前に行う既定を維持し、変更画面を開く場所と変更可能なタイミングを区別する。ソロ営業中は既定の全体ポーズを適用し、マルチ営業中は他人の営業を止めない。音量・振動・演出軽減はメニュー内で変更可能とする案。

設定は端末ごとに自動保存する。機種変更・別端末ログインで操作位置や音量を勝手に上書きせず、初回は標準設定から始める。成長・衣装・実績等のアカウント保存とは区別する。全データ初期化と混同しない「設定を初期値へ戻す」を用意し、進捗・コインは削除しない。

## 6. 今回決めないもの

具体UI寸法・スライダー初期値・左右反転レイアウト、ゲームパッド対応、画質／節電設定、フレームレート、ボイスチャット、音源、詳細な補助操作は未決定。設定変更で注文・星基準・ランキング条件を変える難易度モードを新設しない。
