# COOKED OUT! シーズン課題選択と配置準備 v0.1

- 作成日: 2026-09-14
- 状態: 2026-09-14、公開した週別献立・自己ベストと必要設備表示、初回の本店配置下書き複製、課題別保存、不足設備だけを示す準備、原料箱の課題対応、再挑戦と配置見直しの導線を採用。具体UI・未公開細部は未確定、未実装
- 前提: 本人の厨房配置と固定街で4つの営業課題に挑戦。第1〜3週2系統・第4週3系統を初期方針とする。具体テーマと料理は保留

## 1. 各週の献立を見て課題を選ぶ案

4つのカードを「第1週〜第4週」で並べ、公開済みは課題の料理系統・料理画像と自己ベストを表示する。未公開は公開日時だけを示し、まだ遊べないことを明確にする。正式な企画名・課題名は別途。

課題を選んだら、注文に登場する個別料理と必要設備を確認できる。系統だけを見せて派生料理に必要な設備が開始後まで分からない構造にはしない。注文順の全一覧や模範配置・最適ルートの事前提示を追加する案ではない。

献立は全プレイヤー共通の課題条件であり、通常営業の日替わりメニューのように別系統へ差し替えない。本人が工夫するのは設備の選び方・台数・配置と料理や配送の手順。出張営業の盤面下見禁止はシーズンの準備へ拡張しない。

## 2. 初回は普段の本店配置を出発点にする案

各課題の保存配置がまだない時だけ、その時点で選択中の本店準備配置を複製して、競技準備の下書きとして開く。毎週空っぽから置き直す必要をなくす。

課題の必要設備が不足していれば本人が補い、確認して保存する。初回複製だけで営業開始や本店配置の上書きをしない。以後はその課題で保存した配置を呼び出し、本店配置の変更を自動同期しない。

第1週・第2週などの準備配置は個別に保持する。同じ所有設備をそれぞれの配置で使っても、同時営業ではないので別購入を要求しない。保存は配置の設計情報であり、設備所有数の複製や装備の週別占有ではない。

84の次回開始時の最新Lv反映、通常営業とシーズンの保存分離、リトライは準備配置から開始する既定を維持する。これは本人の本店から初回下書きを作る導線であり、シーズン配置のURL共有・他人からの取り込みを解禁しない。

## 3. 必要な準備だけで始められる案

準備画面は本人の厨房配置を中心にし、献立に必要でまだ配置されていない設備だけをアイコンで示す。強化推奨や上位者の台数を必須条件に変えず、料理成立に必要な配置・到達可能性等の既定チェックを行う。

原料箱の中身はその課題に合わせて準備し、箱を一つずつ買い直したり補充作業をしたりすることを要求しない。同じ食材は既存の供給割当方針に沿って位置が不用意に変わらないようにする。3系統分の材料が供給枠に収まる具体ルールは料理選定と合わせて検証する。

配置が成立していれば、そのまま開始できる。毎回編集を必須にしない。終了後は「もう一度」なら保存済みの準備配置から同じ課題へ、「配置を見直す」なら準備へ戻る。時間と注文の固定条件は既定どおり維持する。

## 保留・検証

- 具体ボタン名・UI配置。初回の本店配置複製と個別料理の事前表示は公開方針を採用済み
- 本店基礎空間と競技準備の互換性、初回下書きのキャンセル・保存、必要設備差分の検証
- 料理詳細・供給枠・具体テーマは保留。開始時に全料理を十分作れる設備構成を用意できることを確認する
- 模範配置の自動生成、シーズンの配置共有、新たな設備貸出しや購入、実装や画像生成は追加しない
