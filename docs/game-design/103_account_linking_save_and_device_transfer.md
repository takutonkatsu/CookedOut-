# COOKED OUT! 初回開始・アカウント連携・機種変更案 v0.1

- 作成日: 2026-09-15
- 状態: 2026-09-15、ユーザー承認で公開方針を採用。登録入力なしで開始、確定データ自動保存、任意の後日連携と1-6後の一度の案内、有料初回購入前の連携必須、機種変更で確定済み進捗・本店／シーズン保存配置を復元、同時営業不可、別端末ログインで進行中を強制終了しない、新旧進捗を自動合算／上書きしない方針が対象。具体連携先・未公開細部・実装は未確定。特定サービスの能力・規約を断定する資料ではない
- 既定: 正式営業は開始時オンライン必須、マルチは初回から利用可、結果は検証後確定・二重付与防止。通信不可時は保存済み内容の練習を利用できる

## 1. 初回は登録作業を挟まず開始する案

初回接続時に内部のプレイヤーIDを自動作成し、未連携のままソロ・友達とのマルチを始められるようにする。開始前にメールアドレス入力・パスワード作成・アカウント連携を必須にしない。既存プレイヤー向けには初回画面に引き継ぎの入口も用意する。

この未連携アカウントと、マルチのホストに対するゲスト参加を混同しない。内部IDは表示名や端末名ではなく、後で連携しても同じ進捗を指す。認証方式・内部ID仕様は別途選定する。

## 2. セーブは自動、本人の復旧手段は別に持つ

コイン・店ランク・設備・料理解放・出張実績・外見・バッジ等の確定済みゲームデータはサーバーへ自動保存し、手動セーブボタンを不要にする案。本店・シーズンの保存済み配置も引き継ぐ対象に含める。営業途中の状態保存や、未検証結果の即時確定を新たに約束しない。

サーバー保存済みでも、本人のアカウントへ入り直す手段がなければ復旧できるとは限らない。未連携のまま端末紛失・再インストール等が起きた場合に、無条件で復旧可能とは表示しない。機種変更前には連携と同期完了を確認する。

音量・操作位置・描画品質等の端末依存設定を同じように全端末へ上書きするか、練習配置までクラウド保存するかは別途。端末側にしかない正規終了結果の送信待ちも、まだ新端末へ自動移動できるものと扱わない。

## 3. 連携は後から、最初の区切りで案内

ホームの設定からいつでも連携できるようにする。初回1-6クリア後の本店解放時に一度、データを守るための短い案内を出すことを提案する。閉じても通常の進行・マルチ・既定のランキング参加条件には影響させない。営業中や毎起動時に繰り返し遮らない。

有料商品の初回購入前は、復旧手段を確保するためアカウント連携を必須にすることを推奨する。無料プレイの連携任意と区別する。購入までの手間が増える欠点はあるため、連携できない利用者の購入機会への影響も検討する。これは商品購入フローの案であり、ストアが要求する規則という主張ではない。

具体的な連携先、利用できない場合の代替手段、年齢・保護者による制限との整合は公式情報を確認して後で決める。この段階で独自パスワード管理や外部連携方式を実装しない。

## 4. 機種変更と同一アカウントの複数端末

新端末では連携済みアカウントに接続し、サーバー上の確定済みデータを読み込む。単なる連携で別の新規IDへ置換したり、店ランクを初期化したりしない。

2026-09-16のユーザー指定により、同じアカウントの2端末同時ログインを禁止する。複数端末は切り替えて利用し、「同時営業だけ禁止、同時ログインは可」とする旧範囲を置き換える。既に進行中の営業を新端末ログインだけで強制終了させない既定との整合を含め、切替確認・旧端末失効・切断復旧の具体体験は114の未承認案で相談する。

端末喪失・クラッシュ・未同期結果で営業状態が残った時の解消経路と有効期限は95と合わせて設計する。永久に利用できなくなるロックを許容する方針ではない。配置編集・購入等の同時更新の排他範囲は未確定。

## 5. データが二つある場合は自動合算しない

新端末で少し遊んだ後に以前の連携済みアカウントへ切り替える場合、新旧のコイン・進捗を足し合わせない案。以前のデータの概要を確認し、そのアカウントへ切り替えることを本人が選ぶ。既存データがある連携先へ新しい進捗を無断上書きしない。

アカウント切替はデータ削除と同一ではない。切替元の未連携データへ再アクセスできる条件、保留結果の扱い、削除・連携解除・復旧は別途設計する。課金購入権の復元もゲーム進捗の合算とは区別して別途確認する。

## 6. 次の具体検討へ残すもの

連携プロバイダー、同期・セーブ競合の規則、同時営業の解消期限、アカウント削除と問い合わせ、購入復元、認証の失敗時、キャッシュ・端末保存の保証。今回の案はプレイヤー体験とデータ保全の基本方針であり、利用サービスや運用費・規約対応が確定したという意味ではない。
