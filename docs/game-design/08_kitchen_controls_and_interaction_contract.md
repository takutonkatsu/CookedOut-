# COOKED OUT! 厨房操作・インタラクション契約 v0.1

- 更新日: 2026-09-11
- 状態: 大枠決定。反応時間、移動速度、ボタン寸法は実機試験で調整
- 目的: Overcooked型の直感的な厨房操作感を、iOS横持ちへ一貫して実装する

## 1. 「本家と同じ操作感」の定義

同じにする対象は、少ない入力、向いている対象への文脈操作、一人一個の持ち物、置く・渡す・投げるの素早さ、継続作業、料理状態の即時フィードバックである。

既存作品のボタン画像、HUD配置、具体的な数値、アニメーション、効果音、ソースコードは複製しない。iOS向けに独自の入力面とフィードバックを作るが、プレイヤーが厨房内で考えることは同じ簡潔さにする。

## 2. 厨房中の入力

| 入力 | 空手時 | 持ち物あり | 設備前 |
|---|---|---|---|
| 左スティック | 連続移動・向き変更 | 持ったまま移動 | 継続作業中は離脱で中断 |
| 取る／置く | 対象を一つ持つ | 前方の有効面へ置く／合流する | 鍋・フライパン自体を持つ、または中身を容器へ移す |
| 作業 | 有効設備を使う | 消火器等の手持ち道具を使う | 切る、洗う、消火する等を継続 |
| ダッシュ | 向いている方向へ短く加速 | 持ち物を維持して加速 | 作業中は作業を解除して移動 |
| 投げる | 反応なし | 投擲可能物だけ固定弧で投げる | 有効な鍋・台・仲間へ軽く照準補正 |

右側の基本入力は「取る／置く」「作業」「ダッシュ」「投げる」の四つ。投擲不能物を持っている時は投げるボタンを無効表示にできるが、位置は動かさない。

## 3. 共通挙動

- キャラクターはグリッド上をアナログで連続移動し、セル中心へ吸着しない
- 一人が同時に持てる物は一つだけ
- 近距離かつ前方の対象を自動選択し、実行前に輪郭表示する
- 持つと即座に手のソケットへ収まり、置くと前方の有効な置き面へ収まる
- 有効な容器・食材・鍋へ置いた場合は、同じボタンで材料合流を行う
- 無効な組合せは状態を変えず、短い拒否音とアイコンを返す
- キャラクター同士は軽く押し合う。完全にすり抜けず、長い転倒硬直も付けない
- カウンター角では移動補正を弱くかけ、小さな引っ掛かりを減らす
- 持ち上げ、設置、投入、提供の開始を入力後すぐ画面と音へ返す

## 4. 下処理と継続作業

- 食材をまな板へ置き、空手で作業入力を続けると切断ゲージが進む
- 作業入力は押し続けを基準とし、連打しても同じ上限速度で受け付ける
- 移動または入力解除で作業を中断し、進捗は食材側へ保持する
- 皿洗いも同じ継続作業規則を使う
- 二人が同じ一設備を同時作業して速度を倍化する仕様は初期版では使わない

## 5. 鍋・フライパン

- 材料を対応器具へ置く、または投げ入れると調理対象へ追加する
- 必要材料が揃うと自動で加熱を開始し、作業ボタンで火力調節しない
- 加熱中、完成、焦げ警告、焦げ、火災を色だけでなくゲージ、音、湯気・煙で示す
- 完成後も熱源上へ置くと焦げへ進む
- 鍋・フライパンは持ち上げて熱源から外せる
- 完成した中身は、対応する皿または配達容器を使って一操作で移す
- 鍋、フライパン、皿は投げられない

## 6. 投擲

- 生食材、切り済み食材、投擲可能な中間食材、共通配達容器を投げられる
- 投げは溜め操作にせず、一定距離・一定時間の読みやすい放物線とする
- 有効なカウンター、仲間、対応する鍋・フライパンへ弱い着地点補正をかける
- 仲間が持てる状態なら直接キャッチできる
- 場外へ落ちた食材は短い復帰待ち後に失われるか供給元へ戻る。ステージごとに統一する
- 皿、鍋、フライパン、消火器は投げられない
- 完成配達容器は投げられる。未完成料理入り容器の投擲は実機試験で確定する

## 7. ダッシュ

- 向いている方向へ短く速度を上げる
- 持ち物は落とさず、料理状態も変えない
- 壁や仲間へ衝突すると短く減速するが、長い行動不能にはしない
- 連打だけが常時最適にならない短い再使用間隔を持たせる
- 1-3後に解放される初心者マルチでは必須にせず、1-4で正式に教える

## 8. 廃棄、提供、事故

- ゴミ箱前の取る／置くで廃棄候補を示し、短い長押しまたは再入力で確定する
- 正しい完成料理だけを提供口、代行棚、バイク積載へ受け付ける
- 誤料理は提供できず、廃棄して作り直す
- 火災時は消火器を持ち、作業入力を続けながら向きで噴射方向を変える
- 厨房で落下したキャラクターは短時間後に同一区画の安全地点へ復帰する。食材・料理は失うが、手持ちの器具・設備本体・一式は空の状態で本人の手へ戻す。永久紛失させない。[厨房落下・復旧仕様](62_kitchen_falls_and_equipment_recovery.md)を優先し、配送路上のパック散乱とは区別する
- 一回の事故で営業を終了せず、時間損失と作業崩れから立て直せる

## 9. モバイル固有の受入条件

- iPhone横持ちで、親指を離さず移動と右側入力を併用できる
- 取る／置くと作業の誤入力率を計測し、頻発する場合も自動化で操作種類を隠さない
- 操作ボタンは固定位置とし、状態によって並び替えない
- 60fpsを目標に入力から最初の視覚反応まで原則2フレーム以内
- 仮想スティックのデッドゾーン、ダッシュ時間、投擲補正は実機で調整する
- 振動を切っても音と画面だけで状態を判断できる

## 10. 根拠と独自性

Team17の公式資料は、食材投げ、鍋への直接投入、動的厨房、注文順コンボ等をシリーズの中心機能として説明している。本作はその一般的な操作文法を参考にし、配達容器投げ、バイク配達、配送代行、本店成長、独自UI・造形・数値で別の体験構成にする。
