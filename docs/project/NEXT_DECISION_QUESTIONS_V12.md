# COOKED OUT! 次期大枠仕様・回答用質問票 v1.2

- 更新日: 2026-09-11
- 状態: 回答済み。競技スコアのみ表示、個人設備を使うシーズン競技と共通設備の常設ランキングを分離。常設ランキングの範囲等はv1.3で確認
- 対象: 4週間シーズンの合計スコアランキング
- 参照: [4週間シーズン・合計スコアランキング仕様案](../game-design/16_season_score_ranking_system.md)

## 1. 合計スコア

- 1-A. 各厨房は全挑戦の合計ではなく、その厨房の自己ベスト一件だけを採用し、4厨房の自己ベストを合計する形でよいか。
- 1-B. 料理や配達有無による得点規模の違いをなくすため、生スコアを各週・各人数の基準スコア10,000点へ換算した「競技スコア」を合計してよいか。
- 1-C. 競技スコア10,000は上限にせず、基準以上なら11,000以上も記録できるようにしてよいか。
- 1-D. 結果画面では競技スコアを大きく、生スコアを小さく併記してよいか。

## 2. 設備配置

- 2-A. 設備の種類、台数、Lvは競技厨房ごとに全員共通で貸し出し、プレイヤーは位置だけ変更できる形でよいか。
- 2-B. 壁、穴、固定カウンター、食材箱、提供口、スポーンは固定し、指定ソケット内だけへ設備を配置してよいか。
- 2-C. 競技配置プリセットは厨房ごと・人数ごとに一つ保存し、挑戦間は何度でも編集可能にしてよいか。
- 2-D. 2〜4人ではホストが配置を確定し、ゲストは準備完了前に完成配置を確認する方式でよいか。

## 3. 人数別記録と同点

- 3-A. 協力時のスコアを参加者全員の自己ベストへ反映し、自己ベスト時の仲間を週ごとに記録してよいか。
- 3-B. 協力ランキングは固定チーム制にせず、週ごとに異なる仲間と出した自己ベストを合計してよいか。
- 3-C. 同点時は、失効合計が少ない、納品合計が多い、最終合計を先に達成した、の順で決めてよいか。
- 3-D. グローバル上位200、国内上位200、フレンド順位、本人の順位と上位割合を表示してよいか。

## 4. 質問2-Cの言い換えと報酬

以前の2-Cは「1人、2人、3人、4人ランキングの報酬を、一人が最大四回受け取れるようにするか」という質問だった。

- 4-A. コインと共通外見は、四ランキングのうち本人の最も高い順位区分を基準に一回だけ与えてよいか。
- 4-B. 人数別の順位バッジとプロフィール記録は、参加したすべての人数帯で獲得できるようにしてよいか。
- 4-C. 報酬区分を、参加、上位50%、25%、10%、3%、1%、トップ100、トップ10、1位としてよいか。
- 4-D. ランキング報酬に性能差を付けず、限定外見も将来再入手機会を設けてよいか。

## 5. 無制限挑戦

- 5-A. 挑戦回数は完全無制限とし、未完走や低スコアでも自己ベストを下げない形でよいか。
- 5-B. 自分側の切断・途中退出は未完走扱いだけにし、回数制限がないため追加ペナルティを付けない形でよいか。
- 5-C. 上位記録はサーバー検証と再現用ログを必須にし、異常記録はランキング反映を保留してよいか。
