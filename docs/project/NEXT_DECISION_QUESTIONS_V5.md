## 1. チュートリアル第1章

第一案は1-1〜1-8の8ステージ、全体中央値25分以内。

1. 1-1: 基本操作とレタスサラダ
2. 1-2: 注文票、時間、ゴミ箱、ダッシュ
3. 1-3: 食材・配達容器投げ
4. 1-4: 鍋と野菜スープ
5. 1-5: フライパン、焦げ、火災、消火器
6. 1-6: 現地提供、再利用皿、皿洗い
7. 1-7: 配達代行とバイク自前配達
8. 1-8: 動的厨房での総合試験

- 1-A. 8ステージ構成でよいか。
- 1-B. ダッシュを1-2、投げを1-3で教えてよいか。
- 1-C. 全8ステージ終了まで全モードをロックする従来案を維持するか。推奨は段階解放で、1-3後に初心者用マルチステージとロビー、1-7後に本店通常営業、1-8後に第2章を解放する。全8本を必修にする場合は、友人とすぐ遊びたい新規プレイヤーが約25分待つ点を許容する必要がある。
- 1-D. 経験者向けに短い技能試験を用意し、合格者は1-2〜1-7を飛ばせるようにするか。推奨は初期版では設けず、完了時間と離脱率を見て追加判断。
- 1-E. チュートリアルにも通常と同じ星0〜3と自己ベスト更新を残すか。推奨は残す。

## 2. 初期キャラクター

動物を約3分の2、人間を約3分の1とする第一案。

- 2-A. 初期解放キャラクターを12体、動物8体・人間4体としてよいか。
- 2-B. 動物種は、カピバラ、ヤギ、カエル、アホロートル、クマ、鳥、ネコ、イヌ等から選定する。最初の8種を次回まとめて決めるか。
- 2-C. 尻尾、耳、角、くちばしも顔・手足と同じキャラクター固有部品に含めてよいか。
- 2-D. 共通コック帽と衣装は全キャラクター同形状とし、色変更は外見カスタマイズで行う方針でよいか。

## 3. 共通配達容器

Aの角当て付き角形＋Bの透明蓋を採用方向とし、汁物も同じ容器を使う。

- 3-A. 組立中は蓋が開き、料理完成時に透明蓋が自動で閉まる仕様でよいか。
- 3-B. 汁物は液体物理を使わず、容器内の固定されたスープ面と揺れ演出だけで表現してよいか。
- 3-C. 未完成料理入り容器を投げられるかは操作試験で決めてよいか。完成済み容器は従来どおり投げられる。

## 4. 1-1レイアウト

10×8を維持し、中央3×2セルの作業島と下側の補助カウンターを追加した。

- 4-A. この密度で実装試作へ進めてよいか。
- 4-B. 1-1には穴、動く床、加熱器具を一切置かない方針でよいか。
