## 1. 店ランク

5段階より多くする方針は決定した。設備レベルは1〜5なので、店ランクは設備とは別の総合進行値として扱う。

- **A. 10段階:** 覚えやすく、序盤から終盤まで約10回の大きな昇格を作れる。推奨。
- **B. 15段階:** 報酬頻度は高いが、各ランクの違いが薄くなりやすい。
- **C. 20段階:** モバイルゲームらしい長期数値になるが、有限キャンペーンとの対応が複雑。

各店ランクは「累計ソロ星＋指定ソロ出張＋必要設備条件」で上昇し、最高ランクで最終大型出張営業を解放する。

- 1-A. **回答: 10段階。**
- 1-B. **回答: 当面は名称を付けず数字だけにする。**

## 2. ソロ常時オンライン

広告を必ず表示できる保証はなく、広告SDKが「在庫なし」を返す場合もある。その場合にプレイを止めないことを前提にする。

### 推奨方式

1. ログインと営業開始にはオンライン接続必須。
2. 営業開始時に、サーバーから一回限りの営業チケットを取得。
3. 営業途中で切断しても、その営業は最後まで続けられる。
4. 結果は「同期待ち」とし、再接続後に報酬を確定。
5. 同期待ちの間は、新しい報酬営業、日課、ランキングを開始できない。
6. 広告の在庫なし・読込失敗時は、広告なしで通常進行する。後払い広告は行わない。
7. 長期メンテナンス時に報酬なしの練習厨房を許可するかは別決定。

- 2-A. **回答: 営業チケット方式を採用する。**
- 2-B. **回答: サーバー障害中も報酬なしの練習厨房を許可する。**
- 2-C. **回答: 広告在庫なし・読込失敗時は広告なしで進める。**
