# COOKED OUT! 次期大枠仕様・回答用質問票 v1.5

- 更新日: 2026-09-11
- 状態: 回答済み。種類共通Lv、ランク別上限、Lv対象7種類、効果、初回付与、UIを決定。組立台と受渡し台を統合し、鍋・フライパンを熱源込みの設備へ変更
- 対象: 店ランク1〜10、設備台数、設備Lv1〜5
- 参照: [店ランク・設備進行案](../game-design/18_store_rank_and_equipment_progression.md)

## 1. 設備レベルの単位

- 1-A. 個体ごとではなく設備種類ごとにLvを持ち、所有する同種類設備すべてへ同じLvを適用してよいか。
- 1-B. 追加台数は一台ずつ購入するが、購入した設備は最初から現在の種類Lvを使ってよいか。
- 1-C. 設備の売却、Lvリセット、強化素材は初期版では設けず、コインだけで強化してよいか。

## 2. 店ランクの役割

- 2-A. 奇数ランク3・5・7・9でLv上限、通常営業Tier、厨房拡張を一段ずつ上げてよいか。
- 2-B. 偶数ランク2・4・6・8で同種類設備の購入上限を2・3・4・5台へ増やしてよいか。
- 2-C. 設備種類ごとにも固有台数上限を持たせ、実上限を店ランク上限との小さい方にしてよいか。
- 2-D. ランク10は新しい性能段階を追加せず、シーズン参加条件、専用バッジ、コイン・外見報酬を節目にしてよいか。

## 3. Lvを持つ設備

- 3-A. 初期のLv対象を、まな板、鍋用加熱台、フライパン用加熱台、洗い場、配送代行棚、バイク、消火器の7種類にしてよいか。
- 3-B. 食材箱、通常カウンター、組立台、受渡し台、提供口、ゴミ箱、皿置場、容器供給口、積込口はLvなしでよいか。
- 3-C. 鍋とフライパン本体は消耗品や個別Lvにせず、加熱台の購入時に一個付き、追加個数だけ購入する形でよいか。

## 4. Lv効果

- 4-A. まな板は切断時間、洗い場は洗浄時間、消火器は消火時間だけを短縮してよいか。
- 4-B. 鍋・フライパン加熱台は加熱時間短縮と焦げ猶予延長にしてよいか。
- 4-C. 配送代行棚はLv1の36秒からLv5の24秒まで3秒ずつ短縮してよいか。
- 4-D. バイクは最高速・加速・制動だけを最大20%強化し、積載数は全Lvで2個固定にしてよいか。
- 4-E. Lvで占有セル、入力方法、レシピ条件を変更しない形でよいか。

## 5. 初回無料付与と価格

- 5-A. 設備を出張営業で初めて学んだ時、Lv1を一台無料付与してよいか。
- 5-B. 第1章では1-1まな板、1-2鍋、1-3バイク、1-5フライパン、1-6消火器、1-7洗い場、1-8配送代行棚の順で本店設備をそろえてよいか。
- 5-C. 既存の450／750／1,100／1,500コインを、一台ではなく設備種類全体のLvアップ価格として試験してよいか。
- 5-D. 追加設備は種類別に300〜1,200コインの範囲で、通常営業2〜3回以内を基本に価格設定してよいか。

## 6. 設備・ランクUI

- 6-A. 設備カードに種類Lv、次Lv効果、所有台数／上限、価格をまとめてよいか。
- 6-B. 厨房内では設備個体ごとのLv数字を常時表示せず、見た目の段階差と準備画面で確認する形でよいか。
- 6-C. 店ランク画面には現在XP、次ランクまで、次のLv上限、台数上限、厨房拡張を表示してよいか。

## 7. 次の工程

- 7-A. 上記決定後、7設備それぞれの追加台数上限と追加購入価格を確定してよいか。
- 7-B. その後、通常営業Tier 1〜5の注文負荷と設備推奨値を再計算してよいか。

## 8. 回答結果

- 1-A〜1-C: すべて採用する。
- 2-A〜2-D: すべて採用する。
- 3-A、3-B: 大枠を採用する。ただし、組立台と受渡し台は別設備にせず、一種類の「組立・受渡し台」へ統合する。
- 3-C: 加熱台を独立購入品にしない。鍋とフライパンは、それぞれ専用熱源一台と一組で購入・配置する。Lvも加熱台ではなく「鍋」「フライパン」の種類Lvとして上げる。
- 4-A〜4-E: 名称変更後の鍋・フライパンを含め、すべて採用する。
- 5-A〜5-D: プレイテスト用初期値として採用する。価格は実測で調整可能とする。
- 6-A〜6-C: すべて採用する。
- 7-A、7-B: 続行する。結果は[店ランク・設備進行仕様](../game-design/18_store_rank_and_equipment_progression.md)へ追記した。
