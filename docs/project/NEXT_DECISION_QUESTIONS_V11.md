# COOKED OUT! 次期大枠仕様・回答用質問票 v1.1

- 更新日: 2026-09-11
- 状態: 方針変更により廃案。レート・リーグ・回数制限・練習区分を撤回し、v1.2の合計スコアランキングへ移行
- 対象: 4週間シーズンの実力レート
- 参照: [4週間シーズン・実力レート仕様案](../game-design/14_season_rating_system.md)

## 1. 解放と参加方式

- 1-A. レート戦は店ランク10で解放し、それ以前は週替わり厨房を練習・通常報酬用として遊べる形でよいか。
- 1-B. 毎週1厨房を追加し、公開済み4厨房はシーズン終了まで残して後から追いつけるようにしてよいか。
- 1-C. 練習は無制限、レート挑戦は各厨房10回・シーズン合計40回としてよいか。
- 1-D. 4厨房すべてで最低1回レート挑戦したプレイヤーを最終順位報酬の対象にしてよいか。

## 2. 人数別記録

- 2-A. 1人、2人、3人、4人でレートとランキングを完全に分けてよいか。
- 2-B. 2〜4人では同じ営業結果を参加者全員の該当人数レートへ反映してよいか。
- 2-C. シーズン報酬は四つのうち最高到達リーグ一つを基準に一回だけ与え、ソロだけでも全報酬種別へ到達可能にしてよいか。

## 3. レート計算

- 3-A. 初期レートを1,000としてよいか。
- 3-B. 厨房ごとに星1付近=1,000、星2付近=1,400、星3付近=1,800、上級目標=2,200等の基準点を持たせ、実スコアから走行実力レートを補間してよいか。
- 3-C. 通常は現在レートと走行実力レートの差の25%を反映し、一回の増減を±50に制限してよいか。
- 3-D. シーズン最初の5回だけ差の50%、±100まで反映して適正帯へ早く移してよいか。

## 4. リーグとリセット

- 4-A. 初期は固有名称を付けず、リーグ1〜7と数字・色・形のバッジで表示してよいか。
- 4-B. 次シーズンは、1,000を超えた分の50%を残すソフトリセットとし、開始上限を1,800にしてよいか。
- 4-C. シーズン最高到達リーグ、最終レート、国内・世界の最高順位をプロフィールへ恒久保存してよいか。
- 4-D. グローバル上位200、国内上位200、フレンド順位と、本人の順位・上位割合を表示してよいか。

## 5. 報酬と保護

- 5-A. 到達リーグ報酬は一度受け取れば降格しても失わず、最終順位報酬だけシーズン終了時レートで決めてよいか。
- 5-B. 報酬はコイン、称号、バッジ、プロフィール枠、性能差のない外見に限定してよいか。
- 5-C. 自分側の切断・退出は挑戦回数を消費し、サーバー障害時だけ返却する方針でよいか。

## 6. 保留中の日次・週次件数

- 6-A. レート戦自体に週上限があるため、通常のデイリー／ウィークリーは急いで固定せず、第1章と通常営業の実測後に決めてよいか。推奨はこの方針。
