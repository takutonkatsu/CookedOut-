## 1. 画像量産基準

- 1-A. 第5案の、正面を向いた大きな顔、単純な目鼻、大きな共通帽子というキャラクター方向でよいか。
- 1-B. 帽子は参考画像との類似に距離を取るため、膨らみ数、傾き、後頭部、帯位置を次の全身案で独自化してよいか。
- 1-C. 動物6・人間2の画像は比率確認用とし、初期正式版を12体・動物8・人間4で進めてよいか。
- 1-D. 料理画像は、同じ角形容器、上寄り視点、大きな食材、低い細部密度という第5案を基準にしてよいか。
- 1-E. 注文票では蓋を開くか反射を弱め、ゲーム内完成品では透明蓋を閉じる方式でよいか。
- 1-F. 以上を承認後、36料理を12種×3シートで量産してよいか。

## 2. 初期36料理

- 2-A. 初期正式リリース36系統、縦切り4・内部アルファ12・ベータ24の段階実装でよいか。
- 2-B. 36系統を「切る、土台組立、鍋一括、鍋土台、フライパン個別、フライパン合流、鍋＋フライパン、セット、注文分岐」の9文法へまとめてよいか。
- 2-C. 提案一覧から削除・追加したい料理はあるか。
- 2-D. 初期36では飲料を外し、すべて同じ配達容器で扱える食事へ絞ってよいか。
- 2-E. 一料理3〜5派生、一注文の部品数は通常4以下・最高5以下でよいか。

## 3. 出張営業

- 3-A. 初期正式版を全9章・54ステージとしてよいか。
- 3-B. 第1章8、第2〜8章各6、第9章4の配分でよいか。
- 3-C. 現地提供30・外部配達24を第一案としてよいか。
- 3-D. 固定26・動的20・背景移動8を第一案としてよいか。背景移動8は固定／動的の内数として扱う。
- 3-E. 第9章は新料理を出さず、既習料理とギミックだけの最終試験にしてよいか。

## 4. 通常営業

- 4-A. マルチと同じく、1-3星1後に本店通常営業も解放してよいか。最初はサラダと野菜スープだけを出す。
- 4-B. 営業開始前に、解放済み料理から1〜3系統を自分で選ぶ方式、ランダム候補3セットから選ぶ方式、完全ランダムのどれにするか。推奨はランダム候補3セット。
- 4-C. 新しい出張を1〜2、通常営業を2〜3、設備強化、章後半という反復でよいか。
- 4-D. 店ランク10では機能設備Lv5を上限とし、以後は外見、称号、スコア、ランキングを伸ばす方式でよいか。

## 5. 厨房操作

- 5-A. 右側を「取る／置く」「作業」「ダッシュ」「投げる」の四ボタンにしてよいか。
- 5-B. 切る・洗う・消火は押し続けで進み、連打も同じ上限速度で受け付ける方式でよいか。
- 5-C. 投げは溜めなしの固定弧とし、仲間・台・対応する鍋／フライパンへ弱く補正してよいか。
- 5-D. 対応食材を鍋・フライパンへ直接投げ入れられる仕様でよいか。
- 5-E. ダッシュ中も持ち物を落とさず、衝突時は短い減速だけにしてよいか。

## 6. チュートリアル1-4以降

- 6-A. 1-4ダッシュと注文順、1-5フライパン、1-6火災、1-7皿洗い、1-8配達代行＋動的厨房の順でよいか。
- 6-B. 1-3未完了プレイヤーはマルチ不可、1-3完了者は未習得ギミックのある先行ステージにも参加可能とし、開始前に30秒以内の実地ガイドを出してよいか。
- 6-C. チュートリアルにも星0〜3と人数別自己ベストを残してよいか。
