# COOKED OUT! 次期大枠仕様・回答用質問票 v1.3

- 更新日: 2026-09-11
- 状態: 回答済み。初期54ステージの常設ランキング、全条件固定、シーズン個人設備、スコア換算非表示を決定。協力記録名義とシーズン解放条件はv1.4で確認
- 対象: シーズン競技の個人設備と、誰でも遊べる常設ランキング
- 参照: [4週間シーズン・合計スコアランキング仕様案](../game-design/16_season_score_ranking_system.md)

## 1. 二種類のランキング

- 1-A. 「シーズン競技以外の誰でも遊べるランキング」は、初期54出張ステージそれぞれの常設ランキングという理解でよいか。
- 1-B. 常設ランキングは、該当ステージを一度でも正規プレイした時点から自動参加としてよいか。
- 1-C. ホスト招待で未解放ステージを先行プレイした場合も、その走行スコアを常設ランキングへ即時反映してよいか。
- 1-D. 常設ランキングはシーズンリセットなしで、ステージごとの歴代自己ベストを残してよいか。

## 2. 常設ランキングの公平条件

- 2-A. 出張ステージ既定の設備種類、台数、Lv、位置をすべて固定し、配置変更を認めない形を推奨するが、それでよいか。
- 2-B. 注文票順、発生時刻、タイマー、ギミック周期、配達先も人数別に固定してよいか。
- 2-C. 1〜4人ランキングを分け、協力得点を参加者全員へ保存してよいか。
- 2-D. 常設ランキングにはシーズン順位報酬を付けず、自己ベスト、順位、実績・バッジを主目的にしてよいか。

## 3. シーズン競技の個人設備

- 3-A. シーズン競技では、ホストが所有する設備種類・台数・Lvからロードアウトを作り、指定ソケットへ配置する形でよいか。
- 3-B. 料理成立に必要な最低設備は第1章で全員が一台以上入手する基本設備だけから選び、未所有設備の貸出しはしない形でよいか。
- 3-C. 所有設備が多くても、設置可能数はシーズン厨房のソケット数で自然に制限してよいか。
- 3-D. 2〜4人ではホスト設備を使い、ゲストは設備と配置を確認して準備完了する形でよいか。
- 3-E. シーズン中に設備を強化した場合、次の挑戦から新しいLvを使えるようにしてよいか。

## 4. 料理解放

- 4-A. 店ランク10でも出張進行によって未習得料理があり得る。シーズン競技では対象料理をその週だけ一時利用可能にし、通常営業への恒久解放はしない方式でよいか。
- 4-B. 一時利用料理は開始前に工程カードを表示し、初回だけ任意の確認画面を開けるようにしてよいか。

## 5. 表示と内部データ

決定済み: プレイヤーには競技スコアだけを表示し、「生スコア」という言葉や数値は見せない。不正検証、同点処理、調整のため、換算前スコアと内訳はサーバー内部にだけ保存する。

- 5-A. 人数別基準スコアの具体値と換算式も通常UIには表示せず、プレイヤーには同条件では同じ計算規則が適用されることだけを案内してよいか。

## 6. 次の設計順

- 6-A. 上記決定後、店ランク1〜10の具体的な機能解放、初期設備台数、鍋・フライパン・まな板等のLv1〜5効果を決めてよいか。
- 6-B. その設備表を使い、通常営業Tier 1〜5とシーズン競技の想定最大スコアを再計算してよいか。
