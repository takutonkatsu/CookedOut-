## 1. ランク10後も無限に遊べる仕組み

- 1-A. 店ランク10・設備Lv5を機能上の上限とし、設備能力を無限には上げない方針でよいか。
- 1-B. ランク10後もXPを加算し、仮称「名声レベル」を上限なく伸ばしてよいか。
- 1-C. ランク10後は追加1,000XPごとに名声を一段階上げ、250コインを与える初期値でよいか。
- 1-D. 名声5、10、25、50、100と以後50刻みに、性能差のない称号・プロフィール装飾等を置いてよいか。
- 1-E. 「名声レベル」という名称でよいか。名称を増やしたくなければ、店ランク10後は累計XPだけを表示する案もある。
- 1-F. 通常営業に選択可能な難度・報酬Tier 1〜5を置き、店ランク3、5、7、9で次Tierを解放してよいか。
- 1-G. 高Tierは推奨設備未満でも挑戦可能とし、詰まった場合は低Tierで稼いで設備を強化して再挑戦する形でよいか。
- 1-H. 9-4星1かつ店ランク10で、注文失効3件まで続く上級者向け「連続営業」を解放してよいか。

## 2. 周期的な遊び

- 2-A. デイリー2件、ウィークリー4件を初期値にしてよいか。
- 2-B. 同じ厨房、料理、注文列、配達先で競う「週替わり出張営業」を採用してよいか。通常営業は引き続きソロ専用とする。
- 2-C. 共通条件では設備レベルを指定値へ統一し、1〜4人を別ランキングにしてよいか。
- 2-D. シーズンを8週間とし、全8週のうち上位6週を集計する案でよいか。
- 2-E. 周期報酬は強さに影響させず、コイン、称号、バッジ、プロフィール枠、外見を中心にしてよいか。
- 2-F. ソロだけでも全報酬種別へ到達でき、協力プレイを長期進行の必須条件にしない方針を維持してよいか。

## 3. コイン収入と価格

- 3-A. 星2基本コインをTier 1から順に120、180、260、380、540としてよいか。
- 3-B. 星倍率を星0=0.25、星1=0.75、星2=1.00、星3=1.25、初回クリア加算を基本額の50%としてよいか。
- 3-C. 設備一台の強化価格をLv1→2で450、Lv2→3で750、Lv3→4で1,100、Lv4→5で1,500としてよいか。対応帯の星2営業約2.5〜2.9回分である。
- 3-D. 厨房拡張価格を順に1,100、2,000、3,200、4,500としてよいか。対応帯の星2営業約6〜9回分である。
- 3-E. 設備最大後のコイン消費先として、帽子・制服、バイク外見、厨房テーマ等を用意してよいか。

## 4. 自前配達と配送代行

- 4-A. 配送代行棚を初期1枠とし、棚へ置いてから30秒後に納品完了する初期値でよいか。
- 4-B. 自前配達は厨房を離れてから戻るまで平均20〜30秒を距離設計の基準にしてよいか。
- 4-C. 自前配達ボーナスを1人+50%、2人+30%、3人+20%、4人+15%から試験してよいか。
- 4-D. 完璧な自前中心運用と代行中心運用の最終スコア差を、各人数で±5%以内にすることを合格基準としてよいか。
- 4-E. 初期版では配達専用コンボを作らず、既存の注文順コンボだけにしてよいか。
