# COOKED OUT! 第1章＋通常営業 Core Alpha 計画 v0.1

- 更新日: 2026-09-11
- 状態: 直近の正式な制作方針。2週間の機能完成版と、その後の安定化完了版へ分割
- 対象: 出張営業第1章1-1〜1-8、通常営業の基本ループ、同時進行する全54出張ステージ設計

## 1. 到達点

次の大きな到達点を `Core Alpha` と呼ぶ。

> 初回起動から第1章1-1〜1-8を終え、本店の通常営業を解放し、献立選択、設備配置、調理、自前配達または配送代行、結果、報酬、設備強化、再挑戦までを、iPhone上で繰り返し遊べる。

これは機能の寄せ集めではなく、短い製品版一周である。第2章以降を量産する前に、料理、厨房、配達、動的厨房、成長、オンライン、セーブ、UI、分析の共通基盤を一度すべて通す。

「完璧」はバグが永久にゼロという意味ではなく、次を満たす意味とする。

- 仮ボタンや開発者操作なしで開始から結果まで進める
- プレイを止める既知の不具合がない
- 1〜4人で同じルールが成立する
- iPhone実機で文字、料理、対象輪郭、状態が読める
- 再起動、切断、リトライ、セーブ読込で進行を壊さない
- 数値と配置をコード変更なしで調整できる
- 必須ログが取得でき、難度と離脱箇所を検証できる

## 2. 二本立てで進める

```text
実装トラック                            企画トラック
第1章1-1〜1-8を製品化                  全54面を一枚企画カード化
        ↓                                      ↓
通常営業の一周を接続                    次章6面を詳細グリッド化
        ↓                                      ↓
オンライン・セーブ・実機QA             グレーボックス結果を後続へ反映
        └──────── 共通データ契約 ────────┘
```

両トラックは、グリッド寸法、設備ID、料理要求タグ、ギミックID、提供方式、人数別係数を共通の正本として使う。企画カードにしか存在しない例外仕様は作らない。

## 3. 実装トラック

### Gate 0 — 基準固定

- 1-1、カピバラ、P0厨房、料理3基準、HUDを実機画面で確認する
- 厨房の移動、対象選択、四行動、投擲、カメラの操作契約を固定する
- 共通キャラクター骨格と基本アニメーション9群を固定する
- ステージ、料理、設備、注文、星ラインをデータから読める状態にする

Gate 0を通るまで、残るキャラクターと料理の本番量産は行わない。

### Gate 1 — 第1章の機能完成

| 面 | 主な完成対象 |
|---|---|
| 1-1 | 移動、対象選択、取る／置く、切る、組立、提供 |
| 1-2 | 注文票、鍋、加熱タイマー、失効、廃棄 |
| 1-3 | 投擲、直接投入、バイク、短い街路、自前配達、マルチ解放 |
| 1-4 | ダッシュ、注文順コンボ、逆走コンベア |
| 1-5 | フライパン、個別加熱、焦げ予告 |
| 1-6 | 焦げ、火災、延焼、消火、復旧 |
| 1-7 | 現地提供、再利用皿、返却、継続入力の皿洗い |
| 1-8 | 配送代行、自前との選択、予告付き接続変化、章完了 |

初回の1-1〜1-3はソロ必修とする。1-3星1後はマルチを解放し、再プレイを含む1-1〜1-8を1〜4人で成立させる。未習得の後半面へゲスト参加できる既決定仕様も維持する。

### Gate 2 — オンライン協力

- まず1-1の2人で、移動、所持、設備、注文、投擲を同期する
- 次に1-3で厨房と配達の分離、1-8で動的厨房を同期する
- 2人安定後に3人、4人へ増やす
- ルームコード、準備完了、途中参加なし、60秒再接続、途中報酬条件を接続する
- 全8面で1〜4人別の星と常設ランキング用記録を生成できるようにする

オンラインを後続54面の完成後へ回さない。同期方式はギミックとステージデータの設計へ直接影響するためである。

### Gate 3 — 通常営業の基本ループ

Core Alphaへ含める通常営業は次の一周である。

1. 第1章星1完了で本店通常営業を解放
2. 習得済み料理だけから互換性のある3献立候補を生成
3. 難度Tierを選択
4. 必要設備の不足確認、ショップ購入、種類共通Lv強化
5. 推奨配置または3枠の配置プリセットを12×9厨房へ適用
6. 外部配達型の営業を開始
7. 注文ごとに自前配達か配送代行を選択
8. スコア、星、コイン、XP、自己ベストを保存
9. 設備を強化して再挑戦

Core Alphaでは、第1章で習得する3料理系統を中心に一周を完成させる。店ランク1〜10、設備Lv1〜5、Tier1〜5を扱えるデータ構造は作るが、後半料理、最終経済、ランク10到達速度までをこの時点で確定する必要はない。

街は一つの小型街区を1-3と通常営業で共用する。交差点一つ、分岐一つ、近・中距離の配達先、厨房への帰還路、ミニマップを先に完成させる。大規模な街や大量の建物外観は後続とする。

### Gate 4 — 製品品質の一周

- 初回起動、チュートリアル、解放、本店、営業、報酬、強化、再挑戦を連続で通す
- iPhone実機で30fps基準、発熱、親指操作、Safe Area、可読性を検証する
- 1〜4人の星1〜3分布、自前／代行差、厨房滞在率を計測する
- アプリ終了、通信瞬断、再接続、結果再送、セーブ移行を検証する
- EditMode、PlayMode、ネットワーク、データ検査、実機回帰テストを通す

このGateを通過した版を、最初のクローズドTestFlight候補とする。

## 4. このマイルストーンへ含めないもの

後で必要だが、Core Alphaの完成を妨げないよう次は分離する。

- 第2〜9章の本番3D化と全54面の実装
- 初期36料理すべての実装
- 残る全動物と全外見の量産
- 店ランク10後の4週シーズン競技
- 日次、週次、ログイン報酬、全常設ランキング画面
- 広告、広告削除、外見課金、ストア提出用商品
- 大規模な街、豊富な交通、天候、街別景観

ただし、後付けで作り直さないため、分析イベント、安定ID、サーバー権威境界、ランキング登録用走行ID、課金と広告を差し込める画面境界はCore Alphaから用意する。

## 5. 企画トラック — 全54出張ステージ

全54面は二段階で決める。

### 第1段階: 全54面の企画カード

全ステージについて、先に次だけを確定する。

- 面の一文コンセプトとプレイヤーへ起こしたい混乱
- 料理、提供方式、固定／動的／背景移動
- S／M／L／Splitの設計帯
- 主要ギミック一つ、補助ギミック最大一つ
- 設備数、作業区画、受渡し方法の概略
- 人数別に必要となる協力行動
- 前の面から何を復習し、何を新しく学ぶか
- 美術テーマ、必要な背景・プロップ・SE

既存の54面マスター表を、この企画カード形式へ拡張する。ここでは座標と秒数を最終固定しない。

### 第2段階: 章単位の詳細配置

厳密な設備座標、通路幅、ギミック周期、注文列、星ラインは、実装直前の章だけを詳細化する。

1. 第1章8面を実装で確定
2. 並行して第2章6面の2〜3配置候補を作る
3. 第1章の実測後に第2章を確定し、第3章候補へ進む
4. 以降も一章ずつ同じ手順を繰り返す

各面の確定手順は、`企画カード → 配置案2〜3個 → 方向選択 → グレーボックス → 1／2／4人テスト → 座標と周期固定 → 美術化` とする。

全54面の座標を先に固定しない。第1章で対象選択距離、通路幅、投擲距離、オンライン同期、ギミック予告時間が変わった場合の大量修正を防ぐためである。

## 6. 並行作業の同期点

| 実装側で確定したもの | 企画側へ反映するもの |
|---|---|
| 対象選択距離、キャラクター半径 | 最小通路幅、設備前の空きセル |
| 投擲距離、弧、直接投入判定 | 受渡し溝・壁の幅 |
| カメラ範囲とHUD占有 | S／M／L／Splitの実用上限 |
| 鍋・フライパンの処理量 | 人数別の設備数と料理混在数 |
| 動的床の予告・同期 | ギミック周期と安全地帯 |
| 自前／代行の実測時間 | 配達路長、得点、注文密度 |
| 実機の発熱と描画負荷 | 動物数、背景演出、VFX上限 |

毎週または各Gate終了時にこの表を更新し、次章の配置案へ反映する。

## 7. 完了判定

Core Alpha完了には、最低でも次を満たす。

- 1-1〜1-8を初回ソロで一本道完走できる
- マルチ解放後、全8面を1〜4人で再プレイできる
- 各面で新要素を長文説明なしに理解できる
- 通常営業を10回連続で遊び、献立、配置、報酬、設備強化、セーブが破綻しない
- 自前中心と代行中心の理想スコア差が初期目標の±5%以内
- 星1は初見層、星3は熟練層という分布を実測で確認できる
- 全必須分析イベントとクラッシュ・通信ログが確認できる
- iPhone実機の基準端末で重大なフレーム落ち、発熱、UI欠けがない
- 後続の料理一つ、ギミック一つ、ステージ一つをデータ追加中心で作れる

## 8. 期間の目安

既存実装を起点に、企画責任者が週ごとに実機確認できる場合の粗い目安は次の通り。

| 作業 | 目安 | 並行可否 |
|---|---:|---|
| 実機基準、共通操作・アート固定 | 2〜4週 | 全54面の企画カードと並行 |
| 1-6〜1-8と第1章統合 | 3〜6週 | 第2章配置候補と並行 |
| 通常営業の基本一周 | 4〜7週 | 第2〜3章の企画詳細化と並行 |
| 2〜4人オンライン、切断、クラウド | 6〜10週 | 上記と技術的に一部並行 |
| 実機調整、回帰、TestFlight候補 | 3〜5週 | 美術・音の承認と並行 |

当初の全完了条件を満たす安定化版は、単純合算ではなく並行しても現在から約4〜6か月を第一目安とする。一方、ソロ第1章と通常営業一周を優先した`Core Alpha Feature Complete`は2026-09-25までの2週間目標へ変更する。2週間版の対象、凍結事項、日別計画は[Core Alpha 2週間スプリント案](CORE_ALPHA_TWO_WEEK_SPRINT.md)を正とする。
