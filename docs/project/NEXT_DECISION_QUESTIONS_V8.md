## 1. ステージマップ構造

完全な一本道では、前ステージをすべて星1で通るだけで累計星が自動的に貯まり、累計星ゲートの意味が薄くなる。

- 1-A. 第1章はチュートリアルなので1-1〜1-8の一本道を維持してよいか。
- 1-B. 第2〜8章は `x-1 → x-2 → x-3／x-4の分岐 → x-5 → x-6` とし、x-3とx-4は好きな順で攻略できる形にしてよいか。
- 1-C. 章最終x-6は、x-5星1に加えて、その章内で合計7星を得ると解放する方式でよいか。6ステージ中x-6前に触れる5ステージをすべて星1なら5星なので、好きな2星分だけ評価更新が必要になる。
- 1-D. 初心者が星1中心でも詰まりすぎないよう、章内7星が難しい場合は通常営業を2回完了すると一時的に必要値を6星へ下げる救済を入れるか。推奨は入れず、星2を取りやすい序盤ステージを必ず用意する方式。

## 2. 店ランクの基本構造

- 2-A. 店ランク1は第1章完了・通常営業解放時とし、店ランク10は9-4星1・エンディング時にする現在案でよいか。
- 2-B. 店ランク2〜9は、指定章の最終ステージ星1、累計ソロ星、通常営業経験値の三条件を基本にしてよいか。
- 2-C. 累計星はソロ出張営業の星だけを数え、協力星と通常営業評価は含めない方式でよいか。
- 2-D. 一度上がった店ランクはシーズンやログイン切れで下がらない恒久進行でよいか。

## 3. 累計ソロ星ライン第一案

全54ステージで最大162星。最終9-4の前には53ステージ・最大159星が存在する。以下は、章が進むほど星2更新を少し要求する案。

| 店ランク | 指定条件 | 累計ソロ星案 |
|---:|---|---:|
| 1 | 1-8星1 | 8 |
| 2 | 2-6星1 | 17 |
| 3 | 3-6星1 | 28 |
| 4 | 4-6星1 | 41 |
| 5 | 5-6星1 | 56 |
| 6 | 6-6星1 | 73 |
| 7 | 7-6星1 | 92 |
| 8 | 8-6星1 | 113 |
| 9 | 9-3星1 | 132 |
| 10 | 9-4星1 | 133 |

- 3-A. この累計星曲線を基準に試算してよいか。
- 3-B. ランク9の132星は、9-3までの最大156星に対して約85%であり、終盤でかなり星2・3更新が必要になる。最終大型出張を初心者にも開きやすくするなら120前後へ下げるが、どちらがよいか。推奨は120。
- 3-C. 店ランク条件を満たさなくても次の通常出張ステージは星1で進め、店ランクは本店設備と最終大型出張の解放にだけ影響させてよいか。これにより稼ぎ不足でキャンペーン途中が完全停止しにくくなる。

## 4. 店ランクと設備上限

- 4-A. 機能設備の上限Lv5は、店ランク1〜2でLv1、3〜4でLv2、5〜6でLv3、7〜8でLv4、9〜10でLv5としてよいか。
- 4-B. 厨房の床面積・ソケット拡張は、店ランク3、5、7、9の4回にしてよいか。
- 4-C. 配置プリセット枠は店ランク1で1枠、ランク4で2枠、ランク7で3枠へ増やしてよいか。
- 4-D. 通常営業の献立候補構成は、ランク1〜3で単一料理3候補、4〜7で単一1・同文法1・複合1、8〜10で同文法1・複合2の決定済み構造を使う。

## 5. 次の数値設計

- 5-A. 上記確定後、通常営業1回の平均収入と設備Lv1〜5の価格を「標準的な強化1回につき通常営業2〜3回」で逆算してよいか。
- 5-B. その次に、自前配達と配達代行の時間・得点をシミュレーションし、54ステージの人数別星ラインへ進んでよいか。
