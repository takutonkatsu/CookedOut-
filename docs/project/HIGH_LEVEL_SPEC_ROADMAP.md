## 状態の意味

- **決定**: 現時点の基本方針
- **仮決定**: 有力案。相談または試作で確定する
- **未決定**: 企画判断が必要
- **実装決定**: 実装・プレイテストの結果で数値や細部を決める
- **保留**: 事業条件や技術条件が揃ってから決める
- **不採用**: 検討したが、現行仕様には入れない

## 3. 料理システム

| 論点 | 状態 | 現在の方針 |
|---|---|---|
| 操作 | 決定 | 左スティック＋取る／置く・作業・ダッシュ・投げる。連続移動、一人一持ち物、前方自動対象、継続作業、固定弧投擲、対応器具への投げ入れをOvercooked型の入力文法へそろえる |
| 難しさ | 決定 | 精密操作ではなく、マルチタスク、タイマー、設備競合、受け渡し、優先順位で作る |
| 基本工程 | 決定 | 取る → 必要なら切る → 組み合わせる／器具へ入れる → 必要なら加熱 → 容器へ移す → 提供・配達 |
| 工程系統 | 仮決定 | 非加熱組立、部品合流、鍋バッチ、フライパン個別加熱、鍋＋フライパン合流を基本語彙とする |
| ピザ | 決定 | 初期料理・専門業態の両方から廃止 |
| 最初の料理 | 決定 | 切って組み合わせるサラダ系 |
| 初期料理一覧 | 決定 | 初期正式リリース36系統を目標とする。縦切り4、内部アルファ12、ベータ24と段階実装し、専用器具を増やさず9工程文法で構成 |
| 一営業の料理数 | 決定 | 通常は1系統・3〜5注文派生。導入は2〜3派生、復習は2系統・合計4〜6派生、章最終は最大3系統 |
| 料理の更新追加 | 決定 | 初期36系統以降も料理・派生をデータ駆動で追加。更新数は運営実績から決める |
| 加熱器具 | 決定 | 原則、鍋とフライパンだけ |
| 外部配達型の容器 | 決定 | 四隅に角当てがある深い角形の共通容器一種類。完成後も中身が見える透明蓋を備え、汁物にも同じ外形を使う。皿洗いなし |
| 現地提供型の皿洗い | 決定 | 全ステージ共通ではなく、選ばれた現地提供型ステージのギミック。継続アクション式 |
| 食材・容器投げ | 決定 | 食材と共通配達容器を投げられる。清潔・汚れ・料理入りを問わず皿は投げられない |
| 食材の組合せ | 決定 | 生・切り済みは単体保管可。最終組立は皿／配達容器上。鍋・フライパン内合流はレシピ指定時のみ |
| 焦げ・火災 | 決定 | 鍋・フライパンの放置で焦げ、火災へ進む。短時間で復旧可能 |
| 誤レシピ | 決定 | 誤料理は成立し、提供不可。ゴミ箱へ捨てて作り直す |

## 5. 人数と協力

| 論点 | 状態 | 現在の方針 |
|---|---|---|
| 対応人数 | 決定 | 1〜4人 |
| 固定職・能力差 | 決定 | なし。役割はいつでも交代可能 |
| 一〜二人 | 決定 | 共同調理、短い配達、厨房への再合流を繰り返す |
| 三〜四人 | 仮決定 | 厨房へ二人以上残しやすい仕事量にする。役割名は仕様ではなく説明用 |
| ソロ補助 | 決定 | 自動調理や注文予約は使わず、人数別の注文数・発生間隔・タイマー・距離で調整 |
| 協力評価 | 決定 | 原則として営業結果のスコアだけ。受け渡し回数などの個人査定はしない |
| クイック合図 | 未決定 | ボイスなしで「配達へ行く」「戻る」「助けて」を送る定型合図。MVP採否を相談 |

用語上の「物流」は、食材・料理・容器を厨房内外へ運ぶ仕事の総称。「遊撃」は、焦げ対応や不足工程をその場で補う固定担当なしの役割を意味する。どちらも固定職名ではなく、仕様書の説明語に限定する。

| 配達中の仲間 | 仮決定 | 顔アイコンと状態を常時表示。帰還進行バーは不採用。方向・現在地は未決定 |
| ノンバーバル性 | 決定 | 色だけでなく形、動き、アイコン、音で伝える |
| 厨房HUD配置 | 決定 | 左下スティック、右下に取る／置く・作業・投げる・ダッシュ、左上時計、上中央注文票最大5枚、右上スコア。中央は空け、状態は対象物付近へ表示 |
| 配達HUD | 決定 | 右上に簡易ミニマップを置き、道路、現在地、厨房、配達先、配達中の仲間を表示。方向表示と道路上目印も併用 |
| 本店・結果UI | 決定 | 本店は左縦ナビ。マルチはステージ選択後に選ぶ。結果は星／完走、スコア、自己ベスト・順位、報酬、次操作の順 |
| スコア表記 | 決定 | 常設・シーズンとも画面では単に「スコア」と表示し、換算・基準値・生スコアを案内しない |

## 9. マルチプレイと製品

| 論点 | 状態 | 現在の方針 |
|---|---|---|
| オンライン協力 | 決定 | 対応する |
| ローカル協力 | 決定 | 対応しない |
| 野良マッチ | 決定 | 対応しない。フレンド招待・ルームコード方式 |
| 途中参加 | 決定 | 営業中の新規参加なし。ロビーでのみメンバー変更 |
| 任意途中退出 | 仮決定 | 通常操作としては設けない。ただし切断・クラッシュ処理は必須 |
| 切断・再接続 | 決定 | 営業続行、持ち物保持、配達中は安全停止、AIなし、猶予60秒。参加50%以上で未帰還なら星・固有報酬と50%通貨、ランキング無効 |
| 初期プラットフォーム | 決定 | iOSのみ、横持ち |
| Android | 保留 | 初期対象外。ただし個人情報公開はAndroid固有の問題ではない |
| 配信価格 | 決定 | 無料ダウンロード |
| 広告・課金 | 決定 | 全編無料＋広告＋外見課金＋広告削除。強制広告は最大3営業に1回を試験。通常コイン販売と初期ステージ課金は不採用 |
| オフライン | 決定 | 営業開始時はオンライン必須。営業チケット取得後の瞬断では続行し、結果を同期待ちにする。障害時は報酬なしの練習厨房を提供。広告在庫なしは広告なしで進行 |
| 年齢対象 | 決定 | 家族で遊べる全年齢相当を目標にするが、初期版はKids Categoryへ登録しない |

## 10. アート、物語、音

| 論点 | 状態 | 現在の方針 |
|---|---|---|
| アート | 決定 | 明るく読みやすいデフォルメ3D、コミカルな演出 |
| キャラクター | 決定 | 初期12体はカピバラ、カエル、アホロートル、ヤギ、カワウソ、カメレオン、タヌキ、ウサギ、ブタ、ニワトリ、ペンギン、ワニ。約2頭身、共通帽子・制服、能力差なし |
| 物語量 | 決定 | 長い物語・会話は作らず、章立てと短い導入演出で進行を示す |

| 音 | 仮決定 | 許諾を確認した素材を使用し、重要状態を聞き分け可能にする |
| 音楽変化 | 仮決定 | 残り30秒から曲を切り替える、または緊迫レイヤーを追加 |

## 11. 技術・運営の大枠

| 論点 | 状態 | 現在の方針 |
|---|---|---|
| アップデート拡張 | 決定 | マップ、ステージ、料理、ギミック、星ラインをデータ駆動化し、セーブ移行を用意 |

| 実装開始 | 決定 | Unity 6.3 LTS＋URPを正式採用し、別タスクでグレーボックス縦切りから開始。技術選定根拠はADRへ記録 |

## 12. 次に決める順番
