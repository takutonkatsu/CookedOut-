## 1. 通常営業の3献立候補

- 1-A. 料理と厨房の互換性は「料理要求タグ」と「厨房能力タグ」で自動判定し、作れない献立を候補に出さない方式でよいか。
- 1-B. 献立選択後は、必要設備の推奨配置を一括適用できるようにし、そのまま開始するか、プレイヤーがソケット内で調整するか選べる方式でよいか。
- 1-C. 営業開始後は料理に合わせて壁・厨房サイズ・ソケット位置を変えず、設備ロードアウトだけを営業前に変更する方式でよいか。
- 1-D. 3候補の内訳を、序盤は「単一料理3候補」、中盤は「単一1・同文法セット1・複合セット1」、終盤は「同文法1・複合2」と段階変化させてよいか。
- 1-E. 気に入った設備配置を3枠まで保存し、互換性がある献立で呼び出せるようにしてよいか。

## 2. 初期12キャラクター

すべて動物、約2頭身、共通帽子・制服、能力差なしは決定済み。

- 2-A. 初期候補を、カピバラ、カエル、アホロートル、ヤギ、カワウソ、カメレオン、タヌキ、ウサギ、ブタ、ニワトリ、ペンギン、ワニの12体として画像比較を始めてよいか。
- 2-B. 哺乳類7、鳥類2、爬虫類2、両生類1程度の偏りは許容するか。それとも分類をより均等にするか。
- 2-C. 外見課金は新しい動物を売るより、まず共通帽子・制服の外見セットを販売し、無料キャラクター間の選択肢を狭めない方針でよいか。

## 3. 出張営業ギミック

- 3-A. 調査した45タグを、初期、限定、拡張、不採用へ分けた現行計画でよいか。
- 3-B. 初期54ステージでは8共通基盤へ集約し、一ステージの原則を主要ギミック1＋補助最大1としてよいか。
- 3-C. 第6章の回転は厨房全体ではなく、小さな作業島が予告後に90度回転する限定仕様でよいか。
- 3-D. 落下・水没は少数ステージだけにし、約5秒で復帰、重要な料理は回収箱へ戻す方式でよいか。
- 3-E. ポータル、強制役割交換、暗闇、Horde防衛、ふいご、薪かまどは初期版から外してよいか。
