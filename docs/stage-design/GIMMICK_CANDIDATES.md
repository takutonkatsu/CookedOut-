## 4. 第一候補G01＋G02: 固定厨房でも分担を選べる

### 最小の構成案

- 原料箱を一方、提供口を反対側へ固定する。
- 中央の作業台を双方から触れる受渡し位置にし、周囲には歩いて回れる道を残す。
- 両側に小型設備を載せ替えられる空き作業台と、料理を一時的に置く面を用意する。
- 新しい受渡しボタンは使わず、片方が置き、もう片方が取る。
- 小型設備自体は投げられないため、移設は歩いて運ぶ。料理・器具・皿の投擲可否は現行仕様に従う。

### 二つの回し方

原料側にまな板を寄せ、切り物だけ渡せば往復を減らせる。一方、仕上げ側へまな板とコンロを寄せ、原料をまとめて渡す運用も考えられる。固定原料箱・提供口の距離と置場の使い方が残るので、単純に全設備を中央へ集めるだけにしない。

1-4では「ソロ切替による担当分け」の補助として使う候補。1-6では料理二系統と発送口があるため、どの設備を寄せるかという選択へ発展させる候補。いずれも配置変更しない攻略を許し、設備移動回数をクリア条件にしない。

## 5. 最初に仕様を相談する動的候補G03: 往復する空き作業台

### 基本形の提案

1. 固定された二つの作業区の間を、一つの短い作業台が自動往復する。初回は一つの機構だけ。
2. 「左で停車 → 移動予告 → 右へ移動 → 右で停車 → 移動予告 → 左へ移動」を繰り返す。レバーや呼出操作は要らない。
3. 人は台に乗れず、物だけを運ぶ案を第一候補にする。人の移動を扱うG04と役割を分ける。
4. 上面は通常の空き作業台として扱い、食材、皿・配達容器、取り外せる器具、可搬設備を置ける候補。オーブン・フライヤー本体や原料箱は載せ替えない。
5. 台の移動が物の所有や内容物を変更することはなく、置かれた物をそのまま運ぶ。物が台端から勝手に滑り落ちる挙動は付けない案。
6. 停車中は隣接する床から通常の取る／置く・作業ができる。移動中は台上の物を取る・置く・投げ入れる・手作業する対象から外す案。出発の直前までに何を載せるかを選ぶ。
7. 一便逃した物は次の往復まで台上に残る。完成料理・食材を自動廃棄せず、鍋等も生成・複製しない。

### 作業台上の設備は動作するか

ここは採用時に必ず相談する。第一候補は、設置されたコンロやミキサーは台が動いても動作を続ける。人が設備一式を手に持つ時の停止ルールとは別の状態であり、共通仕様への追加定義が必要となる。

これにより「食材を運ぶ」「完成料理を運ぶ」「コンロを載せて次の受取側で仕上げる」という使い方が生まれる。ただし移動中に触れないため、完成直前の鍋を乗せたまま出すと焦げるリスクがある。既定Lv3の加熱・焦げ時間を変えず、安全に置けるタイミングが存在する停車・移動周期を後で検証する。初見で避けられない発火になるなら、この候補は成立しない。

比較対象は「停車中だけ機械が動作する」方式。タイマー管理は楽になるが、自動停止という新しい例外を覚える必要があり、加熱しながら物流を進める面白さは減る。現段階でどちらも確定しない。

### 導入面の形と役割

最初は両作業区を結ぶ徒歩経路も残す。台に乗せ損ねても歩いて回収でき、台を使うと往復を節約できる。台がいない間は双方に材料と調理作業が残る配置にする。全面を隔離して台待ちしかできない状態は初回導入では使わない。

3-6は新料理がないため、動的厨房の導入先として比較可能。ただしハンバーグ2品・パスタ・ポタージュの四注文候補があるため、料理負荷を確認してから選ぶ。5-6も新料理なしだが固定フライヤーが主役なので、可搬熱源より、材料・かご・完成品の運搬が主になる。同じ仕掛けでも面の役割を変えられる。

今回の最初の相談点は、この「人は乗らないが、可搬設備も載せられる往復台」という基本形。運転継続、速度、接触判定、割当面は次の論点として残す。

## 6. 面の役割と組み合わせる一次案

「面白いギミックを先に各章へ六つずつ割り振る」方法では、初出料理が多い本編で学習が重なりやすい。既定献立を見て、次の四つの役割から面ごとに主役を選ぶ案。

| 面の役割 | 新しいものの扱い | 該当候補と具体例 |
|---|---|---|
| 料理・器具を覚える | 盤面は短い動線と既習の配置文法 | 1-3フライパン、1-5鍋、3-1ミキサー、5-1フライヤー、7-1オーブン、8-3ピザ、8-5餃子 |
| 分担・配置を工夫する | 新料理があっても、操作を増やさず既習工程の分担で作る | 1-4の受渡し、1-6の設備寄せ、2-6の米と具の受渡し、7-4の仕上げ場所 |
| ギミックを覚える | 新操作・新器具と重ねず、既習料理で安全な基本形を出す候補 | 3-6の往復台、5-6の搬送。どちらも注文・設備負荷を先に確認 |
| 既習ギミックを使いこなす | 経路・距離・送り物・担当を変えて応用。新料理時は仕掛けを既習にする | 4-5、4-6、6-2、7-3、8-4等を比較。割当未定 |

全48面の元の仮役割表へ、この四役割とG番号を順次追記する。全章で同じ順番や面数比に固定しない。新料理なしの2面だけに全ギミック導入を詰めることも避ける。静的配置の発見、同じ仕組みの段階的な利用、料理の新規負荷を個別に評価する。

第1章のA案では、動的ギミックをまだ必修にせずG01・G02の軽い配置工夫を中心にするのを推奨。第2章以降にG03〜G09の採否・導入面を相談する。皿洗いも第1章外の通常の本編面で導入する候補であり、別必修チュートリアルを作らない。

8-6は既定の肉餃子・野菜餃子による最終大型出張を維持。既習の仕掛けと大きな会場表現で締める候補で、新機構の初登場や全器具の強制登場を必要条件にしない。Sは本編で経験した技術を受渡し・配置で深める応用役とする。

## 7. 今回は中心候補から外しておくもの

- レバー・圧力板専任: 固定待機や他人の都合だけで仕事が止まるため、今回の主役にしない。
- 風、滑り、飛来物、火災床: 基本の物流が成立した後の比較候補。精密入力と予告理解の負荷があるため、同時採用は提案しない。
- 全面回転・大崩落: 置き場や操作方向を覚え直す負荷が大きい。必要なら後で限定した変形として比較する。
- 燃料補給や専用調理器具: 確定料理に工程追加を要求するため今回の候補には入れない。

永久不採用の決定ではない。まずG01〜G09から本作に合う遊びを選び、少数ずつ挙動を詰める。
