# 地上中心の出張ステージで変化を作る案

- 日付: 2026-09-16
- 状態: 比較提案。地上限定、空・川の不採用、ギミック数、章・面への割当は未決定。
- ユーザーの相談: 空や川を作る制作負担が気になる。普通の地上店舗だけでも飽きずに続けられるか、飽きにくい構成を考えたい。
- 境界: 本編48面とSのステージ設計のみ。料理・通常営業・経済・保存・共通操作の変更、新モード、実装、画像生成は行わない。

> 最新相談（2026-09-16）: 厨房の仕掛けを「現実にぎりぎりありそうなもの」に寄せる方向を§9で評価。世界観・採用範囲の確定ではない。

## 1. 見立て

地上中心でも多様な出張ステージを作れると考える。ただし「同じ厨房で、料理と壁紙だけ変える」構成で48面を維持できるという保証ではない。必要なのは、次の面で作業の進め方・人の動き・受渡しが変わり、上達も感じられること。

空・川の採用を継続性の必須条件にせず、まず固定地形の地上厨房で変化を作る方針を比較案として推奨する。プレイ継続を保証する仕組みはなく、見た目の差・新料理・報酬だけで飽きを解消したと判断しない。

## 2. 景観と動的厨房の制作負担は分ける

以下は設計上の追加作業の比較であり、コード・素材の監査や工数見積りを実施したものではない。

| 構成 | 必要になり得る主な作業 |
|---|---|
| 地上店舗・床は固定 | 床壁・小物・照明の制作、配置、カメラの読みやすさ、人数別動線調整 |
| 川辺・床は固定 | 上記に水辺背景・水面表現など。川に落ちる仕様は必須ではない |
| 空が見える会場・床は固定 | 上記に空・遠景・会場外観など。飛行演出と実際の当たり判定の移動は分離可能 |
| いかだ接岸・動く厨房 | 移動と接続、物・設備の追従、通行中の切離し、復旧、同期、人数別成立などの追加検証 |

屋上や川辺の固定会場なら、景観変化と動く足場を分けて検討できる。新しいアートや演出にも負担はあるので、無料・ほぼ作業なしとは扱わない。地上でも、複雑な群衆や可動設備を多数入れれば検証負担は増える。

## 3. 地上でも変えられる「仕事の形」

大がかりな新機構を前提にせず、既存の台・固定設備・可搬設備・原料箱・提供口と歩行経路で比較する。

| 盤面の型（仮） | 同じ料理でも変わる行動 | 初心者・人数別の注意 |
|---|---|---|
| 一室で自由に応援できる厨房 | 手が空いた人が隣の工程へ入る | 混雑しない作業口を用意し、誰かが全工程を独占しないかを見る |
| 下処理と加熱を台で緩く分けた厨房 | 切った材料を次の人へ渡して流す | 完全隔離を必須にせず、ソロ二キャラでも回せる |
| 二つの調理区から仕上げ台へ集める厨房 | 別々に作り、完成時に合流する | 加熱済み部品は既定の器具・容器で扱い、裸の中身運搬を新設しない |
| 固定大型設備を中心に小型設備を寄せられる厨房 | どこで下処理すると運搬が減るかを試せる | 初期配置でも成立。開幕の設備引越しを必須にしない |
| 発送準備を厨房の端へ集めた外部型拠点 | 料理を送り出し、出発前後に厨房担当を引き継ぐ | 自配達・代行とも維持。厨房側と配送側が孤立しないか確認 |

距離を長くするだけ・通路を狭くするだけでは作業時間や接触が増えるだけになりやすい。各面について「誰が何を渡すか」「どこで作業をつなぐか」が前面とどう違うかを先に書く。

## 4. 地上のまま景観を変える候補

小さな店舗、商店街の店、公園の仮設屋台、催事場、学校や地域のイベント会場、港の陸上会場など。普通の店舗内だけに限定するか、地上の屋外会場まで含めるかはユーザー未決定。

同じ床・壁・カウンター部材を使い、看板・テント・装飾・照明・背景客などを差し替える比較案。全会場を専用の建物・専用厨房として制作する必要条件にはしない。ただし料理・重要設備の識別やカメラを装飾で妨げない。

これらは章割当ではない。第1章A案の現地／外部面、空中へ配達を無理に持ち込まない既定も変更しない。

## 5. ギミックをどの程度入れるか

全48面に必要な種類数を机上で先に確定するより、比較設計を次の単位で始める提案。

- 追加ギミックなしでも料理・分担の変化が見える面。
- 分かりやすい小さなギミック一つが主役の面。
- 慣れた仕掛けを違う位置・対象・動線で使う面。
- 必要な場合だけ、既習の仕掛けを組み合わせる応用面。

「普段は追加なし〜主役一つから検討する」を出発点として提案するが、採用上限ではない。単体の対処法を何通りも要求するS-D003の旧条件は復活させない。全体として種類を揃えるS-D004とも両立する。

カラスなどは一つの機構を複数面で使える候補。ただし未承認であり、盗難や待ち時間の機構ばかりを積まない。ギミック数を増やす目的で新料理の多い面へ追加しない。

## 6. 飽きにくさを作るのは「新規性」と「上達の実感」の両方

提案する評価軸:

1. 前の面と違う動き・受渡し・完成の仕方が一つ見える。
2. 前に覚えた料理工程が役立つ。新しいことを覚えるだけの連続にしない。
3. 新しい場所・依頼の雰囲気で「別の出張へ来た」と感じられる。
4. 一回目でも協力して完成でき、再挑戦では自然に手際が良くなる。

原則として各面に「この面ならでは」を一文で書く比較方法を提案する。新システムを毎面一つ入れる意味ではない。新器具の学習自体が面の役割なら、追加の障害物を要求しない。

現行48面のうち46面に初出料理がある点に注意する。料理に慣れてから応用、という六面の固定テンプレートを全章へ押し込まず、既定献立の共通工程・派生の負荷を見て配置する。献立・順序を変える必要が生じたら申し送りに回す。

星3・Sは既定の任意目標として活かせるが、報酬や再挑戦だけで基本営業の単調さを解消できるとは考えない。デイリー、週次、新しい成長・収集・報酬・注文イベントなどの範囲外システムを今回追加しない。

## 7. 最初に比較する候補（未実施）

まず同じ地上用部材を想定し、「一室で応援」「工程間の受渡し」「発送の引継ぎ」の異なる仕事の形を、三つの代表配置として比較する提案。料理は対応する確定献立を使い、既定の提供方式に従う。

最初から空・川・全面可動厨房を作る前提にせず、この違いだけで遊び分けを感じるか確認する。足りなければ小さなギミックを加え、その効果を比較する。実装・画像生成・プロトタイプ制作は今は行わず、ユーザーと一面ずつ相談する。

検証時はクリア率だけでなく、「前の面と何が違ったか説明できるか」「手伝う場面があったか」「初心者が置いていかれないか」「次の面へ進みたいか」を確認する。ソロ・2〜4人別の成立も必要で、48面全体の継続性を代表三面だけで保証しない。

## 8. 決定しない事項と申し送り

- 空・川の永久不採用、全章を地上へ変更することは決定しない。
- ギミック総数・上限、章の景観、盤面、注文条件・秒数は確定しない。
- 新機構・共通仕様・料理変更は今の提案では要求しない。
- 制作負担への配慮と地上中心の比較案を、元タスクへの未送信メモに残す。工数の確定見積りとして扱わない。

## 9. 現実にぎりぎりありそうな厨房へ寄せる案

### 評価

料理・工程・配達を中心にする検討方向と相性がよいと考える。採用基準の提案は「仕組みや原因は現実に説明できる。大きさ・速度・反応・演出はコミカルに誇張してよい」。厳密な業務・衛生・物理シミュレーションを作る意味にはしない。

説明なしで用途を想像しやすい道具・現象を使えば、ギミック理解の負担を抑えられる可能性がある。ただし実際の分かりやすさや楽しさ、制作費は未検証。現実的な設備でも可動物・追従・同期は別途必要になる。

### この基準で残せる候補（採用未定）

| 候補 | 一文のルール・用途 | 位置づけ |
|---|---|---|
| 料理・物資用コンベア | 置いた物を別の場所へ運ぶ | 搬送。家庭的な小店すべてへ置かず、設備のある会場で比較 |
| 小型の料理用リフト | 上下の調理区へ物を運ぶ | 搬送。人が乗る昇降床とは区別し、新調理工程は増やさない |
| 配膳ワゴン | 決まった場所を回り、料理の受渡し位置が変わる | 現地提供・搬送。料理を受理する時点などは採用後に相談 |
| 開くと通路へ張り出す扉 | 扉が開いている間、通り道が狭くなる | 短い通行調整。新しい扉専用操作を初めから要求しない |
| 通り抜ける台車 | 予告して通路を横切る | 短い譲り合い。永久封鎖・待機専任を必要としない |
| 屋外のカラス | 長く置いた食べ物を持っていく | 小さな事件。屋内へ不自然に配置せず、対象や損失は未定 |

コンベア・リフト・ワゴンを一つの厨房へ全投入する案ではない。専用調理器具や料理追加ではなく、会場の搬送・提供・動線としての候補。新機構自体の採否と詳細定義は別途相談する。ベルト等は本家にもある系統なので、未登場の独自機構と偽らない。

### 基準から外れやすいもの

理由なく床や部屋が空中を移動する、ポータルで瞬間移動する、設備の影が実体の橋になる、といった幻想的な因果。この案を採用するなら候補外にする方向だが、今回はユーザーの質問への評価であり永久不採用を確定しない。

一方、川辺・屋上の固定厨房や、現実の乗り物内の厨房は景観の議論として残せる。そこで自配達が自然に成立するかは別判定であり、無理な配送路を追加しない。

### 制限によるデメリット

- 厨房が突然別の場所へ変わるような大きな驚きは減る。そのぶん会場の用途・景観と、小さな出来事の見せ方が重要になる。
- 搬送設備に偏ると、違う名前でも運ぶだけの似た面になる。仕掛けを増やすだけでなく、物を渡す場面と厨房全体の仕事の形を変える。
- 故障・停電・清掃・補充ばかりだと、現実の面倒な仕事の再現になりやすい。便利な仕掛けも残し、各設備に燃料や点検作業を追加する必要はない。
- 現実的であることは実装が簡単なことと同義ではない。特に昇降搬送・来場者・車両等は、見た目とは別に復旧・同期・人数別検証が必要。

### 当面の提案

ギミックの単体に複数解を義務付けず、一文で理解できる簡潔さを維持する。仕掛けの種類数よりも、現実らしい理由があるか、行動と結果が読めるか、料理と配達へ余計な仕事を積まないかで候補を絞る。

「現実の道具や現象で起こる、誇張したドタバタ」を比較方針として提案する。これで48面の変化が十分という保証はせず、前述の代表配置で違いを確認する。決まっている動物料理人・デフォルメ表現・料理の自動形成・省略された水や油などは維持する。

### 共通世界観との依存

CURRENT_GAME_SPEC §1.6は、空中厨房・移動いかだ・形の変わる厨房が存在でき、現実的説明の程度は未決定としている。今回の案は、その許容範囲を絞る相談に当たる。元資料は直接編集せずH-015へ未送信記録を残す。ギミック候補・例外・対象をユーザーと確認してから扱う。
