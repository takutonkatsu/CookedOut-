# COOKED OUT! ビジュアル開発 第37ラウンド — まな板占有表示と原料カード分離

- 更新日: 2026-09-12
- 対象: まな板の包丁表示、加工済み食材・鍋・フライパン・完成料理の原料カード
- 状態: Unity統合・自動検証済み。横持ちiPhone実機承認待ち
- 非変更範囲: 調理判定、切断時間、レシピデータ、設備Collider、Item Anchor、グリッド座標、Blender正本、FBX、Resources Prefab

## 1. 比較と評価

## 2. 実装ブリーフ

> まな板に材料が載った瞬間から、その材料が取り除かれるまで待機包丁を非表示にする。生の未加工単品には冗長なカードを出さず、切断済み・加熱済みの単品、材料入り鍋／フライパン、組立中および完成済み料理には、構成している全原料の既存IngredientSourceCardsを表示する。カードは省略せず、互いに重ならない自動グリッドへ並べ、料理を含む全Rendererの最高点より十分上へ配置する。

## 3. Unity実装

- `ChoppingKnifeMotion.SetBoardOccupied`を追加し、まな板のスロット状態から包丁Rootの表示を切り替える
- 材料配置中のWORK進行は維持するが、包丁アニメーションは再表示しない
- 材料を回収して空になったまな板では待機包丁を復帰する
- 原料カードの4個上限を撤廃し、`ceil(sqrt(count))`列の自動グリッドへ変更
- カードを0.62 m、中心間隔を0.68 mとして0.06 mの視認ギャップを確保
- 鍋の湯気、フライパンの炎、完成容器の透明蓋まで生成した後に最高点を測り、その上0.55 mへカードを配置
- 新規画像は生成せず、既存のレタス・にんじん・玉ねぎ・牛肉IngredientSourceCardsを再利用

今回の変更は状態連動とTransform配置のみで、メッシュ形状や材質を変更しないため、Blender生成スクリプト、Blender編集正本、23 FBX、23 Unity Resources Prefabは第36ラウンドの検証済み成果を維持した。

## 4. 検証

- EditMode全体: 45/45成功
- PlayMode全体: 50/50成功
- 空のまな板では包丁表示、材料配置直後・作業中・切断完了後は非表示、材料回収後は再表示
- 生の未加工単品はカード0個、加工済み単品は元原料カード1個
- 4原料の鍋と完成容器は4個すべてを表示
- 各カードのXZ境界が相互に重ならないことを全組み合わせで確認
- カード下面が食材・料理・容器・蓋・湯気・炎の最高点より0.45 m以上上にあることを確認
