# 縦切り実装の仮定

この文書の値は`CURRENT_GAME_SPEC.md`を変更する製品仕様ではない。プレイテストと企画判断で差し替える。

| ID | 仮定 | 理由／差し替え点 |
|---|---|---|
| IMP-A001 | `1-1`は固定厨房の現地提供型チュートリアルとする | 現在の実装範囲は一注文の基礎操作であり、旧資料の屋上リフト・バイク配達は後続フェーズに明記されているため |
| IMP-A002 | 営業75秒、初回注文45秒 | 一営業の長さと注文猶予は「実装決定」で未確定のための試作値 |
| IMP-A003 | 基本100点、残秒1秒につき2点、星ライン100／150／180 | 得点構造は決定済みだが倍率と星ラインは未決定のための試作値 |
| IMP-A004 | 一注文を提供すると営業を早期完了して結果画面へ進む | 最小縦切りを短時間で反復検証するため。通常ステージの複数注文化では外す |
| IMP-A005 | 切断はWORK長押し0.75秒で進み、中断後も食材へ進捗を保持する | 操作契約の継続作業を先行実装した試作値。実機試験で秒数を調整する |
| IMP-A006 | 現地提供型の`1-1`でも、今回指定された共通配達容器を使用する | 皿洗いは選ばれた後続ステージだけに導入する決定と整合する |
| IMP-A007 | Unityプロジェクトの基準patchを`6000.3.24f1`とする | ローカルへ導入済みの6.3 LTS patchへ固定。更新時は同系列patchで再テストする |
| IMP-A008 | 仮UI表示は英語とする | グレーボックスでbuiltin fontの文字欠けを避けるため。製品のローカライズ方針ではない |
| IMP-A009 | 誤操作防止を要するゴミ箱の長押しは未実装とする | 今回はデバッグ可能な縦切りを優先。長押し秒数は未決定で、入力設計と合わせて追加する |
| IMP-A010 | 投擲の機能検証中はEditorの`Q`と画面上の仮`THROW`ボタンを使い、1-1でも一時的に有効化する | 正式な長押し＋リリース方式、ボタン配置、1-3での解禁は操作試験後に切り替える。製品仕様の変更ではない |
| IMP-A011 | `1-2`野菜スープの初期2食材をニンジン＋タマネギとする | 正本は2食材の鍋一括まで決定済みで具体食材は未確定。IDとレシピ定義の差し替えで変更可能 |
| IMP-A012 | 鍋の加熱完了を4秒とし、火から外している間は停止、戻すと進捗を保持して再開する | 加熱停止・再開の機能検証値。完成猶予や焦げは1-5〜1-6実装時に追加する |
| IMP-A013 | 投擲の自然距離は4.8m、設備への補正半径は0.9mとする | 10×8厨房で約3セル先へ投げつつ、隣接セル単位の強い吸着を避ける機能試作値。実機操作試験後に調整するため |
| IMP-A014 | `1-3`の最初のバイク実装は野菜スープ一注文を完成容器で積み、短い一本道を往復すると完了する | 積載・乗車・連続走行・追従カメラ・荷下ろし・帰還を検証する機能縦切り。乗車から帰還までは時計を止める。アクセル／ブレーキ専用入力、自前配達ボーナス、複数配達先、交通は後続で追加する |
| IMP-A015 | `1-3`で場外へ落ちた物は0.7秒の落下演出後に単一の`RECOVERY`箱へ戻し、チュートリアル最高星は端末ローカルのschema v1へ保存する | 紛失で進行不能になることを防ぐ機能試作。箱が使用中なら隣の安全な床へ戻す。クラウド同期、複数回収口、演出時間は後続で差し替える |
| IMP-A016 | バイクカメラは車体後方7.2m・高さ5.4mを基準に、旋回追従を毎秒105度、位置追従を0.34秒、注視点追従を0.2秒で平滑化する | 車体へ完全固定せず旋回時の回り込みと加減速時の遅れを感じられる初期試作値。実機の酔いやすさと操作追従性を確認して調整する |
| IMP-A017 | バイクはW／上矢印で前進加速、S／下矢印で停止方向へ制動し、A・D／左右矢印で速度に応じて左右へ操舵する。後退はまだ行わない | 厨房の方向移動と乗車中の車両操作を同じキー上で明確に切り替える機能試作。後退、ハンドブレーキ、タッチ用専用ペダルは配達HUD工程で追加判断する |
| IMP-A018 | `1-3`は一人営業として自前配達ボーナス50%を適用し、直線路全体を一枚の簡易ミニマップへ正規化して表示する | 人数別ボーナス率は決定済みだがチュートリアルは固定ソロ。複数道路・複数配達先の地図投影は製品版配達工程で差し替える |
| IMP-A019 | `1-4`の先行縦切りは、ダッシュ0.28秒、再使用待ちなし、衝突減速0.18秒とし、歩行4.1m/sを上回りダッシュ7.5m/sを下回る4.8m/sの2セル逆向きコンベアを置く。サラダを完成させ、連打ダッシュで運んで提供することを完了条件にする | 操作だけの訓練ではなく、料理の提供経路でダッシュを使わなければ物理的に進めない状況を作り自然に学ばせる。複数注文と注文順コンボは次工程で接続し、各速度・秒数は実機で調整する |
| IMP-A020 | 手持ち基準をプレイヤーのローカル座標`(0, 0.72, 0.68)`へ置き、`1-5`のフライパンは切断済み肉を4秒で完成、完成後6秒で焦げる。焦げた中身はフライパンを持ってゴミ箱で廃棄し、空のフライパンは手元へ残す | 容器が顔を隠さない腰前の保持位置と、個別加熱・完成回収・焦げ予告・失敗後の再利用を一皿の調理で確認する機能試作値。位置と秒数は実機目視で調整する |
