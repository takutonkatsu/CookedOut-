## 操作と実行

1. Unity HubでこのフォルダをUnity 6.3 LTS projectとして開く。
2. package importとcompileが完了するまで待つ。URP assetは初回import後に自動生成される。
3. 基本操作は`Assets/_CookedOut/Scenes/Tutorial_1_1.unity`、鍋工程は`Tutorial_1_2.unity`、投擲とバイク配達は`Tutorial_1_3.unity`、ダッシュ配達は`Tutorial_1_4.unity`、フライパン調理は`Tutorial_1_5.unity`、火災復旧は`Tutorial_1_6.unity`、皿洗いは`Tutorial_1_7.unity`、複合配達は`Tutorial_1_8.unity`を開きPlayする。
4. Editor操作はWASD／矢印で移動、Eで取る／置く、SpaceまたはF長押しで作業、Qで投げる、Shiftでダッシュ。
5. レタスを取り、まな板へ置き、SpaceまたはFを押し続けて切り、Eで拾う。容器をカウンターへ置き、切ったレタスを入れ、完成容器を提供口へ持っていく。
6. 1-2ではニンジンとタマネギをそれぞれ切って鍋へ入れる。加熱中の鍋はEで外して退避でき、戻すと続きから加熱する。完成後、空容器を持って鍋へEを押し、提供口へ運ぶ。
7. 1-3では切った食材を低いカウンター列越しに鍋へ投げ、完成スープを容器へ移す。右手前の`BIKE LOAD`へ完成容器を持ってE、もう一度Eで乗車し、厨房奥の一本道を緑色`DELIVERY`まで走る。荷下ろし後は黄色い`RETURN`へ戻ると配達が完了する。積載場所付近ではEで降車できる。
8. 1-4ではレタスを切り、空容器で完成サラダを回収する。完成品を持って右方向へ進み、通常歩行より速い逆向きコンベアをShiftまたは画面のDASHを連打して突破し、奥の提供口へ届ける。ダッシュは再使用待ちなしで、押すたびに続けて発動できる。
9. 1-5では牛肉を切って`PAN HEAT`へ入れる。加熱ゲージが満ちたら6秒以内に空容器を持ってフライパンへEを押し、完成したハンバーグプレートを提供口へ運ぶ。フライパンを外すと加熱を一時停止できる。焦げた場合は熱源でEを押してフライパンを持ち上げ、`TRASH`へ運んでEを押すと中身だけを捨てられる。手元に残った空のフライパンを熱源へ戻してやり直す。
10. 1-6では営業時計が停止した状態で開始する。消火器棚から消火器を取り、炎の前でSpaceまたはFを長押しして鎮火すると時計が動き、スープとハンバーグを合計2件提供すると星評価対象になる。
11. 1-7では清潔な皿が2枚だけ支給される。料理を提供すると返却口へ汚れ皿が戻るため、洗い場へ置いてSpaceまたはFを長押しし、洗浄済みの皿を再利用する。合計3件の提供が星評価条件。
12. 1-8では既習3料理を扱う。1件目は配達代行棚、2件目はバイク自前配達が必須で、3件目以降はどちらでもよい。厨房中央の接続部は警告点滅後にゆっくり移動する。

- `Tutorial_1_2`の鍋工程はUnity Editorで目視確認済み。にんじん／玉ねぎ供給カードは`style_version 1`画像へ差し替え、同じContentIdの生食材を供給することをPlayModeで確認した。
- 厨房HUDは左下の簡素な固定スティック、右下の文字なし人型ピクトによる同寸正方形2×2四行動、上端時計・注文・スコアを採用し、`style_version 1`実装候補とした。配達HUDは左下アクセル・下矢印の後退、右下左右操舵、右上の距離・方向案内まで実装済み。正式な簡易ミニマップとiPhone実機での寸法調整はdesign工程で行う。
- `Tutorial_1_3`はバイクを厨房北端と街路の境界へ移し、積載台を撤去して完成容器をバイクへ直接積載する。積載可能な完成料理を持つ場合は斜めセル・軽い向きずれを許容し、乗車中は厨房側へ境界を越えられない。往復配達、配送中のタイマー継続、追従／復帰カメラをPlayModeで確認済み。
- `1-3`の場外落下物用`RECOVERY`作業台は撤去した。落下物は厨房内の最後の安全地点へ地面アイテムとして戻る。ローカル進捗保存、バイク専用入力、配達HUDと解放フラグは維持し、直接キャッチはマルチ実装時に追加する。
- `1-4`は再使用待ちなしのダッシュ操作、衝突減速、手持ち保持、通常歩行では突破できない逆向きコンベアを、サラダ調理から提供までの必須経路へ組み込んだ縦切りまで実装済み。スープを含む複数注文と注文順コンボは次工程で接続する。
- `1-5`は切断済み牛肉だけを受け付けるフライパン、加熱停止・再開、6秒の完成猶予、残り2秒警告、炎上表示、フライパンをゴミ箱へ運んで中身だけ廃棄する復旧、容器移し、提供までの機能縦切りを実装済み。本番のハンバーグ付け合わせ、焦げ予告の音・アニメーション、食材カードと注文票用の本番画像はdesign工程で追加する。
- 本店は`home_kitchen_v1`として12×9固定地形、固定作業面、37ソケット、到達可能性、店ランク非依存までDomain化した。次工程は、18汎用ソケットだけを対象に所有設備・種類共通Lv・向きを保持する配置プリセットを追加し、固定部材をプリセット保存対象から除外する。
- 企画上、鍋用熱源とフライパン用熱源は独立購入設備ではなく、それぞれ鍋・フライパンに一台ずつ付属する一式へ変更された。既存の`PotHeatSource`等は営業中に器具本体を着脱する物理表現として残せるが、ショップ、所持数、Lv、セーブでは鍋／フライパン側へ集約する。組立台と受渡し台も同一設備種として扱う。ストア・本店配置実装時に反映する。
