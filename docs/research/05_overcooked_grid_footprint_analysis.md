# Overcooked厨房グリッド寸法・画面範囲調査

- 更新日: 2026-09-11
- 目的: COOKED OUT!の本店・出張営業で使う論理グリッド寸法の基準を作る
- 結論: 密な一体型厨房は概ね10〜14×7〜10セル、中心帯は11〜13×7〜9セル。分断厨房は外接範囲が15〜18×8〜11セル程度でも、空白を含む小区画の集合である

## 1. 調査上の注意

Ghost Town Gamesはインタビューで、Overcookedのレベルがグリッドベースであり、粗いレイアウトをUnity上で組んだ後、分業と設備位置を長く調整すると説明している。[S1]

ただし、各製品版厨房の内部グリッド寸法や全レベルの最小・最大値は公式には公開されていない。本資料の寸法は、標準カウンター一台の幅を1セルとして、Team17提供画像およびゲーム画面から床目地、カウンター列、島の間隔を目視換算した推定値である。斜め投影、装飾、床目地の省略があるため、1セル程度の誤差を含む。

「外接範囲」は、水、穴、宇宙空間等を含め、すべてのプレイ区画を囲む矩形である。「密な本体」は、連続して歩ける主要床と外周カウンターを指す。分断厨房では外接範囲をそのまま全面床にしてはいけない。

## 2. 代表厨房の目視換算

| 作品・厨房 | 推定外接範囲 | 密な本体／区画 | 読み取れる設計 |
|---|---:|---:|---|
| Overcooked 1-1 | 約11〜12×7 | 約11×7 | 長方形外周＋中央の細長い島。導入でも作業面を中央へ置く |
| Overcooked 6-4 | 約15〜16×9〜10 | 各区画4〜7セル幅 | 中央室と回転する外部室を分け、空間全体を一枚床にしない |
| Overcooked The Peckening | 約13〜14×8 | フェーズごとに約10〜13×6〜8 | 最終厨房でも、一度に読ませる作業面を段階的に切り替える |
| Overcooked 2 1-1 | 約11×8 | 約9×6の歩行面＋外周 | 序盤の密な固定厨房。二つの小型中央島を使う |
| Overcooked 2 1-3 | 約11〜12×8 | 約10×7 | 外周作業面と細い中央島で短い周回動線を作る |
| Overcooked 2 2-6 | 約13〜14×7〜8 | 左右約5×6＋中央可動列 | 横長だが、中央ギミックで分業範囲を区切る |
| Overcooked 2 4-6 | 約11〜12×9 | 外周＋中央約4×5 | 縦方向を使う場合も、中央の穴と可動列で密度を保つ |
| Overcooked 2 5-6 | 約15〜16×9 | 各島約4〜6×3〜5 | 外接範囲は大きいが、三つの小島と空白で構成する |
| Overcooked 2 6-6 | 約12〜13×8 | フェーズごとに約10〜12×6〜8 | 最終面は設備・料理を段階変更し、単純な巨大床にはしない |

Overcooked 2の公式紹介でも、動的厨房は営業中に移動・変形し、空中厨房から別厨房へ衝突して料理構成まで変わる例が示されている。[S2] 重要なのは最大マス数ではなく、同時に読ませる作業区画を小さく保ったまま、接続と設備位置を変えることである。

## 3. 観測範囲

目視サンプルを設計用の範囲へ丸める。

| 分類 | 推奨解釈 |
|---|---|
| 小型・導入厨房 | 10×7〜11×8程度 |
| 標準の密な厨房 | 11×8〜13×9程度 |
| 大型の密な厨房 | 最大14×10程度。常用しない |
| 分断・小島厨房 | 外接15〜18×8〜11程度を許すが、各島は4〜8セル幅を基本にする |
| 動的厨房 | 外接寸法より、各状態で到達できる作業区画、接続幅、移動周期を管理する |

これは原作内部データの確定値ではなく、COOKED OUT!用の安全な設計帯である。公式のレベル設計説明は、寸法の一律化より、各ステージで異なる協力行動を作り、その後に設備位置を反復調整する方法を重視している。[S1]

## 4. COOKED OUT!への反映案

### 4.1 本店

本店の最終12×9は、原作で多い標準〜やや大きめの密な厨房帯に収まる。iPhone横持ちでは左右下にタッチHUDが重なるため、原作の大型画面向け上限14×10を本店へ常用しない。

- 最終外周: 12×9
- 通常営業解放時の実使用域: 12×9全域
- ランクによる床面積、閉鎖区画、設備ソケットの追加解放は行わない
- カメラ: 12×9全体を基準にし、ランクアップで連続的に縮小しない
- 配送出口: 画面端の専用帯に寄せ、調理用汎用ソケットと完全には混ぜない

### 4.2 出張営業

全ステージを12×9へ固定しない。次の三サイズを基本テンプレートにし、分断型だけ16×10程度の論理キャンバスを許す。

| テンプレート | 基準 | 用途 |
|---|---:|---|
| S | 10×7 | チュートリアル、単一料理、安全導入 |
| M | 12×8 | 標準厨房、初期〜中盤の中心 |
| L | 14×9 | 章最終、複合料理、強いギミック |
| Split | 最大16×10外接 | 空白を含む2〜4区画。各区画は4〜8セル幅 |

大型化で難度を作らず、通路幅、設備間距離、受渡し方向、接続時間、注文密度を優先して調整する。LとSplitはキャラクターの画面上サイズがHUD込みの実機基準を下回る場合、カメラ分割ではなくレイアウト縮小を先に検討する。

## 5. 次の決定候補

1. 本店は通常営業解放時から12×9全域固定とし、物理拡張を行わない
2. 出張営業はS 10×7、M 12×8、L 14×9、Split最大16×10を設計帯にする
3. 最終寸法はマス数だけでなく、iPhone実機でのキャラクター、食材、危険表示、HUDの最小見かけ寸法で合否判定する
4. 54ステージ表へは、各厨房のテンプレートと実占有範囲を後から追加する
